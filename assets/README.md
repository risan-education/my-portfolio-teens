# 写真・動画・資料の所在

- 作成日: 2026-09-26
- 更新日: 2026-09-26

ChatGPTへの頼み方:

> この資料の所在メモの案を作ってください。原本の保存先と閲覧できる人を分けて、確認できないことは未確認としてください。

案を本人が確認して保存します。[初期設定](../docs/getting-started.md)／[保存方法の確認](../docs/connection-check.md)

原本は本人が選んだ外部ストレージへ置き、ここには所在メモを保存します。リンクを知っていることと閲覧権限があることは別です。

別のMarkdownファイルに、作成日・更新日、資料名、原本の保存先とファイル名、対応する活動記録、閲覧できる人、権限と原本を確認した日、バックアップ先、出典・利用条件を記入します。URLが使えない場合もフォルダ名とファイル名で探せるようにします。パスワードや共有用の秘密コードは書きません。
