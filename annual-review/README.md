# 年間振り返りの保存先

- 作成日: 2026-09-26
- 更新日: 2026-09-27

ChatGPTへの頼み方:

> 今年の実記録から、私が残したい経験を選ぶのを手伝ってください。年間振り返りの案に根拠リンクを付けてください。

案を本人が確認して保存します。[初期設定](../docs/getting-started.md)／[保存方法の確認](../docs/connection-check.md)

[年間振り返り用紙](../templates/annual-review.md)をコピーして、記録日と対象年が分かる別ファイルにします。例: 270331-annual-review.md（2027年3月31日に振り返った場合）。対象の年度は本文に書きます。ファイル名の規則はほかの記録と同じ YYMMDD-theme.md で、年を4桁で入れる別形式は使いません。

全部の活動を並べる必要はありません。根拠をたどりながら、本人が今残したいものを選びます。
