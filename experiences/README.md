ChatGPTへの頼み方:

> このメモを一言メモか活動記録に整理して、保存先と案を見せてください。

案を本人が確認して保存します。[初期設定](../docs/getting-started.md)／[保存方法の確認](../docs/connection-check.md)

本人用の非公開コピーでは、年ごとのフォルダに保存できます。例: experiences/2026/260926-reading.md。日付不明なら experiences/unknown/date-unknown-reading.md でも構いません。

[一言メモ](../templates/quick-note.md)か[活動記録](../templates/experience.md)をコピーします。学年やタグは任意です。[問いの一覧](../questions.md)から関連付けても探せます。
