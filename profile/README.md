# 今の自分

- 作成日: 2026-09-26
- 更新日: 2026-09-27

ChatGPTへの頼み方:

> 今の私の興味と希望を、確認日付きで整理する案を見せてください。過去の記録から今の希望を決めつけないでください。

案を本人が確認して保存します。[初期設定](../docs/getting-started.md)／[保存方法の確認](../docs/connection-check.md)

好きなこと・興味・相談したいことを、書きたいときだけ残します。本名・学校名・住所は不要です。

ここで残した本人の言葉と活動記録をもとに、[自己理解の手順](../docs/self-understanding.md)で得意・苦手・好き・嫌いと性格の傾向を整理できます。確認済みの出力はderived/へ保存し、大学・学部選びの参考にします。

本人用の非公開コピーでは、例えば YYMMDD-interests.md に確認日と今の言葉を記録できます。過去の記録を消して「ずっと同じ興味だった」と書き換えません。

AIに毎回自分のことを説明しなくて済むように、[AI向け自己紹介の現在版](../templates/ai-profile.md)をここに置けます。本人が確認した今の情報だけを書き、更新日を付けて見直します。渡し方は[AIへ持ち運ぶ](../docs/portability.md)を参照してください。

[利用範囲の見直し用紙](../templates/record-use-review.md)も必要に応じて使えます。AIへ渡さない情報は、このリポジトリをAIへ接続する前に接続対象の外へ置きます。[共有のガイド](../docs/privacy.md)
