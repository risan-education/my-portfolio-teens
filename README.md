# Myポートフォリオ〈中高生版〉

- 作成日: 2026-09-26
- 更新日: 2026-10-02

**「やってみた」「うまくいかなかった」「気になった」を一言から。** ChatGPTにメモを伝え、できた案を自分で確かめ、自分用のPrivate（非公開）へ残すMarkdown教材です。毎日書く必要も、全欄を埋める必要もありません。

**初めてなら [最初の10分](docs/first-10-minutes.md)。** GitHubの設定前に一件作れます。[5つの会話と完成記録](examples/prompts/README.md)／[質問なし・訂正などの短い会話](examples/prompts/short-sessions.md)も見られます。

## 次からは、このように頼めます

接続と保存先を確認した後は、自分用PrivateのURLとメモを送ります。用紙やファイル名はAIが案内します。

> 昨日、図書室で借りた本を読み終わった。知らないことがたくさんあった。

上は架空の入力例です。自分の内容に置き換えます。案に言っていないことがあれば直し、よければ次を送ります。

> この内容で保存してください。

質問には答えなくても構いません。「今日は質問なし」「日記はいらない」でも終えられます。日記を付ける場合も短くて大丈夫です。元メモと追加回答の原文は残ります。

**保存後は、報告されたファイルを開いて本文を確認します。** 標準は自分用Privateのmain。端末内や別ブランチだけなら、その範囲を確認します。[保存先・呼び出し方・一覧](docs/where-records-go.md)

## はじめに

第一の目的は、日々の経験・問い・作品・考えの変化を残し、大学入試の総合型選抜・推薦入試に備えることです。入試対策を始める時期や、日々の記録だけに使うことも本人が選べます。記録量や受賞歴を競う教材ではありません。

中高生が共通の用紙を使うテンプレート集（0.5.3）です。本人が記録と利用範囲を選び、保護者は希望に応じて支援します。実記録は自分用Privateまたは本人が指定した非公開の端末内へ保存します。

## ChatGPTで始める

1. [最初の10分](docs/first-10-minutes.md)で一件作る。
2. 続けたくなったら、[はじめ方](docs/getting-started.md)に沿って自分用Privateを用意する。
3. [接続確認](docs/connection-check.md)で、架空の練習記録を保存・追記し、もう一度開けることを確かめる。

使える機能は環境によって異なります。[確認済み・未確認の範囲](docs/connection-environments.md)を参照し、保存機能がなければ[手動保存](docs/manual-editing.md)で続けます。有料プランやアプリの導入は必須ではありません。小学生版から続ける人は[引き継ぎガイド](docs/migration.md)へ。

## 高1で募集要項を読んだら、6段階の探究を始める

本教材の入試対策では、一つの主テーマを6段階で育てることを必須の取り組みとします。入試対策に取り組むかどうかは本人が選びます。[テーマの選び方](docs/choosing-inquiry-theme.md)で本人の関心から選び、[6段階の探究ガイド](docs/inquiry-project-guide.md)で見通しと最初の行動を決めます。大学未定でも始められます。主テーマの未実施段階は、理由と再検討時期を残して見直します。

日々の質問で使う4つの流れは、その日の考えを深めるため。6段階は長期の主テーマの見通しです。[二つの関係](docs/inquiry-project-guide.md#日々の4つの流れと主テーマの6段階)。大学の出願条件は、教材の学習方針と分けて確認します。

## 総合型選抜・推薦入試用に出力する

[出願準備ガイド](docs/admissions-guide.md)で、大学・学部・方式・入学年度を特定します。[提出条件確認](templates/submission-check.md)で今回のAI作業が許される範囲を確かめてから、本人が選んだ原記録を材料にします。未確認・禁止の作業は条件確認まで。根拠表と提出本文は分け、提出は別に行います。

## 記録を置く場所

日々の新規記録はexperiencesの年別フォルダ、探究・作品はprojectsのテーマ別フォルダ、振り返りはreflectionsへ。既存の直下の記録は移動不要です。フォルダを開くと一覧と案内のREADMEが表示され、記録がまだなければREADMEだけが見えます。

[保存先と呼び出し方の一覧](docs/where-records-go.md)／[問いの一覧](questions.md)／[用紙の一覧](templates/README.md)。記録が増えて探しにくくなったら[任意の索引](docs/record-index.md)を作れます。
