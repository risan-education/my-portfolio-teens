# 練習用の保存先

- 作成日: 2026-09-27
- 更新日: 2026-09-27

接続や保存の確認に使う、本人用の練習ファイルを置く場所です。ここに置くファイルはすべて架空の内容とし、本人の活動の集計・要約・出願用の出力に含めません。

配布元の [examples/](../examples/README.md) は教材の架空例で、テンプレート更新のときに差し替わることがあります。本人の練習は examples/ ではなく、この practice/ に保存します。

ChatGPTへの頼み方:

> 架空の練習記録の案を作ってください。practice/ に保存し、本文に架空と明記してください。同名があれば上書きしないでください。

練習の手順は[接続確認](../docs/connection-check.md)にあります。練習が終わったら、実際の記録は experiences/ などの本来の場所へ保存します。練習ファイルを削除するかどうかは本人が決めます。
