## どんな関心から始めるか

架空の高校生は、好きな物語を別の言語で読むと登場人物が冷たく感じられた。自分の印象を出発点に、どの言葉を根拠にそう読んだのかを確かめる。

- 関連を調べたい学部・学科の分野: **文学・日本語・外国語**
- 高校生活を通して育てる大きな主テーマ: **言葉と物語が生む解釈の違い**
- 最初の問い: **著作権の利用条件を確認できる短編の一場面で、原文と翻訳の呼称・省略・語り手の距離はどう異なるか。**
- 準備・小さな始め方: 利用可能な原文と翻訳、辞書、図書館。翻訳にも独自の権利があるため版ごとに確認する。別言語が難しければ同一作品の語り方の比較から始める。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 印象が変わった一文を、自分の感想と原文の所在を分けて記録する。 |
| 2. 課題を決める | 一場面に絞り、呼称・代名詞・省略など比較する観点を決める。 |
| 3. 仮説を立てる | 距離を感じる理由は人物の呼び方かもしれない、と解釈の仮説を置く。ほかの読み方も書く。 |
| 4. 現場で確かめる | 原文と訳文の対応表を作り、前後の文脈・辞書・先行する解説を照合する。単語数だけで文学的価値を決めない。 |
| 5. 形にして発信する | 根拠箇所を必要最小限引用した読解レポートや読書会資料を作り、自分の解釈と異論を併記する。 |
| 6. 人を巻き込む | 国語・外国語の先生や読書会の友人と別の解釈を検討し、説明できない箇所を次の比較対象にする。 |

## 方法を具体的にする

選んだ場面と比較観点の理由を先に書き、都合のよい文だけを選ばない。同じ言葉が別場面でどう使われるかも確認する。友人の感想は正解判定や読者全体の傾向にせず、可能な読みの一つとして扱う。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 高1からどう深めるか

高1は一場面の精読と読書会。高2は別の場面・作品・翻訳年代へ比較を広げる。高3は共通点と反例をまとめ、当初の読みが変わった理由を示す。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

### 成果報告（架空）

私は、同じ短編を原文と日本語訳で読んだとき、登場人物の態度が異なって感じられたことに疑問を持った。作品の内容が同じでも、言葉の選び方によって人物との距離が変わるのではないかと考え、ある再会の場面を対象に、呼び方、省略、語り手の説明を比較した。翻訳の優劣を決めるのではなく、自分の読みの根拠を明らかにすることを目的とした。

最初に、使う版を決め、比較する場面の前後も読んだ。原文と訳文の対応表には、人物の呼称、発言、行動の説明を別々に記した。辞書で確認できる意味と、文脈から私が考えた意味を区別し、作品解説も参照した。初めは、名前で呼ぶか代名詞で呼ぶかの違いが、冷たく感じる主な理由だと予想していた。

ところが、対応表を見直すと、呼び方が似ている文でも私の印象は違っていた。一方の文章では発言の前に人物の迷いを示す説明があり、もう一方ではそれを後で読むことになっていた。私は、言葉一つの違いだけでなく、どの情報を先に受け取るかも関係すると考えた。そこで、比較の範囲を広げ、人物について分かることが増える順番を整理し直した。

読書会では、比較表と自分の解釈を示した。友人からは、冷たさではなく、相手への遠慮として読めるという意見が出た。私はこの意見を正誤で判定せず、どの表現を根拠にしたのかを聞き、元の文章へ戻った。その結果、自分が人物の事情を読み落としていた部分が分かった。報告文には最初の解釈に加え、別の読み方が成り立つ理由と、どちらかに決められない箇所を残した。

今回の比較では、呼称の違いだけでは人物の印象を十分に説明できず、情報の順序や前後の文脈を合わせて読む必要があった。ただし、一作品の一場面についての考察であり、訳者の意図や読者全体の反応を確かめたわけではない。私は本文の整理と解釈を担当し、先生には言葉の意味、友人には異なる読みの可能性について助言を受けた。

この探究を通じて、感想を述べることと、根拠を示して解釈することの違いを学んだ。意見が変わることを失敗とせず、どの記述によって考えが変わったかを記録できたことが成果である。今後は別の場面でも同じ見方が使えるかを確かめ、大学では文学や言語、翻訳を学びながら、表現と読みの関係をさらに考えたい。
