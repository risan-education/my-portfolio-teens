## どんな関心から始めるか

架空の高校生は、家庭の鉢植えへの水やりを工夫したいと考えた。水を少なくすることと、生育を保つことの両方を確かめる。

- 関連を調べたい学部・学科の分野: **農・園芸・生命科学**
- 高校生活を通して育てる大きな主テーマ: **植物の生育と資源の使い方**
- 最初の問い: **鉢土の表面を覆うと、土の水分の減り方と同じ種類の植物の生育はどう変わるか。**
- 準備・小さな始め方: 同じ種類・大きさの苗、同じ鉢と土、はかり、定規、安全な被覆材。複数鉢を置ける範囲で始め、管理方法を先生と確認する。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 水やりで困っている場面と、植物のどの変化を見たいかを書く。 |
| 2. 課題を決める | 被覆あり・なしの条件に絞り、水分減少と生育を別々に調べる問いにする。 |
| 3. 仮説を立てる | 被覆すると水分が減りにくいが、生育への影響は温度などで変わるかもしれないと予想する。 |
| 4. 現場で確かめる | 各条件で複数鉢を用意し、苗・土・鉢・水量を揃える。位置を偏らせず、鉢の重さ・葉数・生育を一定時刻に測る。 |
| 5. 形にして発信する | 使用した水と生育の図を作り、家庭で再現するときの条件と限界を説明する。 |
| 6. 人を巻き込む | 園芸担当の先生や友人と管理記録を点検し、鉢の位置や測定方法を改善する。 |

## 方法を具体的にする

一鉢に何枚も葉があっても独立した多数の鉢の代わりにはしない。鉢全体の重さには植物の成長も含まれるため、水分量そのものと断定しない。必要なら植物なしの比較鉢も加える。実験用植物は食べず、枯れそうなときの中止条件を決める。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

### 成果報告（架空）

私は、家庭の鉢植えの水やりを工夫したいと考え、土の表面を覆うことに関心を持った。水が減りにくくなれば管理が楽になると予想したが、植物の生育にもよいとは限らない。そこで、被覆の有無によって鉢の重さと植物の状態がどう変わるかを、別々に記録して比べた。

先生と管理方法を相談し、同じ種類で大きさの近い苗を使い、土と鉢を揃えた。被覆ありとなしをそれぞれ四鉢ずつ用意し、置き場所が一方へ偏らないように配置した。給水の時刻と量を記録し、一定時刻の鉢の重さ、葉数、高さ、見た目を観察した。私は測定表を作り、測り忘れた日は推測で埋めず欠測として残した。

観察期間中、被覆した鉢では重さの減少が小さい日があったが、葉数や高さの変化は鉢ごとに異なり、同じ傾向が明瞭には見られなかった。初めは重さの差をそのまま土の水分の差として説明しようとした。しかし、先生から、鉢全体の重さには植物の成長なども含まれると指摘され、測定値の意味を見直した。

そこで、植物を植えていない比較鉢を使う予備的な観察を追加した。ただし、植物がない鉢は元の条件と同じではないため、そこで得た差をそのまま差し引くことはしなかった。園芸に関心のある友人と記録を点検した際には、写真の角度が違うと葉の広がりを比べにくいことも分かった。私は撮影位置を固定し、変更した日を記録した。

発表では、使用した水、鉢の重さ、生育の記録を分けた図を示した。今回の成果は、土を覆えば生育もよくなるという予想を見直し、水の管理と生育を別の指標で検討する必要を示せたことである。ただし、同じ量を給水した比較なので、必要な給水量がどれだけ減るかを実証したわけではない。観察期間や鉢数も限られ、違いの原因を一つに決めることはできない。

私は、測りやすい数値を測りたい性質そのものと思い込まないことを学んだ。助言を受けても測定と考察は自分で行い、枯れかけた場合の対応を優先して管理した。今後は温度や土の状態も確かめ、同じ生育を保つために必要な水量という問いへ進みたい。大学では植物生理や土壌、実験計画を学び、資源を節約する工夫を条件付きで評価できるようになりたい。
