## どんな関心から始めるか

架空の高校生は、同じ図書館でも求める過ごし方が違うことに気付いた。利用者を分類して評価するのではなく、選択肢が伝わる環境を考える。

- 関連を調べたい学部・学科の分野: **社会・社会福祉**
- 高校生活を通して育てる大きな主テーマ: **多様な使い方を支える公共の居場所**
- 最初の問い: **一つの図書館の案内から、静かに読みたい人と会話して学びたい人は、使える場所とルールを判断できるか。**
- 準備・小さな始め方: 館内案内・利用規則・公開平面図、紙の地図。施設に確認した範囲の環境観察。利用者の顔や行動を無断で撮影・追跡しない。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 自分が過ごしやすかった場面と、困った場面を区別して記録する。 |
| 2. 課題を決める | まず館内案内だけで席の用途や会話のルールが分かるかを調べる。 |
| 3. 仮説を立てる | 空席の数より、使い方の説明不足が場所選びを難しくしているかもしれないと考える。 |
| 4. 現場で確かめる | 案内・規則・現地表示の一致を点検し、架空の利用場面に合う場所を友人に探してもらう。判断の根拠と迷った箇所を聞く。 |
| 5. 形にして発信する | 使い方を選べる案内図を試作し、静けさと交流の双方への配慮を説明する。 |
| 6. 人を巻き込む | 司書や友人と運営上の制約を検討し、案内の表現を直す。実掲示する場合は施設の許可を得る。 |

## 方法を具体的にする

障害や家庭事情を見た目から推測しない。希望する人への聞き取りは目的と利用範囲に同意を得て、答えたくない項目を設けない。友人の反応はその場の検証であり、地域住民全体の意見とは分ける。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 予想と違ったらどうするか

次は**起こり得る展開の架空例**であり、結果の予告ではありません。

案内の改善より部屋の不足が大きな課題なら、表示だけで解決できたとは言わない。費用・運営・時間帯を含めて次の問いを設定する。

## 高1からどう深めるか

高1は一施設の案内調査。高2は許可のある別施設との比較や利用場面の追加。高3は公共空間の選択肢と運営の両立について提案と限界をまとめる。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

**残すもの:** 許可範囲、環境点検表、公開資料の出典、匿名の反応、案内図各版、採用されなかった提案の理由。

**大学での学びとの接点:** 地域福祉、社会調査、公共空間、社会的包摂。本人の体験だけで他者の困りごとを決めずに調べる方法を大学で学ぶ接点。

### 成果報告（架空）

私は、図書館で静かに読みたいときと、友人と相談しながら学びたいときに、同じ席を選べばよいわけではないと感じた。そこで、館内案内から自分の目的に合う場所と利用ルールを判断できるかを調べた。利用者の性格や事情を分類するのではなく、場所を選ぶための情報がどう伝えられているかに注目した。

施設に調査の目的を伝え、確認できる範囲で案内図、利用規則、現地の表示を見比べた。私は、会話の可否、予約の必要、利用できる時間を表にした。その上で、静かに読む、二人で相談する、短時間だけ資料を見るという架空の場面を作り、同意した友人五人に案内図から候補を選んでもらった。氏名や家庭事情は集めず、選んだ理由と迷った箇所を記録した。

点検では、場所の名前が分かっても、そこで何ができるか判断しにくい場面が見られた。特に、学習室という名称から会話ができると考えた人と、静かに使う部屋だと考えた人がいた。利用規則には説明があったが、案内図だけではその情報へたどり着きにくかった。私は、席の数より先に、用途とルールを対応させて示す必要があると考えた。

そこで、各場所に利用場面と確認先を添えた案内図を試作した。司書の方から、会話できる部屋でも時間帯や予約によって使えないことがあると教わり、いつでも使えるように見える表現を修正した。友人と再点検すると、利用できる時間を確かめる必要に気付く反応があった。一方、希望に合う部屋そのものが空いていない問題は、案内だけでは解決できなかった。

私は、初版と修正版を授業内で発表し、情報の不足と空間の不足を分けて説明した。成果は、目的に応じて場所を選ぶための試作を作り、その限界を明らかにしたことである。今回の協力者は友人に限られ、地域の利用者全体を代表していない。また、実際の館内掲示や利用状況の変化までは確認していない。案内の作成と考察は私が担当し、運営条件について司書の助言を受けた。

この探究から、誰にでも同じ情報を示すだけで使いやすい場所になるとは限らず、選択に必要な条件を伝えることが大切だと学んだ。今後は、利用者の希望を決めつけずに確かめる調査方法を学びたい。大学では地域福祉や社会調査を学び、異なる過ごし方を望む人が、同じ公共空間を使える仕組みを考えたい。
