## どんな関心から始めるか

架空の高校生は、友人に説明したとき「分かった」と言われても、別の問題では伝わっていなかった経験を持つ。正答率を競うより、説明のどこが伝わらないかを知りたい。

- 関連を調べたい学部・学科の分野: **教育・教科教育**
- 高校生活を通して育てる大きな主テーマ: **つまずきに気付ける教材づくり**
- 最初の問い: **分数の大きさを比べる説明で、面積図と数直線はそれぞれ何を理解しやすく、何を誤解しやすくするか。**
- 準備・小さな始め方: 紙の教材、教科書、先生の助言。初回は協力に同意した同年代の友人による教材点検。小学生への授業は学校・保護者等の手続と教員の指導が整った場合だけ別計画にする。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 自分が説明に困った場面と、教育に興味を持った理由を残す。 |
| 2. 課題を決める | 比較する分数と学習目標を一つに絞り、二つの説明案を作る。 |
| 3. 仮説を立てる | 数直線は大きさの順序、面積図は部分と全体の関係を説明しやすいのでは、と予想する。 |
| 4. 現場で確かめる | 先生に内容を点検してもらい、友人に説明を自分の言葉で言い換えてもらう。見せる順序を入れ替え、誤解した箇所を集める。 |
| 5. 形にして発信する | 教材の初版と修正版、どの誤解に対応した変更かを校内で発表する。 |
| 6. 人を巻き込む | 数学の先生と友人で役割を分け、別の問題にも説明が使えるかを再点検する。 |

## 方法を具体的にする

問題の難しさ、説明時間、図の大きさをできるだけ揃える。「分かりやすい」という感想と、説明を使えたかを分ける。同年代の少人数の確認だけで小学生への教育効果を主張しない。参加しない自由を伝え、成績や氏名は集めない。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 予想と違ったらどうするか

次は**起こり得る展開の架空例**であり、結果の予告ではありません。

面積図で正答しても理由を説明できない場合は、正解の増加を成功とせず、図の「全体」をどう理解したかへ問いを戻す。

## 高1からどう深めるか

高1は一つの学習内容と教材改善。高2は別の表現や問題で再検討し、実施可能なら教員の指導下で授業観察へ進む。高3は改善過程と対象の限界をまとめる。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

### 成果報告（架空）

私は、友人に分数を図で説明したとき、分かったと言われても別の問題では説明が伝わらなかった経験から、教材の分かりやすさを考える探究を始めた。面積図と数直線のどちらが優れているかを決めるのではなく、それぞれの図で何を理解しやすく、どこで誤解が起きるかを調べることにした。

分数の大きさを比べる問題を選び、面積図と数直線を使った二種類の教材を作った。説明時間や文字量をできるだけ揃え、数学の先生に内容を確認してもらった。その後、協力に同意した同年代の友人六人に、図の意味を自分の言葉で説明してもらった。教材を見る順番は入れ替え、正解したかだけでなく、どこを見て判断したかを記録した。

初回の点検では、面積図で正しく答えた人の中にも、全体の大きさが異なる二つの図をそのまま比べようとする人がいた。数直線では、線上の位置に注目できても、目盛りの間隔をどう数えたか説明しにくい場面があった。私は、正答したことだけを理解の証拠として扱っていた点を見直し、図の前提を言葉にできるかを点検項目に加えた。

教材を修正する際には、面積図では何を一つの全体とするか、数直線では何を一つ分とするかを明示した。さらに、図を選んだ理由を説明する問いを添えた。再点検では、前提に触れて説明する場面が見られたが、同じ人が繰り返し参加しているため、修正だけの効果とは言えない。私はその限界を含め、初版と修正版を並べて授業内で発表した。

発表後、先生からは、図を増やすことで逆に情報が多くなる可能性を指摘された。そこで、必要な説明を一度にすべて載せるのではなく、学習者の発言に応じて追加する形も検討した。私は教材作成と反応の整理を担当し、友人には説明の点検、先生には内容と方法の確認をしてもらった。相手の誤解を能力の問題と決めず、教材の前提を問い直せたことが大きな学びだった。

今回の成果は、同年代の少人数による教材改善の過程であり、小学生への教育効果を実証したものではない。今後は異なる問題でも同じ誤解が生じるかを確かめたい。大学では教科教育や学習評価を学び、答えの正誤だけでは見えない理解を、どのように捉えて授業へ生かすかを深めたい。
