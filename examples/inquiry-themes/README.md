# 総合型選抜・推薦入試に向けた、架空の探究テーマ18例

- 作成日: 2026-09-26
- 更新日: 2026-09-27

**何を探究したらよいか分からないときに、分野の違う例を読んで、自分の問いを見つけるための読み物です。** 高1頃に大学の募集要項と学べる内容を調べたら、ここを参考に一つの主テーマを選び、[6段階の探究ガイド](../../docs/inquiry-project-guide.md)に沿って始めます。

すべて本教材が作成した**架空の計画と成果報告の例**です。各ページの計画部分と、実施した場合を想定した文面例を分けています。実在の生徒の合格体験記でも、提出用の完成原稿でもありません。動機・仮説・結果や数値を本人の実績として使わず、自分の経験と実際の結果を記録します。

## 文部科学省などにも例はある？

あります。文部科学省の[総合的な学習・探究の時間の資料](https://www.mext.go.jp/a_menu/shotou/sougou/main14_a2.htm)、[情報科の実践事例](https://www.mext.go.jp/a_menu/shotou/zyouhou/detail/mext_01833.html)、JSTの[SSHの事例と成果](https://www.jst.go.jp/cpse/ssh/result/)から探せます。今回確認した実践と、入試で探究を扱う大学の例は[公式資料の読み方と調査メモ](../../docs/inquiry-theme-sources.md)にまとめました。

これらは学習の方法を知る資料です。どのテーマが出願に使え、何が評価されるかは大学・学部・年度・方式で確認します。**本教材の6段階は独自の構成で、文部科学省の公式な6段階分類ではありません。**

## 成果報告の文面は何字くらいがよいか

**読み方を学ぶ教材としては、800〜1,200字程度を勧めます。今回は18例とも約900字に揃えました。** 問い・方法・結果だけでなく、考え直した点、自分の役割、限界と次の課題までを、読み比べやすい長さで示すためです。各ページに、見出し・注記・空白・改行を除いた本文の字数を記載しています。

文面は箇条書きではなく、きっかけから結論へつながる複数の段落で書いています。分野に応じて、資料の比較、観察、制作、実験、シミュレーションなどの方法と、その方法から言える範囲を説明しています。改善案を作った段階と、効果を検証した段階も区別します。

この長さは本教材の編集方針で、大学が共通に指定する字数ではありません。実際に提出する場合は、募集要項の設問・字数・書式・AI利用条件を優先します。長い報告が必要なら、自分の調査方法・根拠・図表・文献を詳しくし、短くする場合も問いと結論、重要な限界を残します。

**文面例の活動・資料の内容・結果・数値は全て架空です。** 実在の原記録や参考文献による裏付けはありません。文章の組み立て方を参考にし、自分の報告には自分の記録と出典を対応させてください。**文面をコピーして自分の提出物や記録にしないでください。** 一人称で書かれていても、これは架空の人物の報告です。

## 大きなテーマは、一回の調査を育てていく軸

「地域を活性化する」「食品ロスをなくす」のような広い目標だけでは、何を確かめたか説明しにくくなります。最初は一施設、一場面、一種類の食品などに絞ります。小さく試した結果から、別の時期や条件で比べ、方法を変え、他者と改善することで継続的な探究になります。

調べたことを並べるだけで終わらず、「資料をどう比較したか」「反例で解釈がどう変わったか」「試作のどこを直したか」を残します。人文系では、仮説を暫定的な解釈、現場で確かめる段階を原典・史料との照合として使えます。すべての分野にアンケートや実験を求めません。

6段階は一度きりの順番ではなく、戻りながら深めます。発信は校内発表、協働は先生や友人との改善から始められます。学校ですでに取り組んでいる探究も使えます。

## 三つを比べ、一つの主テーマを選ぶ

具体的な手順は[テーマの選び方](../../docs/choosing-inquiry-theme.md)で読めます。志望学部から選ぶ方法と、好きなこと・日々の記録から選ぶ方法を用意しました。資料を分析して論文へ深めたいときは、[EEを参考にした15例](../extended-essay/README.md)も比較に使えます。

読み比べるときは、次の表を自分の言葉で埋めます。「大学で学びたいこと」はまだ仮で構いません。

| 比べること | 候補A | 候補B | 候補C |
| --- | --- | --- | --- |
| 気になった例・自分の疑問 |  |  |  |
| 自分の経験とのつながり |  |  |  |
| 今学期に確かめたい一文の問い |  |  |  |
| 使える資料・場所・道具・協力 |  |  |  |
| 必要な時間・費用・同意と、難しければ縮める方法 |  |  |  |
| 最初の一週間にできること |  |  |  |
| 大学でさらに学びたいこと・未確認の授業 |  |  |  |
| やってみたい理由・気になる負担 |  |  |  |

「受かりそう」という印象だけで選ばず、継続して知りたいことと実行できる範囲を相談します。先生と実施条件を確認し、本人が一つを選んだら、[プロジェクト用紙](../../templates/inquiry-project.md)へ6段階全体の見通し・最初の行動日・月ごとと学期末の見直し日を移します。[出願準備計画](../../templates/admissions-plan.md)とは相互にリンクします。

## ChatGPTと一緒に選ぶ

> examples/inquiry-themes/README.mdの18例から、私と主テーマを選ぶ相談をしてください。まず私が気になった例、普段の疑問、好きな教科、使える時間・場所・費用・協力者を聞いてください。私の回答を待ち、関心のある分野と違う分野を含めて三案を比較してください。各案の大きな主テーマ、今学期の問い、方法、6段階の見通し、最初の一週間にできることを示してください。大学の公式な条件とAIの提案を分け、架空例を私の動機・実績に変えないでください。

選んだ後:

> 選んだテーマは［テーマ］、理由は［本人の言葉］です。docs/inquiry-project-guide.mdとtemplates/inquiry-project.mdに沿って、計画案を作ってください。例の場所や方法を私の環境に合わせ、未確認事項と確認する相手を残してください。実施していない段階は完了にしないでください。

案を確認したら、自分用Privateの `projects/<theme>/README.md` へ保存を依頼します。個々の実施記録は `YYMMDD-theme.md` 形式にし、例の本文を活動記録へ丸ごとコピーしません。

## 出願に向けて残しておくこと

本人が実際に行った問いの設定、出典と方法、データや作品の各版、予想との違い、考えの変化、協力者との役割分担を残します。「活動した」という一覧より、**なぜその方法を選び、何を根拠に変えたか**が分かる記録を目指します。ここに示した計画を完了しただけで出願資格や合格が保証されるものではありません。

出願年度には[出願準備・出力ガイド](../../docs/admissions-guide.md)で活動対象期間・設問・AI利用条件を確認します。本人の実記録だけを材料にし、この18例や他の人の研究を本人の実績に混ぜません。
