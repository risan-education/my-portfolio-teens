## どんな関心から始めるか

架空の高校生は、町の記念碑を見ても何が起きたのか分からなかった。被害の大小を競うのではなく、「誰が、何のために残した資料なのか」を調べて地域の歴史を伝えたいと考えた。

- 関連を調べたい学部・学科の分野: **文学・史学・地理**
- 高校生活を通して育てる大きな主テーマ: **地域の歴史と災害の記憶を伝える**
- 最初の問い: **同じ水害について、自治体史・古い地図・新聞では、記述する場所や出来事がどう違うか。**
- 準備・小さな始め方: 図書館の自治体史、利用条件を確認した古地図・新聞、ノート。初回は一つの出来事と二つの資料に絞る。現地へ行けなくても公開資料で始められる。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 碑文を見て気になった言葉と、自分の地域との関わりを書く。 |
| 2. 課題を決める | 一つの水害・一つの地区を選び、資料間の共通点と食い違いを調べる問いにする。 |
| 3. 仮説を立てる | 行政資料は復旧、新聞は直後の出来事を多く記すのでは、と仮の見方を立てる。記述が逆の箇所も探す。 |
| 4. 現場で確かめる | 発行年・作成者・目的・引用箇所を表にし、当時の資料と後年の説明を照合する。地名変更も確認する。 |
| 5. 形にして発信する | 出典付きの小展示を作る。事実として確かめられた内容、解釈、未確認の言い伝えを表示で分ける。 |
| 6. 人を巻き込む | 司書や社会科の先生と資料の読み方を検討し、友人の質問で分かりにくい展示を直す。地域への公開は管理者と相談する。 |

## 方法を具体的にする

最低二種類の資料について、同じ項目で比較する。記載がないことを「出来事がなかった」証拠にしない。聞き取りを追加する場合は目的・記録方法・引用範囲の同意を得て、記憶と同時代資料を別欄にする。災害経験の話を無理に求めない。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 予想と違ったらどうするか

次は**起こり得る展開の架空例**であり、結果の予告ではありません。

新聞に救助より復旧費用の記事が多ければ、仮説に合わせて記事を捨てず、発行時期や読者の違いを調べ直す。資料が少ない地区を単純に「被害が小さい」と扱わない。

## 高1からどう深めるか

高1は一件の資料比較と校内展示。高2は隣接地区または別の年代と比較し、資料が保存される条件へ問いを深める。高3は比較の範囲と未確認部分を明示してまとめる。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

### 成果報告（架空）

私は、町の水害を伝える記念碑を見た際、そこに書かれた短い説明だけでは当時の暮らしが想像できなかったことから、地域に残る災害の記録を調べた。問いは、同じ水害について、地域史、当時の新聞、地図では何が共通して記され、何が異なるかである。初めは、地域史には復旧事業、新聞には救助の様子が多く残ると予想した。

調査では一つの地区と一回の水害に範囲を絞った。図書館で資料の探し方を教わり、作成者、発行時期、目的、記された場所を比較表にした。私は資料の読み取りと表の作成を担当し、先生には古い地名の読み方を確認してもらった。記述が似ていても、同じ原資料を使っている可能性があるため、別々の証拠として数えてよいかも確かめた。

比較すると、地域史では道路や橋の復旧がまとまっていた一方、新聞にも復旧費用の記事があり、最初の予想だけでは資料の違いを説明できなかった。同じ新聞でも、水害直後と後日の記事では扱う内容が異なった。そこで資料の種類だけでなく、出来事から記録されるまでの時間を比較の軸に加えた。地図との照合では、現在とは異なる地名があり、同じ場所の記録を別地区の記録として読んでいた箇所も訂正した。

これらを基に、出来事の経過、資料ごとの記述、分からないことを分けた校内展示を作った。友人から、新聞に出てこない地区は被害が少なかったのかと質問された。しかし、記事がない理由までは資料から判断できない。私は、記録の量を被害の大きさと結び付けて見せていた配置を改め、資料が残っていないことと、出来事がなかったことは別だと説明を加えた。

今回の成果は、水害の全体像を確定したことではなく、資料が作られた時期や目的によって、見える出来事が変わると具体的に示せたことである。ただし、調査した資料は限られ、当時の住民の経験を十分に含んでいない。引用した箇所の所在と自分の解釈を分け、確かめられなかった部分を結論に残した。

私は、最初に立てた予想を守るより、読み違いや反例によって比較方法を変えることの大切さを学んだ。今後は、隣接地区の記録と比べ、どのような情報が保存されやすいのかを調べたい。大学では史料を批判的に読む方法や資料保存の考え方を学び、地域の歴史を、分からない部分も含めて伝えられるようになりたい。
