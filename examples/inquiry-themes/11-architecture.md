## どんな関心から始めるか

架空の高校生は、空いているベンチでも座りたいとは限らないことに気付いた。景色の好みだけでなく、日差しや動線を含めて居場所を設計したい。

- 関連を調べたい学部・学科の分野: **建築・都市・環境デザイン**
- 高校生活を通して育てる大きな主テーマ: **気候と人の使い方に合う空間**
- 最初の問い: **日陰・日なた・屋内にある休憩候補地では、時間帯によって環境と利用可能な条件がどう違うか。**
- 準備・小さな始め方: 学校の許可を得た平面図、温湿度計、日陰の記録、紙の模型。暑い時間帯の調査を無理に行わず、安全な範囲で先生と計画する。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 自分が休みやすい場所の条件を挙げ、他の人とは違う可能性を残す。 |
| 2. 課題を決める | 校内の三地点程度に絞り、同じ時間帯で比較する項目を決める。 |
| 3. 仮説を立てる | 日陰の面積だけでなく、風通しや移動経路も場所選びに関係しそうだと予想する。 |
| 4. 現場で確かめる | 複数日に同時刻の環境を測り、天候・測器の高さ・日陰の位置を記す。動線や通行を妨げないかも図面で確認する。 |
| 5. 形にして発信する | 休憩スペースの模型と配置案を作り、環境条件・運営条件・未確認点を説明する。 |
| 6. 人を巻き込む | 施設担当の先生や友人と避難動線・維持管理を点検し、案を改良する。実際の設置は管理者に相談する。 |

## 方法を具体的にする

測器への直射日光など測定方法の違いを揃える。気温だけで人体の安全や快適性を確定せず、温度の測定と本人の感想を分ける。利用者を撮影して属性を推定しない。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 予想と違ったらどうするか

次は**起こり得る展開の架空例**であり、結果の予告ではありません。

涼しい候補地でも授業の移動経路から遠ければ使いにくい。環境測定だけで決めず、利用場面と配置の問いに戻る。

## 高1からどう深めるか

高1は一季節の観察と模型。高2は季節・時間帯の違いを比べ、維持管理の制約も加える。高3は採用案と別案の比較、測れなかった条件をまとめる。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

### 成果報告（架空）

私は、校内に空いているベンチがあっても、休憩したいと思える場所とは限らないことに気付いた。そこで、休憩場所のよさを見た目や席数だけでなく、日差し、時間帯、移動のしやすさから考える探究を行った。校内の三地点を候補にし、それぞれがどのような場面で使いやすいかを比べた。

学校の許可を得て、先生と相談した安全な時間帯に観察した。温湿度の測定では、測器の高さや置き方を揃え、日陰の範囲、天候、近くの通路を記録した。同じ時刻に測れるよう友人と分担し、観察日を変えて比べた。私は配置図と記録表を作り、測定方法を途中で変えた場合は、その前後を同じ条件として扱わないようにした。

調査すると、一日の中で日陰になる時間が違い、朝に使いやすく見えた場所が昼にも同じとは限らなかった。また、環境条件だけでは良い候補に見えても、教室から遠く、短い休み時間には移動しにくい地点があった。私は、温度が低い場所を選ぶという最初の考えを見直し、いつ、何分くらい使う場所なのかを先に決めることにした。

その結果を基に、既存の場所を使う案と、日陰を補う設備を置く案を模型にした。施設担当の先生に見てもらうと、人が集まることで通路や避難時の動きを妨げる可能性が指摘された。友人からは、座る向きによって話しやすさが変わるという意見も出た。私は模型の配置を直し、環境条件、動線、維持管理の三つを比較表にまとめた。

校内発表では、一つの場所を最良とするのではなく、短時間の休憩と長めの滞在では選ぶ条件が異なると説明した。成果は、観察結果に基づく配置案と、その案を採用するときに確認すべき事項を示せたことである。ただし、一季節の限られた観察であり、快適さを利用者全体について測ったわけではない。気温だけで人体の安全性を判定することもできず、実際の設備設置は行っていない。

私は、空間を設計するには、一つの数値だけで判断せず、人の使い方と運営上の条件を重ねて考える必要があると学んだ。今後は別の季節にも観察し、利用場面が変わると案の評価がどう変わるかを確かめたい。大学では建築環境や都市計画を学び、測定と利用者の経験を結び付けて空間を考えられるようになりたい。
