## どんな関心から始めるか

架空の高校生は、観光案内を直訳しても友人が場所を理解できない場面に出会った。語学力だけでなく、地名の前提知識や地図との対応を調べたい。

- 関連を調べたい学部・学科の分野: **国際・外国語・観光**
- 高校生活を通して育てる大きな主テーマ: **言語や経験の違いを越える地域案内**
- 最初の問い: **一施設への案内で、短い日本語・外国語・図記号をどう組み合わせると、行き先と利用方法が伝わるか。**
- 準備・小さな始め方: 利用条件を確認した地域地図、公開案内、自作の案内カード。まず校内の架空課題で試し、外部の人への協力依頼は先生を通して計画する。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 伝わらなかった言葉と、相手が必要としていた情報を分けて記す。 |
| 2. 課題を決める | 一施設の入口までの案内など、狭い課題に絞る。 |
| 3. 仮説を立てる | 直訳だけの案内より、地図と短文を組み合わせる方が判断しやすいのではと考える。 |
| 4. 現場で確かめる | 案内の内容を揃えた複数案を用意し、同意した協力者に地図上で場所と手順を示してもらう。迷う理由を聞く。 |
| 5. 形にして発信する | 案内カードを制作し、訳の確認者、地図の出典、分かりにくさをどう直したかを記す。 |
| 6. 人を巻き込む | 外国語の先生や地域施設の担当者と検討する。可能なら異なる日本語経験を持つ希望者の意見を受けて改善する。 |

## 方法を具体的にする

国籍だけで言語能力やニーズを決めない。翻訳は意味が変わっていないか確認し、AI訳を正解扱いしない。少人数の評価から「外国人全員に伝わる」と言わず、対象の経験・利用場面の限界を記す。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 高1からどう深めるか

高1は一施設への案内。高2は利用規則や周辺施設へ範囲を広げ、文化的前提の違いも調べる。高3は言語の選択理由と改善履歴をまとめる。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

### 成果報告（架空）

私は、地域の施設への道順を説明したとき、言葉を別の言語に訳すだけでは場所が伝わらないことに気付いた。地元の人には分かる建物の呼び名も、初めて来た人には手掛かりにならないかもしれない。そこで、一つの施設の入口を探す場面に絞り、短い文章、地図、図記号の組合せを考えた。

まず、公開されている案内の利用条件を確かめ、施設名、目印、入口、利用時の確認事項を整理した。同じ内容について、文章を中心にした案と、地図に短文を添えた案を作った。外国語の表現は先生に意味を確認してもらい、AIの翻訳だけで正しいとは判断しなかった。地域をよく知る人に有利になり過ぎないよう、最初の点検には架空の地図も使った。

同意した友人に案内を見てもらい、目的地と入口を地図上で示してもらったところ、地図を添えても入口の位置を取り違える場面があった。私は図記号があれば伝わると予想していたが、建物全体を指す印と、実際に入る場所を示す印を区別していなかった。また、近くの目印から案内の矢印が始まっていないため、道順のつながりが分かりにくいという意見も出た。

私は、入口の印と施設名の表示を分け、同じ目印を文章と地図で対応させた。外国語の先生には修正後も意味が変わっていないかを見てもらった。地域施設の担当者からは、使える入口が曜日で変わる場合もあると指摘され、確認先を記す欄を加えた。初めの案に情報を足し続けるのではなく、道順と利用条件を分けて示す構成にした。

成果として、案内カードの試作と、修正理由を説明する比較資料を作り、校内で発表した。今回確かめたのは主に同年代の少人数が地図を読む場面であり、外国語話者や実際の観光客への効果はまだ分からない。国籍から言語能力を推測したり、全ての人に分かる案内だと主張したりはできない。私は情報の整理と制作を担当し、訳と施設条件について助言を受けた。

この探究で、伝わらない理由を相手の語学力だけに求めず、自分が当然と考えていた知識を見直すことを学んだ。今後は、異なる経験を持つ希望者の協力を得られる方法を先生と相談したい。大学では言語や異文化コミュニケーション、観光情報を学び、受け手の前提が違うことを踏まえた案内の作り方を深めたい。
