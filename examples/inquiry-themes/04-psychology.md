## どんな関心から始めるか

架空の高校生は、友人の見落としを「不注意な性格」と片付けず、情報の配置が関係するのかを調べたいと思った。

- 関連を調べたい学部・学科の分野: **心理・認知科学**
- 高校生活を通して育てる大きな主テーマ: **注意と情報の見つけやすさ**
- 最初の問い: **同じ内容のお知らせで、締切の位置と見出しの付け方を変えると、必要な情報を探す過程はどう変わるか。**
- 準備・小さな始め方: 架空のお知らせ、紙または端末、記録表。教員に計画を確認してもらい、同意した少人数の同年代の協力で予備調査を行う。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 自分が締切を見落とした状況を振り返り、性格以外の可能性を挙げる。 |
| 2. 課題を決める | 一回目は見出しの有無だけに絞り、「締切を見つける」という同じ課題で比べる。 |
| 3. 仮説を立てる | 見出しがある方が見つけやすいと予想し、逆に情報が多く感じられる可能性も書く。 |
| 4. 現場で確かめる | 同程度の二種類の架空文面を用意し、提示順と文面の割当てを入れ替える。正誤・探索時間・迷った箇所を匿名で記録する。 |
| 5. 形にして発信する | 平均だけでなく各試行のばらつきも示し、情報配置の改善案を発表する。 |
| 6. 人を巻き込む | 友人と情報委員の助言で案を直し、次は締切の位置だけを変えて調べる。 |

## 方法を具体的にする

同じ文面の答えを覚える影響、端末への慣れ、読む速さを検討する。集めるのは課題中の反応だけで、性格・障害・能力を判定しない。途中中止を認める。少人数の予備調査では効果を一般化せず、測り方の改善も成果として残す。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 予想と違ったらどうするか

次は**起こり得る展開の架空例**であり、結果の予告ではありません。

見出しがある版でも誤答が出れば、字を大きくし続ける前に、質問の表現や日付の複数記載が原因かを点検する。

## 高1からどう深めるか

高1は小規模な予備調査で方法を整える。高2は一度に変える条件を絞り、別の文面で再検討。高3は仮説の修正と、分かった範囲・分からない範囲をまとめる。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

## 残す証拠と、大学で学びたいこと

**残すもの:** 調査計画、刺激文面各版、提示順、匿名データ、除外や中止の理由、解釈の変化。

**大学での学びとの接点:** 認知心理学、実験計画、統計。性格診断ではなく、注意を調べる方法への関心として大学の授業と照合する。

出願用に整理するときは、本人が実際に取り組んだ問い・方法・変更・役割を原記録で確かめます。出願先の募集要項で活動の対象期間・評価方法・提出物・AI利用条件を確認し、[出願準備ガイド](../../docs/admissions-guide.md)に沿って許可された範囲だけ出力します。この架空例を本人の実績には含めません。

### 成果報告（架空）

私は、学校のお知らせで締切を見落とした経験から、見落としを本人の注意不足だけで説明してよいのか疑問を持った。そこで、同じ情報でも見出しの付け方によって探し方が変わるかを調べた。最初の調査では、文字の大きさや色を同時に変えず、見出しの有無に対象を絞った。

教員に計画を確認してもらい、長さや構成を近づけた二種類の架空の行事案内を用意した。それぞれに見出しのある版とない版を作り、協力に同意した友人八人に締切を探してもらった。各人には内容の異なる案内を一つずつ見てもらい、見出しの有無と見る順番が偏らないようにした。正誤、探すまでの時間、迷った箇所を記録し、性格や成績の情報は集めなかった。

見出しがある版では締切付近へ早く目を向ける様子が見られたが、正しく答えられるとは限らなかった。特に、申込期限と資料の提出期限を近くに書いた案内では、見出しがあっても別の日付を答える場面があった。このため、私は速さだけで分かりやすさを評価する計画を変更し、何の日付だと理解したかも確かめることにした。

情報委員の友人と見直した結果、締切という見出しだけでは、複数の手続を区別できないと考えた。そこで、申込と資料提出の欄を分け、誰が何をいつまでに行うかを対応させた試作を作った。私は案内の作成と記録の整理を担当し、友人には実際に迷った理由の説明を依頼した。授業内の発表では、変更前後の案だけでなく、最初の比較で分からなかった点も示した。

今回の調査から、情報を目立たせることと、意味を取り違えずに理解できることは別に点検する必要があると考えた。ただし、参加者は少人数の友人で、文章の違いも完全には揃えられていない。時間の差を一般的な効果として示すことや、見出しによって見落としが解消すると断定することはできない。修正版についても、独立した参加者での検証はまだ行っていない。

私にとっての成果は、見出しを付ければよいという単純な予想から、情報の分類と理解の関係を調べる問いへ進めたことである。今後は日付の位置を変える調査と、手続の表現を変える調査を分けて行いたい。大学では認知心理学や実験計画を学び、見落としを人の性格と決めつけずに検討する方法を身に付けたい。
