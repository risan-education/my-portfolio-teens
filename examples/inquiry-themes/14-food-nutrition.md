## どんな関心から始めるか

架空の高校生は、食べ残しを減らそうと言うだけでは家族の行動が変わらないことに気付いた。責めるための記録にせず、生活の流れを見直す。

- 関連を調べたい学部・学科の分野: **食物・栄養・生活科学**
- 高校生活を通して育てる大きな主テーマ: **暮らしの仕組みと食品ロス**
- 最初の問い: **使い切れずに残る食品を記録すると、買い方・保存場所・献立変更のどこに改善の手掛かりがあるか。**
- 準備・小さな始め方: 家族の同意を得た家庭内記録、食品の分類表、必要ならはかり。氏名・健康情報・家計の詳細は集めない。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 自分が使い切れなかった食品と、そのときの予定や事情を思い出す。 |
| 2. 課題を決める | まず一家庭・数週間に絞り、食べられる部分の残りと皮などの区分を決める。 |
| 3. 仮説を立てる | 使う予定が見えにくい食品が残りやすいのでは、と予想する。 |
| 4. 現場で確かめる | 種類・量・理由・在宅人数・特別な行事を無理のない範囲で記録し、一つの変更を試した期間と比べる。 |
| 5. 形にして発信する | 使う予定を共有するメモや在庫表を作り、負担と変化を含めて発表する。 |
| 6. 人を巻き込む | 家族や家庭科の先生と続けやすさを相談し、記録項目と改善案を見直す。 |

## 方法を具体的にする

一家庭の前後比較では、外食・旅行・人数の違いなどを分けて考える。記録忘れをゼロと扱わず、重量が不明なら不明とする。傷んだ食品を食べる、期限を独自判断で延ばすなどの実験は行わず、商品の表示と公的な取扱情報に従う。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 高1からどう深めるか

高1は記録法と小さな改善。高2は季節や生活予定の違いを比較し、希望する別家庭とは個人情報を出さない集計方法を相談。高3は変化と負担、一般化できない範囲をまとめる。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

## 残す証拠と、大学で学びたいこと

**残すもの:** 分類ルール、元記録、欠測、試した変更と期間、在庫表各版、家族の同意と本人の担当。

**大学での学びとの接点:** 食生活学、食品流通、生活経営、栄養教育。食品ロスの量だけでは栄養状態は分からないことも踏まえ、大学の授業との接点を調べる。

### 成果報告（架空）

私は、家庭で食品を使い切れなかったとき、気を付けるよう声を掛けるだけでは同じことが繰り返されると感じた。そこで、誰かの責任を探すのではなく、食品が余る場面と生活の予定を記録し、使う予定を共有する仕組みを考えた。最初は、買った量よりも、在庫や献立の情報が家族に伝わらないことが関係すると予想した。

家族に目的と記録範囲を説明し、同意を得て四週間の記録を始めた。前半の二週間は普段の状態を見て、後半には使う予定を示すメモを試した。食べられる部分の残りと皮などを分け、種類、量、余った理由、在宅人数や外食の予定を記した。計量できなかったものは不明とし、記録がない日を食品ロスがなかった日とは扱わなかった。

初めの記録では、食品が奥にあって気付かなかった場合だけでなく、帰宅が遅くなり予定した料理を作らなかった場合も見られた。私は全ての食品を細かく登録する在庫表を作ったが、家族から更新に時間がかかるという意見が出た。表が正確でも使われなければ役に立たないため、近いうちに使うものだけを短く書く形へ変更した。

変更後には、メモを見て食材を別の料理へ使ったと家族から報告される場面があった。一方、後半は前半より外食の回数も違っていたため、残った量の差をメモの効果と断定することはできなかった。私は単純な合計の比較をやめ、余った理由と、メモを実際に参照した場面を並べて考察した。傷んだ食品を無理に食べるなど、量を減らすことだけを優先する行動は求めなかった。

家庭科の授業では、記録表の変更と、使い続ける負担について発表した。成果は、家庭の予定と食品の情報をつなぐ小さな仕組みを作り、続けやすさを含めて評価できたことである。私は分類と記録の整理、家族は利用時の感想を担当した。一家庭の短期間の観察なので、ほかの家庭や季節に同じ方法が合うかは分からず、栄養状態を評価したものでもない。

この探究から、望ましい行動を呼び掛けるだけでなく、それが生活の中で実行できる条件を考える必要があると学んだ。今後は忙しい時期にも使えるかを確かめ、記録の負担を増やさずに比較する方法を見直したい。大学では食生活や食品流通、生活経営を学び、食品を大切に使うことと暮らしやすさを両立させる方法を考えたい。
