## どんな関心から始めるか

架空の高校生は、校庭の端と通路脇で生えている草が違うことに気付いた。珍しい生物を見つけるだけでなく、違いを継続して測る方法を知りたい。

- 関連を調べたい学部・学科の分野: **理・生物・環境**
- 高校生活を通して育てる大きな主テーマ: **身近な土地利用と生物多様性**
- 最初の問い: **校庭の管理や踏まれ方が異なる場所では、観察できる植物の種類や被度はどう違うか。**
- 準備・小さな始め方: 図鑑、方形の観察枠または位置図、カメラ、管理記録を確認する先生。採取せず観察し、立入禁止区域には入らない。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 気になった場所を写真とメモで残し、見た目の印象と確かな同定を分ける。 |
| 2. 課題を決める | 同じ面積の観察区を複数設け、比較する時期と記録項目を決める。 |
| 3. 仮説を立てる | 踏まれる場所では植物の高さや種類が違うのではと予想し、日当たりなど別の要因も挙げる。 |
| 4. 現場で確かめる | 一定の方法で種類・被度・高さを記録し、同定できないものは仮番号にする。草刈り日・天候・日当たりを可能な範囲で確認する。 |
| 5. 形にして発信する | 季節ごとの変化と場所の違いを地図と図表にまとめ、未同定のものを含めて校内発表する。 |
| 6. 人を巻き込む | 生物の先生や管理担当者と結果を検討し、次年度も比べられる観察手順を友人と作る。 |

## 方法を具体的にする

一地点の中で何度も測った値だけで、場所の違いを十分に確かめたとしない。複数の観察区を取り、季節と管理の違いが混ざる限界を書く。希少種や傷みやすい場所の詳しい位置は公開しない。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 予想と違ったらどうするか

次は**起こり得る展開の架空例**であり、結果の予告ではありません。

種類の差が草刈りより日当たりと対応していそうなら、「草刈りが原因」と結論しない。同じ日照条件の比較へ計画を修正する。

## 高1からどう深めるか

高1は同定と測定の練習、一季節の比較。高2は同じ区画で季節を追い、条件を揃えた比較を追加。高3は継続観察から言える範囲をまとめる。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

### 成果報告（架空）

私は、校庭の端と通路の脇で草の見た目が違うことに気付き、人の通り方や管理が植物とどう関係するのかを調べた。最初は、踏まれやすい場所ほど植物の種類が少ないと予想した。しかし、見た印象だけでは比べられないため、同じ面積の観察区を設け、種類と地面を覆う割合を継続して記録することにした。

学校の許可を得て、通路沿いと校庭の端に複数の観察区を置いた。同じ区画を繰り返し見られるよう位置を記録し、一定の間隔で写真と観察表を残した。植物は採取せず、図鑑で分からないものには仮番号を付けた。私は観察と写真整理を担当し、生物の先生には同定の根拠を確認してもらった。草刈りの時期は管理担当の先生に尋ねた。

観察では、通路沿いに背の低い植物が目立つ区画があった一方、種類の数は一様には違わなかった。校庭の端でも日陰になる区画では見られる植物が異なり、草刈りの後には同じ場所の見た目も変化した。私は、場所の名前だけで二群に分ける方法を見直し、日当たりと草刈りからの経過を記録表に加えた。

また、初めに同じ種類だと思った植物を、写真を見直して別の仮番号に分けることがあった。訂正前の表を消さず、どの特徴から判断を変えたかを残した。友人と観察手順を試すと、地面を覆う割合の見積もりにも差が出たため、同じ写真を見て基準を相談した。記録の差が植物の変化なのか、観察者の判断の違いなのかを考える必要があると分かった。

成果は、場所ごとの観察記録と、次の時期にも使える手順書である。校内発表では、植物の違いを示すとともに、踏まれることが原因だとは断定できないと説明した。日照や管理などの条件を十分に揃えておらず、観察回数を増やしても独立した場所の数が増えるわけではない。未同定の植物もあり、種類数そのものに不確かさが残っている。

私は、生物の名前を知ることに加え、比較する条件と記録方法を整えることが探究に欠かせないと学んだ。今後は日当たりの近い場所同士を比べ、同じ区画を季節を変えて観察したい。大学では生態学や環境統計を学び、身近な観察からどこまで説明できるかを慎重に考えながら、土地の使い方と生物の関係を深めたい。
