## どんな関心から始めるか

架空の高校生は、得意な人に役割が集中する活動を見て、競技成績だけでなく参加の機会に関心を持った。

- 関連を調べたい学部・学科の分野: **スポーツ・体育・健康科学**
- 高校生活を通して育てる大きな主テーマ: **参加のしやすさとルール設計**
- 最初の問い: **軽い協力型のボール活動で、役割交代の仕方を変えると、待ち時間や参加機会はどう変わるか。**
- 準備・小さな始め方: 体育の先生が安全を確認した通常授業程度の活動、既存の用具、記録表。運動が難しい場合は机上の模擬進行から始められる。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 役割が偏ると感じた場面と、自分が楽しめた条件を挙げる。 |
| 2. 課題を決める | 動作の難しさを上げずに、交代ルール一つだけを変える問いにする。 |
| 3. 仮説を立てる | 固定役割より一定時間で交代する方が、参加機会の偏りを減らせるのではと予想する。 |
| 4. 現場で確かめる | 教員の指導と参加者の同意の下、通常ルールと変更案の役割回数・待ち時間を記録する。実施が難しければ模擬条件で比較する。 |
| 5. 形にして発信する | 活動案と、楽しさの感想・参加機会の記録が一致しない点も発表する。 |
| 6. 人を巻き込む | 体育の先生と希望する友人で役割を分担し、安全・説明の分かりやすさ・進行の負担から改良する。 |

## 方法を具体的にする

体力の限界を試す運動、睡眠や食事の制限は行わない。参加・中止・見学を本人が選べるようにし、診断や身体情報を集めない。集団の組合せや慣れが結果に影響するため、ルールだけの効果と断定しない。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 予想と違ったらどうするか

次は**起こり得る展開の架空例**であり、結果の予告ではありません。

参加回数が均等でも本人が望まない役割が増えたら、回数だけで良い活動とせず、選べる役割と交代の方法を見直す。

## 高1からどう深めるか

高1は観察と模擬進行。高2は安全な範囲の試行を重ね、違う集団・活動でも条件を検討。高3は参加機会と選択の両立をまとめる。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

## 残す証拠と、大学で学びたいこと

**残すもの:** 活動計画、安全確認、実施または模擬の区別、匿名の参加記録、変更履歴、自分の進行・分析の担当。

**大学での学びとの接点:** スポーツ教育学、スポーツ社会学、指導法。運動能力の向上を実証したとはせず、参加環境を考えた過程を説明する。

出願用に整理するときは、本人が実際に取り組んだ問い・方法・変更・役割を原記録で確かめます。出願先の募集要項で活動の対象期間・評価方法・提出物・AI利用条件を確認し、[出願準備ガイド](../../docs/admissions-guide.md)に沿って許可された範囲だけ出力します。この架空例を本人の実績には含めません。

### 成果報告（架空）

私は、協力して行う運動でも、慣れた人に役割が集まり、ほかの人が待つ時間が長くなる場面に疑問を持った。参加しやすさを、運動能力が高まったかとは別の観点で考えたいと思い、軽いボール活動の交代ルールに注目した。固定した役割より、一定時間で交代する方が参加機会の偏りを減らせると予想した。

体育の先生と安全な活動と手順を相談し、参加や見学を自分で選べる形で実施した。動作の難しさを上げず、同じ時間の活動で役割を固定する条件と交代する条件を試した。二つのグループで実施順を入れ替え、役割ごとの回数と待ち時間を記録した。私は進行案と記録表を作り、友人に回数の確認を手伝ってもらった。

交代する条件では担当の回数が近くなる場面があったが、活動後の感想は一様ではなかった。待つ時間が減って参加しやすかったという意見がある一方、慣れない役割へ急に替わると落ち着かないという意見も出た。私は、回数が等しければ全員が参加しやすいと考えていたが、本人が選べるか、役割を理解する時間があるかも重要だと気付いた。

そこで、交代前に次の役割を知らせる時間を設け、希望すれば補助役を選べる案を作った。先生からは、選択を認めても特定の人がずっと補助に固定されないよう、本人の希望をその都度確認する必要があると助言された。私は、ルールの説明を短く書き直し、回数だけでなく、変更を希望した場面も残す記録方法へ修正した。

授業内の発表では、初めの二条件の比較と、そこから考えた修正案を分けて示した。成果は、参加機会を回数だけで評価する限界を見つけ、選択と見通しを含む活動案へ進めたことである。修正案の効果はまだ検証していない。また、参加者の組合せや慣れも結果に関係するため、最初の差を交代ルールだけの効果とは断定できない。身体能力や健康状態を測った調査でもない。

私は、活動に参加しているように見えることと、本人が参加しやすいと感じることを分けて確かめる必要があると学んだ。今後は先生の指導の下で修正案を試し、説明や進行の負担も点検したい。大学ではスポーツ教育やスポーツ社会学を学び、得意な人も不慣れな人も、自分の関わり方を選びながら参加できる場を考えたい。
