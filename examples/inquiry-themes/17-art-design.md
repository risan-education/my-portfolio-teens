## どんな関心から始めるか

架空の高校生は、作品の意図を説明し過ぎると見る人の解釈を狭めるのではと気になった。作者の意図が伝わることと、自由な鑑賞の双方を考える。

- 関連を調べたい学部・学科の分野: **芸術・美術・デザイン**
- 高校生活を通して育てる大きな主テーマ: **作品と鑑賞者をつなぐ展示**
- 最初の問い: **同じ自作作品に事実説明・作者の意図・問いかけのラベルを付けると、鑑賞者は何に注目し、どう語るか。**
- 準備・小さな始め方: 自作作品、三種類の短いラベル、校内の展示場所または机上展示。作品や鑑賞者の撮影・コメント掲載はそれぞれ同意を得る。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 自分が説明を読む前後で印象が変わった経験と、展示で大切にしたいことを書く。 |
| 2. 課題を決める | まず一作品に絞り、文字量や配置を揃えてラベルの役割を比較する。 |
| 3. 仮説を立てる | 問いかけは解釈を広げるかもしれないが、答えを求められる負担にもなると予想する。 |
| 4. 現場で確かめる | 同意した鑑賞者に異なるラベルを見てもらい、注目した部分と言葉を記録する。繰り返し見る影響を避ける割当ても考える。 |
| 5. 形にして発信する | 作品とラベルの改訂案、反対の感想を含む考察を小展示にする。 |
| 6. 人を巻き込む | 美術の先生や友人と、作者の意図の伝え方と鑑賞者の選択を話し合い、展示の順路も改善する。 |

## 方法を具体的にする

感想を良い・悪いで採点せず、注目点の分類ルールを示す。同じ感想が複数の分類に入ることも認め、少数の反応から普遍的な鑑賞効果を主張しない。ラベル以外の照明・展示順・作品への好みの影響を考える。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 予想と違ったらどうするか

次は**起こり得る展開の架空例**であり、結果の予告ではありません。

問いかけが正解当てのように受け取られたら、言葉を直すか、説明を読むか選べる展示に戻す。望んだ反応だけを集めない。

## 高1からどう深めるか

高1は自作一点で小展示。高2は作品の媒体や展示場所を変えて比較し、自分の制作にも反映。高3は作品集に加え、問い・検証・修正の記録をまとめる。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

## 残す証拠と、大学で学びたいこと

**残すもの:** 作品とラベルの各版、展示条件、許可された匿名コメント、分類と反例、共同展示での本人の担当。

**大学での学びとの接点:** 美術教育、博物館学、視覚伝達、展示デザイン。芸術系で指定される作品集や実技は、探究報告と別の提出条件として確認する。

出願用に整理するときは、本人が実際に取り組んだ問い・方法・変更・役割を原記録で確かめます。出願先の募集要項で活動の対象期間・評価方法・提出物・AI利用条件を確認し、[出願準備ガイド](../../docs/admissions-guide.md)に沿って許可された範囲だけ出力します。この架空例を本人の実績には含めません。

### 成果報告（架空）

私は、自分の作品について説明すると、鑑賞者の見方を助ける場合と、逆に決められた答えへ誘導する場合があるのではないかと考えた。そこで、同じ自作作品に添えるラベルを変え、鑑賞者が何に注目して語るかを調べた。作者の意図を伝えることと、自由な解釈を認めることの両方を大切にしたかった。

一つの作品について、制作上の事実を説明するラベル、作者の意図を伝えるラベル、問いかけるラベルの三案を作った。文字量と置く位置をできるだけ揃え、同意した友人九人に、初回は一人一種類だけを見てもらった。作品への注目点と感想を記録し、感想をよい、悪いで採点しないこと、公開する場合は別に確認することを伝えた。

作者の意図を示すラベルを見た人からは、その説明に沿って作品を捉える発言があった。一方、問いかけのラベルでは、自分の経験と結び付ける感想だけでなく、正しい答えを求められているようで迷うという反応も出た。私は、問いを置けば解釈が広がるという予想を見直した。同じ形式でも、自由を感じる人と負担を感じる人がいることを無視できなかった。

感想の整理では、色、構図、物語、自分の経験という観点を作ったが、一つの感想が複数に当てはまることがあった。美術の先生から助言を受け、無理に一分類へ押し込まず、重なりを残す方法に変えた。友人との話し合いでは、説明を読む前に作品だけを見る時間が欲しいという意見もあり、ラベルを横に置いて読むか選べる展示案を作った。

小展示では、作品と三つのラベル、受けた反応から修正した理由を説明した。成果は、作者の説明を伝える量だけでなく、鑑賞者が説明との距離を選べる配置を考えたことである。ただし、一作品と少人数の感想であり、ラベルによる効果を一般化することはできない。人ごとの好みも異なり、修正した配置の効果も未検証である。制作、分類、考察は私が担当し、先生と友人から異なる見方を得た。

私は、作品の意図がそのまま伝わることだけを成功とするのではなく、意図と異なる受け取り方にも向き合う必要があると学んだ。今後は別の作品や展示場所でも、説明を読む選択が鑑賞にどう関わるかを考えたい。大学では美術や展示デザイン、博物館での学びを深め、作品と鑑賞者の関係を丁寧に設計したい。
