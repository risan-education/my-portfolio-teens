## どんな関心から始めるか

架空の高校生は、最短の行程でも乗換がぎりぎりでは不安だと感じた。誰にとって良い行程なのかを、数学的な条件として表すことに関心を持つ。

- 関連を調べたい学部・学科の分野: **数学・データサイエンス・交通**
- 高校生活を通して育てる大きな主テーマ: **制約のある移動をモデルで考える**
- 最初の問い: **公開時刻表に基づく二つの行程案は、待ち時間・乗換回数・遅延への余裕という基準でどう変わるか。**
- 準備・小さな始め方: 利用条件を確認した交通事業者の公開時刻表、紙または表計算。移動目的・出発地は架空にし、自宅や通学経路を公開しない。

## 6段階の進め方

以下はすべて未実施の計画です。実際の記録では、本人が選んだ案・行ったこと・結果を分けます。

| 段階 | このテーマでの計画 |
| --- | --- |
| 1. 興味を見つける | 移動で大事にしたい条件を挙げ、最短時間だけでは足りない理由を書く。 |
| 2. 課題を決める | 一つの架空の出発地と目的地に絞り、同じ曜日・時間帯で比較する。 |
| 3. 仮説を立てる | 最短の案より乗換余裕を持つ案の方が、仮定した遅延に強いかもしれないと予想する。 |
| 4. 現場で確かめる | 時刻表を表にして行程を列挙し、徒歩時間や乗換時間の仮定を変えて計算する。手計算で一例を点検してから自動化する。 |
| 5. 形にして発信する | どの条件でどの案が良いかを図にし、一つだけの「最適解」に決められない理由を発表する。 |
| 6. 人を巻き込む | 数学の先生や友人と仮定と計算を点検し、可能なら交通に詳しい担当者の助言を受けて現実との差を見直す。 |

## 方法を具体的にする

ダイヤの有効期間・平日休日・運休日を確認する。仮定した遅延は実測ではなく、混雑や実際の乗換可能性も別に検証が必要。計算上の行程を実利用の安全・到着保証として案内しない。

最初の学期は準備・予備調査・最初の改善までを目安に、授業や部活動と両立する時間を決めます。必要な協力が得られなければ、資料調査や紙の試作へ範囲を縮め、未実施の段階は理由と再検討日を記して残します。

## 予想と違ったらどうするか

次は**起こり得る展開の架空例**であり、結果の予告ではありません。

待ち時間を減らした案で乗換回数が増えれば、重みの付け方で結論が変わることを示す。自分の重みを全利用者の好みとしない。

## 高1からどう深めるか

高1は小さい範囲で手計算とモデルを理解。高2は条件の変化や別目的地を加え、計算手順を改善。高3はモデルの価値と現実を省略した部分をまとめる。

月ごとに次の行動を、学期末に主テーマと方法を見直します。ここに書いた学年配分は目安です。高2・高3から始める場合は範囲を絞り、実施していない過去を補わないでください。

### 成果報告（架空）

私は、移動経路を調べるとき、到着が最も早い案でも、乗換時間が短いと選びにくいことがあると感じた。そこで、行程のよさを所要時間だけで決めず、乗換回数と遅れへの余裕を含めて比較した。問いは、同じ出発地と目的地について、評価する条件を変えると望ましい行程がどう変わるかである。

公開時刻表を読む練習をした後、比較の仕組みを確かめるため、架空の路線と時刻表を作った。平日の同じ出発時刻で、二回乗り換えて早く着く案と、一回の乗換で少し遅く着く案を設定した。徒歩の移動に必要な時間を別に置き、乗換余裕は、接続までの時間から移動時間を引いて求めた。私は表計算を作る前に一例を手計算し、式と照合した。

出発から到着までが短い案は、最も厳しい乗換箇所の余裕が二分だった。もう一つの案は到着が八分遅い代わりに、乗換余裕を七分確保できた。先行する便が三分遅れるという条件を置くと、前者は予定した接続を使えず、後者は計算上接続できた。ただし、この遅れは実際の発生頻度を調べた値ではなく、条件の違いを見るための仮定である。

初めは、所要時間と乗換回数に重みを付けて一つの点数にまとめた。しかし友人から、時間を優先する日と、乗換を少なくしたい日では選び方が違うと指摘された。そこで重みを変えた結果を示し、どの条件で順位が入れ替わるかを図にした。数学の先生には、比較の単位や式を点検してもらい、自分で仮定の一覧を修正した。

発表では、一つの最適な行程を全員へ勧めるのではなく、何を優先するとどの案が選ばれるかを説明した。成果は、時間、乗換、余裕を分けて確認できる比較表を作れたことである。一方、混雑や実際の歩行経路、遅延の分布は調べていない。架空の時刻表による結果なので、現実の交通の到着保証や利用案内には使えない。公開時刻表に置き換える調査は今後の課題として残した。

私は、計算の答えが一つに決まっても、何を目的にするかの選択には人の希望が関わると学んだ。今後は、公開資料の有効期間や運休日を確かめて実際の条件に近づけ、モデルが省略した部分を調べたい。大学では数学、データサイエンス、交通計画を学び、数値だけでは決められない条件も明示した上で、選択を助ける方法を考えたい。
