# 【架空例】探究記録を出願用の材料へ整理する

- 作成日: 2026-09-26
- 更新日: 2026-09-26

このページは[出力シート](../templates/admissions-output.md)の架空教材です。大学・条件・出力は説明用で、実在大学の要項や提出実績ではありません。実利用では本人の記録と公式要項に置き換えます。[手順](../docs/admissions-guide.md)

## 条件の扱いを先に決める

| 状況 | この教材での出力 |
| --- | --- |
| AI利用条件が未確認 | 不明な条件と確認先を整理する。提出本文・構成案は作らない |
| 今回の作業が禁止 | AI作成・添削へ進まない。本人が条件に沿って作成する |
| 今回の作業が許可され、根拠を確認済み | 許可された範囲で根拠を整理し、本人の確認へ進む |

以下だけは「AIによる材料整理と短い活動報告案の作成が許可された」という架空の条件です。実在大学へ一般化できません。

- 架空の設問: 探究で取り組んだことと、見直した点を短く説明する。
- 字数・様式: この教材では指定なし。実際には要項で確認する。
- 対象: [図書コーナーの探究例](inquiry-project/README.md)の実施記録だけ。
- 除外: 学部への志望動機、受賞、未実施のウェブ公開、根拠のない効果の数値。

## 本人が確認する根拠表

| 出力すること | 原記録 | 限界・役割 |
| --- | --- | --- |
| 返却場所を観察した | [観察記録](inquiry-project/observation.md) | 一回15分・6人。立ち止まった理由は聞いていない |
| 箱別の案内を試作し修正した | [制作記録](inquiry-project/work.md) | 本人は試作・修正、友人2人は表示の確認に協力 |
| 仮説を見直した | [観察後の考察](inquiry-project/observation.md) | 入口の字だけでは説明できない可能性に気づいた。原因の確定ではない |

## 別ファイルに出す本文の例

次の段落だけが、許可された条件での架空の活動報告案です。根拠表やPrivateリンクを含めません。

> 図書コーナーの返却場所を観察し、箱ごとの用途を示す案内を試作しました。当初は入口の文字が小さいことが原因だと考えていましたが、箱の前で立ち止まる場面を見て、問いを見直しました。友人の反応を受け、矢印だけでなく箱の名前も加えました。少人数での確認のため、案内の効果はまだ断定できません。

大学で学びたい内容や志望理由は、この実施記録だけでは分かりません。本人の現在の考えと公式のカリキュラムを確認してから扱います。例文にそれらを補っていません。

## 保存・確認の例

- 非公開の根拠表: derived/YYMMDD-admissions-evidence.md。
- 別の本文: derived/YYMMDD-application-draft.md。本人の確認前は下書き。
- 最終確認: 設問、字数、原記録との一致、役割、AIの表示条件、指定様式。
- 実際の提出: 未実施。この教材を受験者本人の実績として使用しない。
