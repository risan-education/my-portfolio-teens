# 15. 街の日陰を増やす案は、場所と費用を合わせるとどう変わるか

- 作成日: 2026-09-26
- 更新日: 2026-09-26

**EEの研究の考え方を参考にした、独自の架空の計画例です。** 実施結果、正式なIB提出論文、採点済みの模範解答ではありません。資料名・対象地・期間等が未定の箇所は、予備調査で実在と入手可能性を確かめて具体化します。

[15例の一覧](README.md)／[EEを参考にするガイド](../../docs/extended-essay-guide.md)／[テーマの選び方](../../docs/choosing-inquiry-theme.md)

## 好きなことから、答えられる問いへ

- 架空の本人の関心: 日陰を増やしたいが、限られた予算をどこに使うべきか気になる。
- 関連を調べたい分野: **地理・経済・都市政策**
- 研究の方法: 二分野の方法を統合する研究
- まだ広すぎるテーマ: 「暑さに対応する街づくり」
- 絞った研究課題の案: **一地区の休憩候補地で、日陰の不足する時間・利用可能な場所と、設置維持費の条件を合わせると、対策案の比較はどう変わるか。**
- 対象と範囲: 一地区・限定した時間帯と候補地に絞る。地理は場所と時間、経済は資源配分と費用の観点を担当する。

この問いも仮です。資料が足りない、範囲が広いと分かったら、理由を残して変更します。結論は調べる前に決めません。

## 資料と方法

**探す資料:** 公開地図・施設情報、安全な範囲の環境観察、公共事業の公開費用資料、空間利用と費用評価の文献。金額の根拠と仮定を分ける。

ここに挙げたのは資料の種類で、確認済みの参考文献一覧ではありません。検索しただけ・題名だけ・本文を読んだ、を分けて記録します。

**分析する方法:** 地理の分析で時間帯別の日陰と到達可能な場所を整理する。その同じ候補地ごとに設置・維持の条件を対応付け、同一の比較表で費用と不足時間を検討する。仮定を変えて選択が変わるか確かめる。

**論文として考えること:** 空間分析だけ、費用計算だけの場合と比べ、二つを統合して初めて分かる選択の難しさを論じる。両分野の紹介を別々に並べて終わらない。

資料の要約だけで終わらず、「この根拠が問いへのどの答えを支えるか」を文章にします。根拠から直接言えることと、自分の推測を分けます。

## 反対の説明と限界

日陰の面積や時間だけから熱中症の予防効果を計算しない。仮定の費用は実際の見積もりと区別し、現場の設置可能性を確認できなければ条件付きの案にする。

想定外の結果や解釈の行き詰まりも残します。実施していない測定、存在を確かめていない文献、AIの予測を結果として使いません。

## 本教材の6段階に組み込む

| 段階 | この研究で残すもの |
| --- | --- |
| 1. 興味を見つける | 上記のような関心のうち、本人に本当に当てはまる経験と言葉 |
| 2. 課題を決める | 予備調査後の研究課題、対象・範囲、変更理由 |
| 3. 仮説を立てる | 仮の説明と反対の説明、比較方法、必要な資料 |
| 4. 現場で確かめる | 上記の方法で調べた原資料・データ、分析、方法の修正 |
| 5. 形にして発信する | 根拠付きレポート、図表や引用の出典、受けた質問 |
| 6. 人を巻き込む | 地理・公民の先生に別々の分析を相談し、統合した説明の弱点を自分で修正する。 |

この6段階は本教材の構成です。本人が分析・論述し、助言者の役割と本人の判断を分けます。正式なEEでは学校の指導と当該評価年度の規定に従い、他の人と提出本文を共同執筆する手順にはしません。

## 最初の一週間と、その先

**最初の一歩:** 候補地二つについて、日陰の時間と費用に必要な資料が揃うか表にする。

**継続の見通し:** 高1は一地区と二分野の基礎、高2は共通条件で分析を統合、高3は結論が変わる仮定と次に必要な調査をまとめる。

各学期に問い・方法・実行条件を見直します。これは本教材の高校生活での配分案で、IBの公式日程ではありません。実記録は[探究ノート](../../templates/inquiry.md)等へ `YYMMDD-theme.md` 形式で残します。

## 入試や大学での学びにどうつなぐか

大学でさらに調べる分野の候補: **都市地理、環境経済、公共政策。正式な学際EEの科目の組合せは学校で別途確認する。** 実際の授業・研究・履修条件は候補大学の公式情報で確認します。

自分が選んだ問い、方法を選んだ理由、根拠の比較、変更した判断、限界を説明できる記録を残します。出願に使う場合は[出願準備ガイド](../../docs/admissions-guide.md)で対象期間・提出物・AI利用条件を確認し、本人の実記録だけを材料にします。

実践につなげたいときは[関連する探究例](../inquiry-themes/11-architecture.md)も読めます。研究論文と実践を両方行う場合も、二つの結果を混同せず、主テーマの下で関係を記します。
