# Extended Essayを参考にした、架空の研究計画15例

- 作成日: 2026-09-26
- 更新日: 2026-09-26

**EEの「問いを絞り、資料を分析し、根拠のある論述へまとめる」考え方を、大学入試に向けた探究へ取り入れる例です。** すべて本教材が独自に作った架空の計画です。正式なIB提出論文、過去の高得点例、本人の実績ではありません。

先に[EEを参考にするガイド](../../docs/extended-essay-guide.md)で、公式の概要、2027年初回評価からの変更、正式なEEと本教材との違いを確認できます。IBを履修していなくても、研究の方法を学ぶ参考として読めます。

学部名や研究の分類は、大学の学びとの接点を探すための案です。正式なEEの登録科目を判定した表ではありません。選ぶときは、本人の関心、資料の入手、必要な基礎知識、期間、指導・助言を受けられる範囲を確かめます。

各例では、広いテーマから研究課題への絞り込み、扱う範囲、資料の種類、分析方法、論じる点、反対の説明と限界、本教材の6段階、高校生活での継続を示しています。実在する研究やデータを調べる前なので、結果・数値・論文の書誌情報は創作していません。

## 実践18例との使い分け

[実践中心の18例](../inquiry-themes/README.md)は、観察・制作・改善・発信から始めたいときに読めます。この15例は、一つの問いを掘り下げ、根拠を比較して研究レポートへまとめたいときに読めます。

例えば、地域の案内を作る実践と、案内文の表現を分析する研究はつながります。同じ主テーマでも、作品を作ったことと、分析から言える結論は別に記録します。EEを参考にするために、必ず二つのプロジェクトを実施する必要はありません。

## 読むときの五つの質問

1. この例のどこを、自分も知りたいと感じたか。
2. 自分が入手できる作品・資料・データはあるか。
3. 比較・精読・実験・計算など、どの方法を試したいか。
4. 予想に合わない根拠が出たら、何を見直せるか。
5. 高校で残った問いを、大学のどんな授業で深めたいか。

まだ迷うときは[テーマの選び方](../../docs/choosing-inquiry-theme.md)へ進み、志望学部から選ぶ方法と、好きなこと・日々の記録から選ぶ方法を比べます。

## ChatGPTと研究課題を絞る

> この15例のうち［例の番号］が気になりました。私が好きなのは［対象・作業］、今ある記録は［使ってよい記録］です。まず私の現在の関心と使える資料を確認してください。その後、広い主テーマと、今学期に調べられる研究課題を分けて二案出してください。方法、必要な証拠、反対の解釈、最初の予備調査を示してください。例の動機や結果を私の実績にせず、未確認の文献や数値を作らないでください。

正式なEE・出願課題に関する作業なら、学校・IB・大学のAI利用条件の確認が先です。通常の学習相談と、提出用の文章・構成・添削を区別します。
