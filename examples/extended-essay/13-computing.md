# 13. 迷路の探索法は、どの条件で違いが出るか

- 作成日: 2026-09-26
- 更新日: 2026-09-26

**EEの研究の考え方を参考にした、独自の架空の計画例です。** 実施結果、正式なIB提出論文、採点済みの模範解答ではありません。資料名・対象地・期間等が未定の箇所は、予備調査で実在と入手可能性を確かめて具体化します。

[15例の一覧](README.md)／[EEを参考にするガイド](../../docs/extended-essay-guide.md)／[テーマの選び方](../../docs/choosing-inquiry-theme.md)

## 好きなことから、答えられる問いへ

- 架空の本人の関心: ゲームの経路探索が、障害物の置き方で変わることに興味がある。
- 関連を調べたい分野: **情報・計算機科学**
- 研究の方法: 一分野を中心にしたアルゴリズム分析
- まだ広すぎるテーマ: 「速い経路探索」
- 絞った研究課題の案: **一歩の費用が等しい格子迷路で、幅優先探索とA*探索の訪問ノード数は、迷路の形と障害物の条件によってどう変わるか。**
- 対象と範囲: 同じ大きさ・開始点・目的地で条件を揃え、複数の迷路群を作る。推定距離と同点時の処理を明記する。

この問いも仮です。資料が足りない、範囲が広いと分かったら、理由を残して変更します。結論は調べる前に決めません。

## 資料と方法

**探す資料:** 各アルゴリズムの理論、実装資料、自作コードと迷路。引用・利用条件、AI生成コードと本人の検証範囲を残す。

ここに挙げたのは資料の種類で、確認済みの参考文献一覧ではありません。検索しただけ・題名だけ・本文を読んだ、を分けて記録します。

**分析する方法:** 小さい迷路で正解を手計算し、複数の配置で経路長・訪問ノード・計算時間を測る。乱数の種や環境を保存し、到達不能な場合も別に集計する。

**論文として考えること:** 速かった例を挙げるだけでなく、探索の仕組みと迷路の形から差を説明する。最短経路を得たかも確認する。

資料の要約だけで終わらず、「この根拠が問いへのどの答えを支えるか」を文章にします。根拠から直接言えることと、自分の推測を分けます。

## 反対の説明と限界

経路長の一致を全条件の正しさの証明としない。端末の速度、実装、推定関数の影響を分け、現実の道路全体へ一般化しない。

想定外の結果や解釈の行き詰まりも残します。実施していない測定、存在を確かめていない文献、AIの予測を結果として使いません。

## 本教材の6段階に組み込む

| 段階 | この研究で残すもの |
| --- | --- |
| 1. 興味を見つける | 上記のような関心のうち、本人に本当に当てはまる経験と言葉 |
| 2. 課題を決める | 予備調査後の研究課題、対象・範囲、変更理由 |
| 3. 仮説を立てる | 仮の説明と反対の説明、比較方法、必要な資料 |
| 4. 現場で確かめる | 上記の方法で調べた原資料・データ、分析、方法の修正 |
| 5. 形にして発信する | 根拠付きレポート、図表や引用の出典、受けた質問 |
| 6. 人を巻き込む | 情報の先生や友人に再実行してもらい、説明不足や不具合を自分で修正する。 |

この6段階は本教材の構成です。本人が分析・論述し、助言者の役割と本人の判断を分けます。正式なEEでは学校の指導と当該評価年度の規定に従い、他の人と提出本文を共同執筆する手順にはしません。

## 最初の一週間と、その先

**最初の一歩:** 紙の小さな迷路で両方式の探索順を追い、コードの動作と照合する。

**継続の見通し:** 高1は手作業と実装理解、高2は条件別の再現可能な比較、高3は理論と実験の一致・不一致をまとめる。

各学期に問い・方法・実行条件を見直します。これは本教材の高校生活での配分案で、IBの公式日程ではありません。実記録は[探究ノート](../../templates/inquiry.md)等へ `YYMMDD-theme.md` 形式で残します。

## 入試や大学での学びにどうつなぐか

大学でさらに調べる分野の候補: **アルゴリズム、人工知能、ソフトウェア工学。** 実際の授業・研究・履修条件は候補大学の公式情報で確認します。

自分が選んだ問い、方法を選んだ理由、根拠の比較、変更した判断、限界を説明できる記録を残します。出願に使う場合は[出願準備ガイド](../../docs/admissions-guide.md)で対象期間・提出物・AI利用条件を確認し、本人の実記録だけを材料にします。

実践につなげたいときは[関連する探究例](../inquiry-themes/09-computing.md)も読めます。研究論文と実践を両方行う場合も、二つの結果を混同せず、主テーマの下で関係を記します。
