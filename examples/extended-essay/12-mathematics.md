# 12. 円周率の近似方法は、計算量と誤差でどう違うか

- 更新日: 2026-09-26

## 好きなことから、答えられる問いへ

- 架空の本人の関心: 同じ数を求めるのに、方法によって速さが違うことに興味がある。
- 関連を調べたい分野: **数学・数理科学**
- 研究の方法: 一分野を中心にした導出・証明・計算
- まだ広すぎるテーマ: 「円周率の計算」
- 絞った研究課題の案: **円に内接・外接する正多角形による近似と、選んだ級数による近似では、誤差を小さくするための計算量をどう比較できるか。**
- 対象と範囲: 理解して導出できる二方法に絞り、計算量を項数や基本演算数などで定義する。

この問いも仮です。資料が足りない、範囲が広いと分かったら、理由を残して変更します。結論は調べる前に決めません。

## 資料と方法

**探す資料:** 幾何学・級数の数学文献、既知の公式、本人が書いた導出とコード。公式を発見したかのように書かず出典を付ける。

ここに挙げたのは資料の種類で、確認済みの参考文献一覧ではありません。検索しただけ・題名だけ・本文を読んだ、を分けて記録します。

**分析する方法:** まず小さい場合を手計算し、近似の上下界や誤差の見積もりを説明する。次に計算機で比較し、丸め誤差と理論上の誤差を区別する。

**論文として考えること:** 数値表だけで終わらず、なぜ違いが生じるかを数式と論理で説明する。条件付きの見積もりや反例も示す。

資料の要約だけで終わらず、「この根拠が問いへのどの答えを支えるか」を文章にします。根拠から直接言えることと、自分の推測を分けます。

## 反対の説明と限界

ソフトの実行時間だけでは実装・端末の影響が混ざる。読めない高度な証明をAIから貼り付けず、説明できる範囲へ問いを縮める。

想定外の結果や解釈の行き詰まりも残します。実施していない測定、存在を確かめていない文献、AIの予測を結果として使いません。

## 本教材の6段階に組み込む

| 段階 | この研究で残すもの |
| --- | --- |
| 1. 興味を見つける | 上記のような関心のうち、本人に本当に当てはまる経験と言葉 |
| 2. 課題を決める | 予備調査後の研究課題、対象・範囲、変更理由 |
| 3. 仮説を立てる | 仮の説明と反対の説明、比較方法、必要な資料 |
| 4. 現場で確かめる | 上記の方法で調べた原資料・データ、分析、方法の修正 |
| 5. 形にして発信する | 根拠付きレポート、図表や引用の出典、受けた質問 |
| 6. 人を巻き込む | 数学の先生に証明の飛躍を指摘してもらい、自分で補う。 |

この6段階は本教材の構成です。本人が分析・論述し、助言者の役割と本人の判断を分けます。正式なEEでは学校の指導と当該評価年度の規定に従い、他の人と提出本文を共同執筆する手順にはしません。

## 最初の一週間と、その先

**最初の一歩:** 正六角形を使う近似を自分で図示し、得られる数が何を意味するか説明する。

**継続の見通し:** 高1は前提となる数学を学び、高2は導出と比較、高3は計算の意味と誤差の議論をまとめる。

各学期に問い・方法・実行条件を見直します。これは本教材の高校生活での配分案で、IBの公式日程ではありません。実記録は[探究ノート](../../templates/inquiry.md)等へ `YYMMDD-theme.md` 形式で残します。

## 入試や大学での学びにどうつなぐか

大学でさらに調べる分野の候補: **解析学、数値解析、計算数学。** 実際の授業・研究・履修条件は候補大学の公式情報で確認します。

自分が選んだ問い、方法を選んだ理由、根拠の比較、変更した判断、限界を説明できる記録を残します。出願に使う場合は[出願準備ガイド](../../docs/admissions-guide.md)で対象期間・提出物・AI利用条件を確認し、本人の実記録だけを材料にします。
