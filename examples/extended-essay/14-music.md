# 14. 同じ旋律が、編曲でどう聞き取れる形になるか

- 作成日: 2026-09-26
- 更新日: 2026-09-26

## 好きなことから、答えられる問いへ

- 架空の本人の関心: 同じ曲の別の演奏で、違う音が目立つ理由を知りたい。
- 関連を調べたい分野: **音楽・芸術・文化**
- 研究の方法: 一分野を中心にした楽曲分析
- まだ広すぎるテーマ: 「編曲と音楽の表現」
- 絞った研究課題の案: **利用できる二つの編曲で、同じ旋律区間の音域・伴奏の密度・リズム配置はどう異なり、旋律の強調をどう説明できるか。**
- 対象と範囲: 一曲・二つの編曲・同じ短い区間を選び、楽譜と音源の対応を確かめる。対象は利用可能な資料があるものへ絞る。

この問いも仮です。資料が足りない、範囲が広いと分かったら、理由を残して変更します。結論は調べる前に決めません。

## 資料と方法

**探す資料:** 楽譜、録音の版・編曲者等の情報、編曲や和声の文献。必要な引用と分析図以外を無断で転載しない。

ここに挙げたのは資料の種類で、確認済みの参考文献一覧ではありません。検索しただけ・題名だけ・本文を読んだ、を分けて記録します。

**分析する方法:** 小節ごとの分析表を作り、聴取した印象を譜面上の要素と照合する。演奏者・録音・楽器の違いと編曲そのものの違いを分けて考える。

**論文として考えること:** 『明るい』『迫力がある』という感想を出発点に、どの音楽的根拠でそう解釈したかを説明する。異なる説明が可能な区間も論じる。

資料の要約だけで終わらず、「この根拠が問いへのどの答えを支えるか」を文章にします。根拠から直接言えることと、自分の推測を分けます。

## 反対の説明と限界

譜面分析から聴衆全員の印象を断定しない。録音条件を揃えられない場合は、その限界を明記する。音源の再生回数や人気を作品の質の指標にしない。

想定外の結果や解釈の行き詰まりも残します。実施していない測定、存在を確かめていない文献、AIの予測を結果として使いません。

## 本教材の6段階に組み込む

| 段階 | この研究で残すもの |
| --- | --- |
| 1. 興味を見つける | 上記のような関心のうち、本人に本当に当てはまる経験と言葉 |
| 2. 課題を決める | 予備調査後の研究課題、対象・範囲、変更理由 |
| 3. 仮説を立てる | 仮の説明と反対の説明、比較方法、必要な資料 |
| 4. 現場で確かめる | 上記の方法で調べた原資料・データ、分析、方法の修正 |
| 5. 形にして発信する | 根拠付きレポート、図表や引用の出典、受けた質問 |
| 6. 人を巻き込む | 音楽の先生や演奏する友人から別の聴き方を聞き、自分の分析を点検する。 |

この6段階は本教材の構成です。本人が分析・論述し、助言者の役割と本人の判断を分けます。正式なEEでは学校の指導と当該評価年度の規定に従い、他の人と提出本文を共同執筆する手順にはしません。

## 最初の一週間と、その先

**最初の一歩:** 同じ旋律の短い区間を二つの版で聴き、気付いた違いと未確認の原因を書き分ける。

**継続の見通し:** 高1は譜面と耳の照合、高2は文献を踏まえて分析、高3は根拠のある解釈と別の説明をまとめる。

各学期に問い・方法・実行条件を見直します。これは本教材の高校生活での配分案で、IBの公式日程ではありません。実記録は[探究ノート](../../templates/inquiry.md)等へ `YYMMDD-theme.md` 形式で残します。

## 入試や大学での学びにどうつなぐか

大学でさらに調べる分野の候補: **音楽学、作曲・編曲、音楽教育。** 実際の授業・研究・履修条件は候補大学の公式情報で確認します。

自分が選んだ問い、方法を選んだ理由、根拠の比較、変更した判断、限界を説明できる記録を残します。出願に使う場合は[出願準備ガイド](../../docs/admissions-guide.md)で対象期間・提出物・AI利用条件を確認し、本人の実記録だけを材料にします。

実践につなげたいときは[関連する探究例](../inquiry-themes/17-art-design.md)も読めます。研究論文と実践を両方行う場合も、二つの結果を混同せず、主テーマの下で関係を記します。
