# 06. 再利用容器の導入を、運営の負担から考える

- 作成日: 2026-09-26
- 更新日: 2026-09-26

## 好きなことから、答えられる問いへ

- 架空の本人の関心: 使い捨てを減らす案が、店ではなぜ簡単に導入できないのか気になる。
- 関連を調べたい分野: **経営・商・環境経営**
- 研究の方法: 一分野を中心にした事業モデルの検討
- まだ広すぎるテーマ: 「環境に配慮した店舗運営」
- 絞った研究課題の案: **小規模な飲料販売で再利用容器を導入する案は、回収率・洗浄費・紛失率の仮定を変えると、費用と作業量の面でどのように評価が変わるか。**
- 対象と範囲: 一種類の容器・一店舗規模のモデルに絞る。実店舗データを使う場合は許可を得る。入手できなければ仮定を明記した条件比較にする。

この問いも仮です。資料が足りない、範囲が広いと分かったら、理由を残して変更します。結論は調べる前に決めません。

## 資料と方法

**探す資料:** 公開された導入事例、費用情報、運営管理に関する文献。企業の宣伝、独立した調査、自分の仮定を分ける。

ここに挙げたのは資料の種類で、確認済みの参考文献一覧ではありません。検索しただけ・題名だけ・本文を読んだ、を分けて記録します。

**分析する方法:** 購入・回収・保管・洗浄の工程を整理し、複数の回収率と処理量で費用・作業時間を比較する。条件を一つずつ変え、結論に大きく影響する変数を探す。

**論文として考えること:** 一つの『成功する案』ではなく、導入が成立しそうな条件と成立しにくい条件を説明する。モデルで捉えられないサービス品質も論じる。

資料の要約だけで終わらず、「この根拠が問いへのどの答えを支えるか」を文章にします。根拠から直接言えることと、自分の推測を分けます。

## 反対の説明と限界

架空の数値で利益の実績を作らない。費用が小さいことから環境負荷も小さいと飛躍しない。正式なEEでは事例・資料の十分さを教員に確認する。

想定外の結果や解釈の行き詰まりも残します。実施していない測定、存在を確かめていない文献、AIの予測を結果として使いません。

## 本教材の6段階に組み込む

| 段階 | この研究で残すもの |
| --- | --- |
| 1. 興味を見つける | 上記のような関心のうち、本人に本当に当てはまる経験と言葉 |
| 2. 課題を決める | 予備調査後の研究課題、対象・範囲、変更理由 |
| 3. 仮説を立てる | 仮の説明と反対の説明、比較方法、必要な資料 |
| 4. 現場で確かめる | 上記の方法で調べた原資料・データ、分析、方法の修正 |
| 5. 形にして発信する | 根拠付きレポート、図表や引用の出典、受けた質問 |
| 6. 人を巻き込む | 先生や許可を得た運営者に工程の抜けを尋ね、自分でモデルを修正する。 |

この6段階は本教材の構成です。本人が分析・論述し、助言者の役割と本人の判断を分けます。正式なEEでは学校の指導と当該評価年度の規定に従い、他の人と提出本文を共同執筆する手順にはしません。

## 最初の一週間と、その先

**最初の一歩:** 回収から洗浄までの工程図を描き、出典がある費用と不明な費用を分ける。

**継続の見通し:** 高1は工程と仮定を整理、高2は公開事例で条件を点検、高3は意思決定の条件と未確認事項をまとめる。

各学期に問い・方法・実行条件を見直します。これは本教材の高校生活での配分案で、IBの公式日程ではありません。実記録は[探究ノート](../../templates/inquiry.md)等へ `YYMMDD-theme.md` 形式で残します。

## 入試や大学での学びにどうつなぐか

大学でさらに調べる分野の候補: **経営管理、事業戦略、会計、サステナビリティ経営。** 実際の授業・研究・履修条件は候補大学の公式情報で確認します。

自分が選んだ問い、方法を選んだ理由、根拠の比較、変更した判断、限界を説明できる記録を残します。出願に使う場合は[出願準備ガイド](../../docs/admissions-guide.md)で対象期間・提出物・AI利用条件を確認し、本人の実記録だけを材料にします。

実践につなげたいときは[関連する探究例](../inquiry-themes/06-economics-business.md)も読めます。研究論文と実践を両方行う場合も、二つの結果を混同せず、主テーマの下で関係を記します。
