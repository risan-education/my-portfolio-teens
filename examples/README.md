# 架空の記入例

- 作成日: 2026-09-26
- 更新日: 2026-10-02

このフォルダの人物・活動・数値・発言・活動日はすべて架空です。書き方を示す教材であり、本人の実績として検索・集計・要約しません。文書の作成日・更新日は教材の編集日です。

例を丸写しして自分の活動にする必要はありません。空欄の[用紙](../templates/README.md)へ、自分が残したいことだけを書きます。接続や保存の練習ファイルは、このフォルダではなく [practice/](../practice/README.md) に置きます。

## 記録から次の用途へつなぐ架空例

- [探究レポート](inquiry-report.md) → [面接練習](interview-session.md)：同じ原記録に戻って説明と限界を確かめます。
- [大学版への移行準備](migration-to-univ/README.md)：日付欄のない記録・相対リンク・利用停止・重複を扱います。大学版との実移行の完了例ではありません。
