# 架空の記入例

- 作成日: 2026-09-26
- 更新日: 2026-09-26

このフォルダの人物・活動・数値・発言・活動日はすべて架空です。書き方を示す教材であり、本人の実績として検索・集計・要約しません。文書の作成日・更新日は教材の編集日です。

| [日々の記録からテーマを選ぶ](theme-selection.md) | 原メモ→AIの候補→本人の回答→研究課題→大学の分野を探す架空の会話 |
| [学部・学科の関心別・探究テーマ18例](inquiry-themes/README.md) | 主テーマ選び、6段階の計画、方法・限界、高1〜高3の発展。架空の計画と約900字の成果報告 |
| [ChatGPTとのやりとり](chatgpt-session.md) | 案・本人の確認・保存・追記の架空例 |
| [中学生の活動](middle-experience.md) | 活動記録。短くても、空欄があってもよい |
