# 【架空例】送る一言と、できあがった記録

- 作成日: 2026-10-01
- 更新日: 2026-10-02

自分に近い場面を一つ選んでください。各ページの冒頭に送る一言と日記の見本があり、完成記録を開けば表・元メモ・追加回答を読めます。詳しい会話は折りたたんであります。

**すぐ終わりたいときは [短い会話例](short-sessions.md)へ。** 質問なし、日記なし、訂正、保存できないときの伝え方があります。

## 使い方

1. 最初の発言を自分の内容に置き換えて送る。接続済みなら、メモだけで一言メモの案になる。別の用紙を使いたいときだけ添える。
2. 案と日付を確かめる。活動日を書かなければ会話日として案に示され、「昨日」は前日に換算される。本当に不明なら未確認と伝える。
3. 質問には答えたい分だけ答える。本人の回答原文を残し、整理した要約と分ける。日記は短くてもよく、不要なら省ける。
4. 保存する本文・関連する問いの案を確認して「この内容で保存してください」と頼む。
5. 保存先・ブランチ・再読込の報告を確かめ、自分でもファイルを開く。

人物・活動・発言・日付・数値は架空です。保存報告も教材上の返答例で、実機検証ログではありません。見本はexamples内にありますが、本人の実績には含めません。自分の実記録は本人用Private、架空の練習はpracticeへ。[保存先と呼び出し方](../../docs/where-records-go.md)／[接続なしの保存](../../docs/manual-editing.md)
