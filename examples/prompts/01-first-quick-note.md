# 【架空例】プロンプト例1: 最初の一言メモ（読んだ本のこと）

- 作成日: 2026-10-01
- 更新日: 2026-10-01

使う用紙: [一言メモ](../../templates/quick-note.md)。人物・活動・発言・活動日はすべて架空です。本人の実績に含めません。

## 場面

中学1年生。ポートフォリオを始めたばかりで、何を書けばよいか分からない。昨日読み終えた本のことを一言だけ残したい。保存先は本人用Private（ChatGPTを接続済み）という設定。

## ChatGPTへ話しかける文（プロンプト例）

```text
AGENTS.mdを読んで、記録を始める準備をしてください。準備ができたら、次の一言を一言メモの用紙で記録する案を見せてください。

昨日、図書室で借りた深海の本を読み終わった。光らない魚がいるのが意外だった。活動日は2026-05-11です。
```

## ChatGPTの応答の要点

- 準備の確認: 本人用PrivateのURL・Privateであること・読み取りと保存ができることを確認し、この段階ではファイルを変更しない。
- 提案する保存先: `experiences/260511-deep-sea-book.md`（同名があれば `-02`）。
- 元のメモは入力された文をそのまま残す。「意外だった」は本人のメモの言葉なので、そのまま「本人の考え」に置く。
- 書名・著者は入力にないので空欄にし、「分かれば追記できます」と伝える。本人の直接発言の引用は作らない。
- 最後に「この内容で保存しますか」と確認する。

## できあがった記録の例

```markdown
# 深海の本を読み終わった

- 作成日: 2026-05-12
- 更新日: 2026-05-12

- 活動日: 2026-05-11
- 記録日: 2026-05-12
- 記録者（本人／代筆。役割だけで可）: 本人
- タグ（任意）: 読書, 深海

## 元のメモ
昨日、図書室で借りた深海の本を読み終わった。光らない魚がいるのが意外だった。

## 追加で残したいこと（すべて任意）
- 本人の実際の言葉（直接発言のみ）: 記録なし（上は本人の入力メモ）
- 本人の考え・次にしたいこと: 光らない魚がいるのが意外だった。
- 支援者の観察:
- AIの提案（未実施）: 書名・著者と、どの魚だったかを追記すると、あとで探しやすい（ChatGPTの提案）。
- 資料・作品の所在: 図書室で借りた本（書名は未確認）

## 追記・訂正
```

## 保存の依頼と報告の例

本人:

> この内容で保存してください。

ChatGPTは `experiences/260511-deep-sea-book.md` をmainへ新規ファイルとして保存し、再読込して報告する。本人はGitHubでファイルを開いて本文と日付を確かめる。

## この例のポイント

- 一言だけで記録は完成する。空欄があってもよい。
- 作成日・更新日は保存した日、活動日は本を読み終えた日で、別の日付になる。
- 「意外だった」という感想を、ChatGPTが「深海生物に強い関心を持った」などと言い換えない。
