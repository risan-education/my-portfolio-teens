# 【架空例】プロンプト例5: 二つの記録から振り返る

- 作成日: 2026-10-01
- 更新日: 2026-10-01

使う用紙: [振り返り](../../templates/reflection.md)。[例2](02-school-festival-role.md)・[例3](03-inquiry-bicycle.md)と同じ架空の生徒の設定です。

## 場面

高校1年生の冬。本人用Privateには、中3の文化祭の記録と、高1の交差点の探究ノートがある。学期末に、この二つを読み返して振り返りを残したい。

## ChatGPTへ話しかける文（プロンプト例）

```text
振り返りの用紙で、学期末の振り返りの案を見せてください。対象期間は2026-09-01から2027-12-20です。

読む記録は experiences/260919-school-festival.md と projects/bicycle-crossing/270602-inquiry-start.md の2件だけにしてください。examples/ と templates/ は読まないでください。

当時の記録に書いてあることと、今の私の考えを分けてください。私の性格を決めつける文は書かないでください。気づきの候補を出してもらったら、どれを残すかは私が選びます。
```

## ChatGPTの応答の要点

- 指定された2件だけを読み、それぞれの要点と根拠の行を示す。読めなかった場合は読めなかったと伝える。
- 気づきの候補を数個挙げる（例: どちらの記録でも「数えてみる」ことをしている）。候補は本人が選ぶまで表に入れない。
- 「現在の興味」は本人の確認日付きで、本人の答えだけを書く。「観察が得意」「分析型」などの性格の断定は書かない。
- 提案する保存先: `reflections/271220-term-end.md`。

## できあがった記録の例

本人が候補から二つを選び、現在の興味を答えたあとの例です。

```markdown
# 2学期末の振り返り（中3秋〜高1冬）

- 作成日: 2027-12-20
- 更新日: 2027-12-20

- 振り返った日: 2027-12-20
- 対象期間: 2026-09-01〜2027-12-20
- 記録者: 本人

## 今回選んだ元記録
- experiences/260919-school-festival.md（文化祭の受付係）
- projects/bicycle-crossing/270602-inquiry-start.md（○○交差点の自転車）

## 当時と今
| 気づき・考えの変化 | 当時の根拠リンク | 今の本人の考え |
| --- | --- | --- |
| 文化祭でも交差点でも、「気がする」ことを数えてみた | experiences/260919-school-festival.md「正の字で数えた」／projects/bicycle-crossing/270602-inquiry-start.md「実施記録」 | 数えると感じ方と違うことがあると分かった。これからも先に数えてみたい |
| 文化祭では「呼び込みのせいか時間帯のせいか分からない」で止まっていた | experiences/260919-school-festival.md「まだ分からないこと」 | 交差点では条件を分けて数えることにした。比べる条件を先に決めるのが大事だと思う |

## 続けたいこと・変えたいこと・休みたいこと
- 続けたい: 交差点の観察（あと3回）。
- 変えたい: 「接触しそう」の基準を先に文で決める。
- 休みたい: なし。

## 現在の興味（本人が確認した範囲）
- 本人の確認日: 2027-12-20
- 本人の答え: 人の動きがどうして偏るのかに興味がある。交通以外でも気になる。

## 次の候補と選択
- 本人が選んだこと: 3学期に観察を3回続ける。
- AI・支援者の提案（未実施）: 学校の先生や地域の交通安全担当に、交差点で気づいたことを聞いてみる（ChatGPTの提案）。

## 判断の経緯（任意）
- 考えた選択肢: 観察を続ける／別の場所に広げる／いったん休む。
- 優先したことと、選ばなかった案・理由: まず同じ条件で回数を増やす。別の場所は比べられなくなるので今は選ばない。
- 結果を受けて見直したこと: （未記入）

## 追記・訂正
```

## この例のポイント

- 読む記録を本人が指定し、架空例や用紙を根拠に含めない。
- 表の「当時の根拠リンク」はファイルと該当箇所まで書く。「今の本人の考え」は当時の記録を書き換えずに別に置く。
- 「観察が得意な人」のような性格の断定は書かない。興味は本人が答えた範囲だけ。
