# 【架空例】かげが、うごいた

- 作成日: 2026-09-25
- 更新日: 2026-09-26

- いつ: 2026-09-01（架空の日付）
- 書いた人: 保護者の代筆
- やったこと・見たもの: 午前と午後に庭の同じ植木鉢の影を見た。
- 本人のことば: 「さっきとちがうところに、かげがある」
- つぎに気になること: 本人の希望「明日も見たい」
- 保護者の観察: 影の先を指さし、午前に見た位置と比べていた。
- メモ: 午前と午後に植木鉢の影を見た。「さっきとちがうところに、かげがある」「明日も見たい」と話した。

この記録だけでは、影が動く理由を本人が理解したとは判断できません。
