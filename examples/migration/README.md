# 【架空例】小学生版の言葉を保って引き継ぐ

- 作成日: 2026-09-26
- 更新日: 2026-09-27

二つの架空例で、原文と関連リンクを保つ引き継ぎを説明します。本人用の手順は[引き継ぎガイド](../../docs/migration.md)と[確認表](../../docs/migration-checklist.md)を使います。

## 1. 小学生版の原文と、今の振り返りを分ける

- [原記録 shadow-note.md](experiences/shadow-note.md): 小学生版の架空例。元のファイル名・本文・日付を保持。
- [現在の振り返り](reflection.md): 今の考えを別ファイルに記入。

2026-09-26に教材としてコピーしました。原記録の作成日・更新日をコピー日に変更せず、この案内に移行日を記録しています。コピー元と参照コミットは[参照記録](../../docs/sources.md)で確認できます。

この原記録には別ファイルへのリンクや外部画像はありません。本文が変わっていないことと、この案内・振り返りから原記録が開けることを点検します。

## 2. つながった記録を、まとまりでコピーする

[linked-source/ の問いの一覧](linked-source/questions.md)から、活動記録・家庭の探究メモ・写真の所在メモを開けます。この4ファイルは、本教材で新しく作った架空の移行元です。小学生版の実記録を含みません。

新しいPrivateへ移すときは、以下のように元の配置を保ちます。ここでは移行先に既存の `legacy/elementary-01/` があったため、まとまり全体を `elementary-02/` にしています。

| 移行元（linked-source/ をルートとする） | 移行先の例 |
| --- | --- |
| questions.md | legacy/elementary-02/questions.md |
| experiences/260901-shadow.md | legacy/elementary-02/experiences/260901-shadow.md |
| projects/shadow/README.md | legacy/elementary-02/projects/shadow/README.md |
| assets/shadow.md | legacy/elementary-02/assets/shadow.md |

この移行元の4ファイルだけをまとめてコピーします。このページや別の架空例まで移行対象にする例ではありません。実際の本人用では、本人が選んだ記録を使い、教材の架空例を実績にしません。

確認すること:

- 4ファイルの本文と日付が元と一致し、移行元もそのまま残る。
- 問いから活動・探究メモへ、探究メモから写真の所在へ移行先内でたどれる。
- 既存の `elementary-01/` の記録が変わっていない。
- 小学生版と共通の `YYMMDD-xxx.md` 形式のファイル名をそのまま保持する。「未着手」「お休み」も書き換えない。
- 保護者の活動案は未実施のまま。写真の実ファイル・閲覧権限は未確認のまま。

このコピーはテスト用の一時フォルダで検証します。[受入確認](../../docs/acceptance-review.md)に結果と範囲を記載しています。利用者のPrivateや外部写真を移行した実行記録ではありません。

## 引き継いだ後の依頼例

> 引き継ぎ確認表で利用してよいとした原記録だけを読み、当時の自分の言葉と保護者の観察を分けて紹介してください。家庭の探究メモの未実施の計画を成果に含めないでください。今も気になるかは私に確認し、今の振り返りを別ファイルにする案を見せてください。
