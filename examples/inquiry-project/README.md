# 【架空例】図書コーナーの返却案内を考える

- 作成日: 2026-09-26
- 更新日: 2026-09-26

このプロジェクトの人物・日付・数値・反応はすべて架空です。[用紙](../../templates/inquiry-project.md)の一連の記入例で、本人の実績には使いません。

この例は、主テーマ「誰もが使いやすい情報の伝え方」の中で、返却案内という具体的な問いを扱う一回の探究サイクルとして読めます。高1からの継続計画では、この結果から次の問いを考えます。入試対策全体がこの短期間で完了するという意味ではありません。[開始と継続のガイド](../../docs/inquiry-project-guide.md)

- テーマ: 返す箱を選びやすい案内
- 本人が取り組む理由: 自分も返す場所を迷い、初めて使う人も迷うのか気になった。
- 元の問い・活動記録: [元メモと観察](observation.md)
- 今取り組んでいる段階: 6までを今回はひと区切り（能力評価ではない）
- 次に本人が選んだ行動: 今回はここまで。再確認の日程は未定。
- 進路探索へのリンク（任意）: なし。進路は未定。

## 1. 興味を見つける

- 考え・計画: 自分も迷った返却場所が気になった。日常の気づきを残す。
- 実施したことと日付: 2026-06-01、自分が迷った経験をメモした。
- 結果・根拠リンク: [6月1日の元メモ](observation.md)
- 本人の振り返り: 身近な困りごとから始めてよいと思った。
- 次の候補: AI案「案内全体を調べる」（未実施・未選択）。
- 本人が選んだ行動（当時の計画）: 返却場所だけを扱う。

## 2. 課題を決める

- 考え・計画: 当初は入口の文字の読みやすさを課題と考えた。
- 実施したことと日付: 2026-06-04、観察に基づき対象を「初めて使う人が箱を選ぶ場面」に絞り直した。
- 結果・根拠リンク: [課題の見直し](observation.md)
- 本人の振り返り: 理由を聞かずに迷ったと断定できない。範囲を狭くして考える。
- 次の候補: 支援者案「場所全体の改善」（未実施・未選択）。
- 本人が選んだ行動（当時の計画）: 箱の用途が伝わるかを調べる。

## 3. 仮説を立てる

- 考え・計画: 当初「文字が小さいから迷う」。新仮説「箱ごとに用途と順番を示せば選びやすいかもしれない」。
- 実施したことと日付: 2026-06-04、元の仮説を残し、新仮説を書いた。仮説が正しいと確認したわけではない。
- 結果・根拠リンク: [予想と見直し](observation.md)
- 本人の振り返り: 自分の予想を結果に合わせて最初からの考えにしない。
- 次の候補: AI案「時間帯による混雑も原因かもしれない」（未検証・未採用）。
- 本人が選んだ行動（当時の計画）: 箱別の試作を見てもらい、選べたかと分かりにくい点を聞く。

## 4. 現場で確かめる

- 考え・計画: 匿名の人数と立ち止まる場所を観察する。担当者に目的と方法を説明する。
- 実施したことと日付: 2026-06-03、許可のうえ15分観察。6人の状況をメモした。
- 結果・根拠リンク: [実施表と限界](observation.md)
- 本人の振り返り: 入口より箱の前で止まる場面が多い。理由は未確認なので段階2・3へ戻った。
- 次の候補: AI案「別の時間帯で観察」（未実施・未選択）。
- 本人が選んだ行動（当時の計画）: 今回は試作で確かめることを選ぶ。

## 5. 形にして発信する

- 考え・計画: 箱別の案内を試作し、同意した友人2人に限定して見せる。ネット公開はしない。
- 実施したことと日付: 2026-06-07に試作、06-10に提示、06-14に反応を受けて修正。
- 結果・根拠リンク: [作品・実際の反応・修正](work.md)
- 本人の振り返り: 矢印の意味が相手にも分かるとは限らなかった。
- 次の候補: AI案「ウェブ公開」（未実施・未選択）。
- 本人が選んだ行動（当時の計画）: 修正版の設置を担当者に相談する。

## 6. 人を巻き込む

- 考え・計画: 担当者と友人を協力候補にする。地域の図書館も候補だが依頼しない。
- 実施したことと日付: 2026-06-17、担当者が設置場所を決め、友人が文を確認、本人が修正・設置後メモを担当。06-21に再観察。
- 結果・根拠リンク: [協力者・役割・変化と限界](collaboration.md)
- 本人の振り返り: 協力によって設置できた。前後で観察条件が違い、人数の変化を案内の効果と断定できない。
- 次の候補: AI案「配置を変えて比較」（未実施・未選択）。
- 本人が選んだ行動（当時の計画）: 今回はひと区切り。次の日程はまだ決めない。
