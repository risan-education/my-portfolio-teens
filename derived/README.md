# 用途に合わせてまとめる

- 作成日: 2026-09-26
- 更新日: 2026-09-26

ChatGPTへの頼み方:

> この目的のために、選んだ実記録を根拠付きでまとめる案を作ってください。原記録とは別に保存してください。

案を本人が確認して保存します。[初期設定](../docs/getting-started.md)／[保存方法の確認](../docs/connection-check.md)

要約・AI向け自己紹介・進路探索・提出用材料を、元記録とは別のファイルに保存します。例: YYMMDD-summary.md。

[総合型選抜・推薦入試の準備と出力](../docs/admissions-guide.md)には、準備計画・提出条件・根拠表・提出用本文を使います。根拠表と外部へ出す本文は別ファイルにします。[自己理解](../docs/self-understanding.md)の出力もここへ保存し、本人が確認した範囲で大学・学部選びに使えます。

[根拠付き要約](../templates/evidence-summary.md)に、目的・対象期間・利用範囲・使ったAI・主張ごとの根拠リンクを記入します。同じ目的で作り直す場合も新しいファイルにし、旧版の利用可否を確認します。

[AI向け自己紹介](../templates/ai-context.md)／[進路探索](../templates/career-exploration.md)／[提出条件確認](../templates/submission-check.md)

templates/・examples/・案内文は本人の実績に含めません。利用停止した原記録を使う要約も停止し、復元時にも再利用しません。
