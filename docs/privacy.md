# 共有と個人情報

- 作成日: 2026-09-26
- 更新日: 2026-09-27

実記録は本人用Privateリポジトリか本人が管理する非公開の端末内へ保存します。配布元のIssue・PR・コメントに実記録を載せません。本名・学校名・住所・連絡先を必須にしません。相手は「部員」「担当者」「家族」などの役割だけでも記録できます。

## ChatGPTへ渡す範囲

GitHubのPrivate設定とChatGPTの会話・ファイルの共有設定は別です。本人が認めたメモだけを渡し、記録を含む会話の共有リンクを公開しません。接続を始める前に、ChatGPTのデータ設定も確認します。[公式のData Controls FAQ](https://help.openai.com/en/articles/7730893-data-controls-faq)（確認日: 2026-09-26）

## 見せる範囲を本人が選ぶ

保存、支援者への共有、AIへの提供、提出、公開は別々の選択です。[利用範囲の用紙](../templates/record-use-review.md)で決め、必要になったときに見直します。本人が希望しないことを、記録のために聞き出しません。

Privateであっても、共同編集者や許可した接続サービスのアクセスは別に存在します。接続対象と権限を確かめ、不要なものは解除します。「AIは読まない」と本文に書くことはアクセス制御になりません。AIへ渡したくない情報は接続対象の外に置きます。

## 写真・動画・資料

原本は外部ストレージへ、[所在メモ](../assets/README.md)だけをここへ置きます。顔、名前札、位置情報、周囲の人の写り込みも本人が共有前に確認します。第三者の作品や資料は出典と利用条件を残します。

リンクがあるだけで相手が読めるとは限りません。閲覧範囲を確認し、相手に見せる必要があるものだけ共有します。「リンクを知っている全員」への権限拡張を保存の手順にしません。

バックアップも同じ利用範囲で保管し、[利用停止・削除](record-choices.md)と連動させます。パスワード、アクセストークン、秘密鍵を記録本文や所在メモへ書きません。

大学・勤務先・顧客・共同研究の資料は、個人用Privateに保存できることと、持ち出し・外部AI提供が認められることを分けます。所属先の条件を確認し、認められた範囲だけを扱います。
