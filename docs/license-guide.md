# 教材の著作権と再利用

- 作成日: 2026-09-27
- 更新日: 2026-09-27

Copyright © 2026 adash333。配布元はrisan-educationです。初版の公開時から、権利を保有するオリジナルの教材はCC BY 4.0、プログラム部分はMITとして範囲を分けます。[NOTICE.md](../NOTICE.md)が適用範囲の入口です。[LICENSE](../LICENSE)はCC BY 4.0の正式本文（英語原文）です。

## 対象と例外

| 対象 | 適用する条件 |
| --- | --- |
| オリジナルの文章・ガイド・用紙・架空例・AI向け指示 | [CC BY 4.0の正式本文](../LICENSE)。著作権は保持する |
| scripts/*.ps1、.github/workflows/*.yml、.gitattributes、.gitignore | [MIT](../LICENSES/MIT.txt)。従来のrisan-education表示も保持 |
| 小学生版のMIT版から再利用した部分 | [従来のMIT表示と全文](../LICENSES/MIT-elementary.txt)を維持。[参照元と範囲](sources.md)を確認 |
| 原文のまま引き継いだshadow-note.md | MITのまま。本文・日付を変更せず、[移行例の案内](../examples/migration/README.md)とNOTICE.mdから表示を参照 |
| 外部の公式資料・第三者の著作物・別条件の寄稿 | 各権利者の表示・条件を保持。単なるリンクを再配布許諾としない |
| 利用者が新しく書いた文章・写真・作品 | 各権利者に帰属。本教材のライセンスを自動適用しない |

教材を利用して作った本人独自の活動記録・ES等に、教材の本文や権利表示を自動挿入しません。用紙や教材の表現自体を再配布するときは、適用条件に従います。記録をPrivateに保存することも、大学版へ移すことも、公開や再ライセンスへの同意を意味しません。

## 表示の例

> 原作：adash333「Myポートフォリオ〈中高生版〉」
> 元の教材：https://github.com/risan-education/my-portfolio-teens
> Copyright © 2026 adash333 / CC BY 4.0
> ライセンス・無保証等の条件：https://creativecommons.org/licenses/by/4.0/
> 変更内容：質問項目と構成を一部変更。

これは書式の一例で、唯一の表示方法ではありません。媒体や配布方法に応じて合理的に表示できます。変更していなければ改変したとは書きません。小学生版由来の部分も再配布する場合は、その[MITの著作権・許諾・免責](../LICENSES/MIT-elementary.txt)も保持します。

CC BY 4.0は条件に従う商用利用・改変・再配布を認めます。著作者表示、ライセンスへのリンク、改変の表示等が必要です。概要だけでなく正式本文を確認してください。[日本語の概要](https://creativecommons.org/licenses/by/4.0/deed.ja)／[日本語の正式本文](https://creativecommons.org/licenses/by/4.0/legalcode.ja)

## 今回確認した範囲

2026-09-27、配布元から提示された「Myポートフォリオ 3版共通のライセンス適用メモ」と、未公開のため初版からCC BY 4.0とする指定に従い、中高生版の公開準備を整えました。メモの権利者指定、開発中のLICENSE、Git履歴の全5コミット、再利用記録を確認しました。履歴上の著者はadash333ですが、履歴の名前だけで全収録物の権利保有を判断したわけではありません。既存のrisan-education表示と、小学生版由来のMIT許諾を残しています。

[CC公式の本文](https://creativecommons.org/licenses/by/4.0/legalcode.txt)を取得してそのまま収録し、[MIT公式本文](https://opensource.org/license/mit)も確認しました。正式本文を独自の説明メモで置き換えていません。確認日は2026-09-27です。

本教材は初版からCC BY 4.0で案内します。開発中の版番号を、MITで公開済みの教材の版として扱いません。CC BY 4.0の条件については[CCの公式FAQ](https://creativecommons.org/faq/)も参照できます。

適用対象はこの中高生版だけです。小学生版・大学版のリポジトリは今回変更していません。公開への反映はコミット・pushの結果で別途確認します。
