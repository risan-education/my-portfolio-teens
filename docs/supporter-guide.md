# 保護者などの支援者へ

- 作成日: 2026-09-26
- 更新日: 2026-09-26

ChatGPTで記録するための登録・契約・アプリ導入は[はじめ方](getting-started.md)を一緒に確認できます。本人が年齢条件を満たさない場合は保護者自身が操作します。支払いと同意の確認を手伝い、内容の選択と確認は本人の希望を尊重します。

記録の主役は本人です。手伝ってほしいこと、見せてよい範囲、AIへ渡してよい範囲を本人と決めます。支援を希望しない記録も認めます。

「どこが気になった？」「いまはどう考えている？」「次に何を選びたい？」と聞き、答えを急がせません。代筆した場合は記録者を明記し、直接発言と支援者の要約を分けます。

支援者が見たことは「支援者の観察」へ。本人が説明していない理解や成長を推測で書き足しません。成績・受賞・量で比べず、うまくいかなかったこと、結論が出ないこと、休む選択も残せます。

本教材の入試対策では、高1頃に募集要項を確認し、一つの主テーマを[6段階で探究する](inquiry-project-guide.md)ことを中心にします。テーマ選び、実施できる範囲、月ごと・学期末の振り返りを支援します。訪問や聞き取りでは相手の同意と安全確認を助け、未実施の段階は理由と次の見直しを残します。本人に代わって活動したり、形式だけの完了を求めたりしません。

進学・卒業時には保存先とアカウントを見直し、[小学生版からの引き継ぎ](migration.md)と[利用範囲の見直し](record-choices.md)を使って、本人に管理を移せる範囲を相談します。サービスの年齢・同意条件は[AIガイド](ai-guide.md)と[はじめ方](getting-started.md)を参照してください。
