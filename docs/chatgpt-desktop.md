# 補足 — ChatGPTデスクトップでファイル編集も頼む

- 作成日: 2026-09-26
- 更新日: 2026-09-26

通常のChatGPT GitHubアプリが読み取り専用で、記録のファイル編集も会話で進めたい場合の方法です。公式資料ではChatGPTデスクトップの **Codex** を選んで、フォルダ内のファイルを編集する使い方が案内されています。[公式の開始手順](https://learn.chatgpt.com/docs/quickstart)（確認日: 2026-09-26）

この方法も同じ[AGENTS.md](../AGENTS.md)と用紙を使います。本人が内容を確認して保存する流れは変わりません。設定に不慣れなら[手動保存](manual-editing.md)を使い、必要に応じて支援者と進めてください。

## 自分用のフォルダを開く

1. [はじめ方](getting-started.md)でアプリをインストールし、自分用のPrivateリポジトリを用意する。
2. ChatGPTに「このPrivateを端末へcloneして編集するために必要な設定を教えて」と頼む。cloneはGitHubのファイルと履歴を端末へ取得する操作。認証は自分で行う。
3. ChatGPTデスクトップの選択メニューでCodexを選び、そのリポジトリのフォルダを開く。APIキー方式ではなく、使っているChatGPTアカウントでログインする。
4. 保存先URL・Private・現在のブランチ・未保存の変更を確認し、AGENTS.mdを読んでもらう。

GitHub反映にはGitと認証が必要です。Windows向けの[公式ガイド](https://learn.chatgpt.com/docs/windows/windows-app)ではGitやGitHub CLI等を案内しています。ポートフォリオだけのために、すべての開発用ツールを一律に入れる必要はありません（確認日: 2026-09-26）。

## 案を確認して保存する

まず[架空の練習](connection-check.md)を行います。内容を確認したら、必要な保存範囲を明確に頼みます。

> この案を自分用Privateのmainへ保存してください。依頼した変更だけをコミットしてGitHubへ反映し、mainの本文を読み直して結果を教えてください。元の記録やほかの変更は消さないでください。

端末内のファイル変更、コミット、push、GitHubでの再確認は別の段階です。途中で止まった場合はどこまで済んだかを確認し、未反映の本文を残します。

通常は本人用mainへの保存を目標とします。実行環境が作業ブランチやPRを必要とする場合は、その制約と反映方法を先に確認します。ブランチ保護を外したり、権限制限を回避したりはしません。

## 扱う情報の範囲

選んだフォルダやGit履歴が編集環境の参照対象になりえます。AIに渡したくない記録は作業フォルダ・接続対象の外へ置きます。通常のChatGPTと同じファイルを同時に編集せず、切り替えるときは最新の保存内容を読み直します。

この教材では、利用者の端末でcloneからPrivateへのpushまで行う通し検証は未実施です。[確認状況](connection-check.md)に記録しています。
