# Extended Essayを参考に、問いを研究論文へ育てる

- 作成日: 2026-09-26
- 更新日: 2026-09-26
- 公式資料の確認日: 2026-09-26

**IBDPのExtended Essay（EE、課題論文）は、総合型選抜・推薦入試に向けた探究の参考になります。** 特に、広い関心を答えられる問いへ絞ること、分野に合う方法で調べること、根拠と反論を検討して文章にすることを学べます。これは下記のIBの説明から、本教材が入試準備への活用として提案するものです。日本の大学がEE形式の論文を一律に要求するという意味ではありません。

[EEを参考にした架空の研究計画15例](../examples/extended-essay/README.md)／[テーマの選び方・二つの方法](choosing-inquiry-theme.md)／[実践中心の探究18例](../examples/inquiry-themes/README.md)

## EEとは何か、何を取り入れるか

EEはIBディプロマ・プログラムのコアにある、自分で取り組む研究と論文です。IBの概要では4,000語の論文として説明されています。[IB公式概要](https://ibo.org/programmes/diploma-programme/curriculum/dp-core/extended-essay/)

本教材では、語数や評価点をそのまま課すのではなく、次のように取り入れます。日本語の4,000字という指定ではありません。正式なEEの言語別の数え方・形式は学校と当該評価年度の規定で確認し、日本の大学へ提出する場合は大学の指定に従います。

| 本教材で取り入れる観点 | 自分の記録で実際に行うこと |
| --- | --- |
| 大きな関心から焦点を絞る | 主テーマと、今回の一文の問いを分ける |
| 方法を理由付きで選ぶ | 精読、史料比較、文献検討、実験、数理モデルなどから問いに合う方法を選ぶ |
| 根拠を検討する | 出典・測定条件・反例・別の解釈を残す |
| 答えを筋道立てて説明する | 資料の紹介だけで終わらず、根拠がどの主張を支えるか示す |
| 自分の学びを振り返る | 方法を変えた判断、失敗、限界、次に学びたいことを残す |

上の表は本教材の活用案です。IBの概要資料でも、研究・論述と振り返りの過程が示されています。[2027年初回評価のSubject Brief](https://ibo.org/globalassets/new-structure/university-admission/pdfs/ee_subjectbrief_en.pdf)

## 2027年からの変更を区別する

IBの更新案内では、新しいEEの初回評価は**2027年5月**です。一科目を中心に研究する方法と、二つのDP科目を統合する学際的な方法が示され、従来のWorld Studies EEはより広い学際的な枠組みに含まれます。[IB公式の変更案内](https://ibo.org/university-admission/latest-curriculum-updates/dp-extended-essay-updates)

古い解説や過去の高評価例に書かれた科目分類・評価表を、現在の提出条件としてそのまま使わないでください。今回の15例は研究の考え方を学ぶ独自の架空計画で、正式なEEとしての科目登録の可否や評価は保証していません。IBを履修している人は、指導教員に評価年度・科目・題材・方法・授業課題との重複を確認します。

## 公式の例はどこで読めるか

IBの[Example essays](https://ibo.org/programmes/diploma-programme/curriculum/dp-core/extended-essay/example-essays/)には、衣装と人物表現の関係、為替と特定地域の観光、音楽ファイルの圧縮と聴こえ方など、幅広い過去の題名が紹介されています。公開ページで確認したのは題名であり、各論文の全文・手法・結果を読んだという意味ではありません。同ページのProgramme Resource CentreはIB World Schools向けです。

[2027年版の公式概要PDF](https://ibo.org/globalassets/new-structure/university-admission/pdfs/ee_subjectbrief_en.pdf)にも研究課題と方法の例が載っています。例の題名をそのまま選ぶより、「どの対象を、どの観点から、どの資料で調べるか」を読み取ります。本教材の15例は、これらの題名や提出論文の転載ではありません。

## 研究課題をつくる練習

例えば「音楽が好き」は大きな関心です。そこから「編曲で同じ旋律の印象が変わるのはなぜか」という疑問を持ち、さらに「利用可能な二つの編曲で、同じ区間の音域・伴奏・リズムはどう異なり、旋律の強調をどう説明できるか」と絞ります。対象の譜面や音源を実際に入手できるか確認してから問いを確定します。

次の点を自分で説明できる問いを目指します。

- 対象、場面、期間、比較する観点が分かる。
- 調べる資料や測るものがあり、時間・道具・知識の範囲で扱える。
- 答えの丸写しや単なる感想で終わらず、分析や複数の解釈の検討ができる。
- 予想と違う資料が見つかっても、問いや結論を修正できる。

IBの旧版公開ガイドにも、関心から予備的に読み、問いの明確さ・範囲・議論の可能性を確かめる説明があります。ここでは問いづくりの参考として使い、旧版の提出規則は採用していません。[Five steps to developing a research question](https://ibpublishing.ibo.org/extendedessay/apps/dpapp/guide.html?chapter=3&doc=d_0_eeyyy_gui_1602_1_e&part=5)

## 既存の6段階とどうつなぐか

長く育てる主テーマの中で、一つの問いを論文にまとめる使い方ができます。実践18例から始め、次のサイクルで文献やデータの分析を深めても構いません。

| 本教材の6段階 | 研究論文につながる作業 |
| --- | --- |
| 1. 興味を見つける | 自分の経験と疑問、読んで気になった点を記す |
| 2. 課題を決める | 先行資料を少し読み、対象と問いを絞る |
| 3. 仮説を立てる | 仮の説明・解釈と、それに反する可能性、確かめ方を置く |
| 4. 現場で確かめる | 原典・史料・文献・データと向き合い、分析する。人文系でも原資料との照合をここに記録できる |
| 5. 形にして発信する | 根拠付きレポートをまとめ、許された範囲で校内等に説明する |
| 6. 人を巻き込む | 先生・司書・友人から方法への質問や助言を得て、自分で再検討する |

この対応表は本教材の設計であり、IBの公式な6段階ではありません。**EEは本人の独立した研究・論述です。** 本教材の協働の段階も、助言を受けて本人が判断する形にできます。グループで書いた論文を、そのまま本人のEEとして扱うことはしません。IBのガイドでも共同で提出物を作ることと、意見交換は区別されています。[2027年版ガイド、本文94ページ](https://ibo.org/globalassets/new-structure/university-admission/pdfs/subject-guides/extended-essay-first-assessment-2027-guide-sbs.pdf)

## 分野ごとの違いを大切にする

資料や方法は分野で異なります。たとえば正式な心理学EEについては、2027年版ガイドの本文56ページに、既存の研究文献に基づき、一次データの収集は行わないという条件があります。今回の心理学例も文献検討にしています。既存18例の独自アンケート等を、心理学EEへそのまま移せるわけではありません。[同ガイドの科目別説明](https://ibo.org/globalassets/new-structure/university-admission/pdfs/subject-guides/extended-essay-first-assessment-2027-guide-sbs.pdf)

一つの問いに二分野を使う場合は、同じ資料や現象をどう組み合わせて説明するかを考えます。前半に理科、後半に社会の紹介を置くだけでは、一つの問いへの答えになりません。本教材の学際例では、二つの方法を一つの比較表・解釈に統合する作業を明記しました。

## 残すものと、ChatGPTへの頼み方

本人用のプロジェクトに、研究課題の版、文献メモ、方法、元データ、分析、反対の解釈、下書き、振り返りを残します。記録には既存の[探究ノート](../templates/inquiry.md)と[プロジェクト用紙](../templates/inquiry-project.md)を使えます。日々のファイル名は `YYMMDD-theme.md`、参考文献には著者・資料名・出版年・ページ・URL等を残します。

> この教材のEE参考例を使って、私の関心［関心］を研究課題へ絞りたいです。まず使える資料・時間・知識を聞き、問いを二案出してください。問いごとに方法、必要な証拠、反対の解釈、調べられない場合の縮め方を示してください。実在を確かめていない論文や数値を作らず、私が読んだ資料と未読候補を分けてください。私の回答を待って次へ進んでください。

これは通常の学習相談の依頼例です。正式なEEや出願用課題を扱うときは、学校・IB・大学それぞれの当該条件を先に確認します。IBはAIの出力を批判的に検討し、評価対象の文章等に取り入れた場合は表示・出典を示すよう説明していますが、これだけであらゆる代筆・添削が許可されるとは判断しません。[IBのAIに関する説明](https://ibo.org/programmes/artificial-intelligence-ai-in-learning-teaching-and-assessment/)

本教材では、未確認・禁止の提出作業には進まず、[出願準備ガイド](admissions-guide.md)の条件確認に戻ります。EE参考例の完成原稿や合格実績を生成する機能ではありません。
