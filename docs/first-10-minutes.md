# 最初の10分 — GitHubなしで一言メモを一件つくる

- 作成日: 2026-09-27
- 更新日: 2026-09-27

登録や接続は後回しにできます。まずChatGPTだけで、記録が一つできる感覚をつかみます。無料プランでも試せます。

## 用意するもの

- ChatGPTのアカウント（13歳以上。18歳未満は保護者の同意が必要。[年齢条件](getting-started.md#1-chatgptのアカウントを用意する)）
- 今日あった小さな出来事を一つ。部活、読書、ゲーム、料理、何でも構いません。

## 手順

1. ChatGPTで新しい会話を開く。
2. [一言メモの用紙](../templates/quick-note.md)を開き、本文をコピーして会話に貼る。
3. 続けて次を送る。

> これは一言メモの用紙です。次のメモから、この用紙に沿った記録の案を作ってください。元のメモはそのまま残し、私が言っていないことは足さないでください。
> メモ: ［ここに今日の出来事を一行で］

4. できた案を読む。元のメモが残っているか、言っていない感想や成果が増えていないかを見る。
5. 直したいところは普段の言葉で伝える。
6. できた本文をスマホのメモ帳やパソコンのテキストファイルに貼って保存する。これが最初の一件です。

ここまでで、この教材の中心である「メモを伝える → 案を確かめる → 保存する」を一通り体験したことになります。

## 次にすること

- 続けたいと思ったら、[はじめ方](getting-started.md)で自分用のPrivateリポジトリを作り、ChatGPTと接続します。書込対応の接続では保存もChatGPTに頼めます。[確認範囲](connection-environments.md)を読み、自分の環境で保存できるか架空の練習で確かめます。
- 先ほど保存したメモは、接続後に experiences/ へ移せます。ChatGPTに「このメモを一言メモとして保存する案を見せて」と頼みます。
- 用紙を貼らずに頼めるようにするには、[AGENTS.md](../AGENTS.md)を読んでもらいます。接続後は自分用URLを伝えるだけで読んでもらえます。

## この段階で気をつけること

- 本名、学校名、住所、友だちの名前は書かなくて大丈夫です。相手は「部員」「先生」などの役割で書けます。
- パスワードや認証コードをChatGPTに送りません。
- ChatGPTが表示した文章は、まだファイルではありません。自分で貼って保存するか、接続後に保存を頼んで初めて残ります。
