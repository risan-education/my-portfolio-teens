# GitHubの登録・ログインと保存先

- 作成日: 2026-09-26
- 更新日: 2026-10-02

ChatGPTで作ったポートフォリオの文章を置くために使います。プログラムを公開する必要はありません。

| 言葉 | この教材での意味 |
| --- | --- |
| リポジトリ | 自分のノートをまとめた保存場所 |
| Private | 非公開。許可した共同編集者や接続サービスのアクセスは別に確認する |
| main | 基本の保存先ブランチ。普段はここにある最新版を確認する |
| コミット | ファイルの変更を履歴へ記録すること |
| push | 端末側のコミットをGitHubへ反映すること |
| テンプレート | 自分用へコピーする空の用紙・ガイド・架空例 |

## アカウントを作る

1. [GitHubの登録ページ](https://github.com/signup)を開く。すでにアカウントがある場合は[ログイン](https://github.com/login)へ進む。
2. 画面に表示される登録方法を選び、メールアドレス・ユーザー名など必要な項目を入力する。ユーザー名に本名や学校名を入れる必要はない。
3. メール等の確認手続きを画面に従って終える。認証コードやパスワードをChatGPTへ貼らない。
4. 登録時の方法で次回もログインする。回復に必要な情報は自分で安全に保管する。

公式資料: [アカウントの作成](https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github)（確認日: 2026-09-26）。Google等の外部アカウントで登録した場合は、同じログイン方法を使います。新しいGoogleアカウントの作成はこの教材の必須条件ではありません。

GitHubの利用は原則13歳以上です。居住国の最低年齢がさらに高い場合もあります。本人が条件を満たさない場合は保護者自身が操作し、ログインを共有しません。[公式利用条件](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service)（確認日: 2026-09-26）

## 自分用のPrivateを用意する

[はじめ方の手順5](getting-started.md#5-本テンプレートを保護者用のgithubにコピーしてprivateに設定する)でテンプレートを複製します。配布元のURLと自分用のURLを区別します。

作成した自分用ページに、所有者／リポジトリ名と **Private** が表示されていることを確かめます。ChatGPTに保存先として伝えるのはこちらです。

GitHubにはMarkdown（.md）というテキストで残します。写真や動画の原本は外部ストレージへ置き、GitHubには所在を記録します。自分の記録を配布元へ提出する必要はありません。
