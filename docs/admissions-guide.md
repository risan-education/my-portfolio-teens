# 総合型選抜・推薦入試に向けて、計画し、記録し、出力する

- 作成日: 2026-09-26
- 更新日: 2026-09-27

このポートフォリオの第一の目的は、**日々の記録と考えを残し、大学入試の総合型選抜、推薦入試に備えること**です。募集要項を調べ、本人の関心と学部の学びをつなぐ探究を計画し、実際の経験を積み、出願先の条件に合わせて整理します。

**本教材では、高1頃に募集要項を確認した時点で、一つの大きな主テーマを選び、[6段階の探究ガイド](inquiry-project-guide.md)に沿って探究を始めることを必須の取り組みとします。** 出願用の文章を作る前に、この主テーマで調査・検証・発信・協働の経験を積み重ねます。この学習方針と、各大学が定める出願資格・選考条件は分けて確認します。

ここでいう推薦入試は、主に学校推薦型選抜を指します。学校からの推薦が関わるため、担任・進路指導の先生との相談も予定に入れます。推薦書は学校が作る書類で、本人用の活動まとめとは分けます。[文部科学省の推薦書の説明](https://www.mext.go.jp/a_menu/koutou/koudai/detail/1406125.htm)

## いつから始めるか

**高校1年生頃から、興味のある大学・学部の公開資料を調べ始める**進め方を本教材では勧めます。これは一律の公式開始時期ではなく、関心を試し、活動を振り返る時間を確保するための提案です。中学生は身近な疑問の記録から、高2・高3から始める人は今ある記録の整理と条件確認から入れます。

| 時期の目安 | すること | 残すもの |
| --- | --- | --- |
| 高1・募集要項を確認した時点 | 大学・学部の学びと自分の関心から主テーマを一つ選び、6段階の見通しを立てて最初の調査を始める。履修科目も学校で相談する | 自己理解メモ、大学・学部の比較、出願準備計画、主テーマの入口 |
| 高1〜高2 | 同じ主テーマで調査・検証を重ね、発信と協働へ進む。月ごと・学期末に見直し、学業と両立する | 元メモ、方法、結果、作品、反応・協力、失敗・変更の理由 |
| 高2〜出願年度 | 候補と選抜方式を絞り、変更予告や要項を再確認。推薦なら校内手続を早めに相談する | 条件の更新履歴、足りない準備、校内締切 |
| 受験年度の要項公開後〜出願前 | 当該年度の正式な条件に置き換え、設問別に整理し、本人・学校で確認する | 提出条件確認、根拠表、許可された範囲の提出用原稿 |

高1で読む要項は、本人が受験する年度の要項とは限りません。**入学年度・選抜方式・学部学科・公開日・確認日を記録し、過年度資料は「参考」と明記**します。文部科学省の実施要項も年度ごとに更新されます。日程はこの表から決めず、大学と学校の当該年度の案内で確認します。[文部科学省の大学入試情報](https://www.mext.go.jp/nyushi/)

## 1. 大学・学部の公式情報を調べる

テーマが先にある場合は、[テーマの選び方・方法2](choosing-inquiry-theme.md#2-好きなテーマを選びそれに合う大学学部を探す)で関心から関連分野と大学候補を探し、この節の公式条件確認へ戻れます。志望学部がある場合は同ページの方法1を使います。

志望先が未定なら、[自己理解と大学・学部選び](self-understanding.md)から候補を出します。公式の入試ページを起点に、次を[準備計画](../templates/admissions-plan.md)へ整理します。

| 調べる資料・条件 | 確かめること |
| --- | --- |
| 募集要項・訂正・変更予告 | 入学年度、大学・学部・学科、方式、対象者、募集人員、出願資格 |
| アドミッション・ポリシー | 求める学びの姿勢・知識等。募集要項の必須条件と、育てたい力を区別 |
| カリキュラム・授業・研究分野 | 入学後に何を学べるか。気になる問いをどの授業や方法で深められるか |
| 出願・選考の条件 | 評定、履修科目、資格の有効期間、共通テスト・学力試験・小論文・面接等の有無 |
| 推薦と併願 | 学校推薦の要否、専願・併願・入学確約の条件、校内選考と締切（学校に確認） |
| 書類・日程 | 設問、字数・様式、活動対象期間、証拠資料、事前登録、出願、面接、入学手続の各期限 |
| AI・本人作成の条件 | 文案作成・構成相談・添削・翻訳など、今回頼みたい作業が許されるか |

大学名だけで条件をまとめず、**学部・学科・方式ごと**に一枚作ります。総合型選抜でも学力を確認する選考があります。例えば摂南大学の2027年度総合型選抜要項では、学科によりプレゼンテーションや小論文・実技など評価方法が異なります。全大学に同じ探究成果物を出す前提にはしません。[同大学の募集要項](https://www.setsunan.ac.jp/admission/faculty/requirements/files/comprehensive/2027sougou_youkou.pdf)

ChatGPTへの依頼例:

> ［入学年度］の［大学・学部・学科・選抜方式］について、公式の募集要項、訂正情報、アドミッション・ポリシー、カリキュラムを調べてください。資料名・対象年度・URL・ページまたは見出し・確認日を付け、出願必須条件、評価方法、準備したいことを分けてください。受験年度の要項が未公開なら、過年度は参考と明記してください。templates/admissions-plan.mdで案を作り、読めない資料や不明な条件は未確認にしてください。

検索機能がない、PDFを読めない、校内情報が公開されていない場合は、その箇所を本人や先生が確認します。検索結果の短い紹介だけで条件を確定しません。

## 2. 主テーマを一つ選び、6段階の探究を開始する

選ぶ前に、[学部・学科の関心別の架空例18例](../examples/inquiry-themes/README.md)を読めます。各例は最初の問い、方法、6段階の計画、高校生活を通した深め方を示しています。[文部科学省・JST・大学の調査メモ](inquiry-theme-sources.md)で実践事例と入試の評価条件の違いも確認してください。例の動機や想定結果を自分の実績にせず、自分の関心と実行できる範囲から選びます。

「本人が知りたいこと」「大学で学びたい内容」「選考で確認されること」を並べ、重なる部分を探します。要項の言葉に合わせて過去の動機を作り直さず、**今から取り組む問いと方法**を決めます。学部に関係がありそうという推測と、要項に明記された評価条件は別欄にします。

[6段階の探究ガイド](inquiry-project-guide.md)に従い、[プロジェクト用紙](../templates/inquiry-project.md)で主テーマの入口を作ります。6段階全体の見通し、最初の具体的な問い、予想、先行資料、調べ方、期間・費用、協力や同意、最初の行動予定、月ごと・学期末の振り返りを置きます。[探究ノート](../templates/inquiry.md)は、その中の個々の調査・検証の詳細に使います。評定・履修・資格・試験の準備も、探究とは別に計画へ入れます。

例えば「案内を分かりやすくしたい」なら、観察→表示の試作→相手の反応→修正を計画できます。「探究したから出願条件を満たす」とは判断せず、当該方式の条件と照合します。

> 私の関心は［関心］、参考にした公式資料と条件は［確認メモ］です。一つの主テーマを選ぶために候補を二案出し、私と相談してください。選んだテーマはdocs/inquiry-project-guide.mdに従い、templates/inquiry-project.mdで6段階全体の見通しを作ってください。最初の問いと調査予定、教科学習、期間・費用・協力の確認、残す証拠、月ごと・学期末の見直しを分けてください。要項の必須条件とAIの提案、計画と実施を区別してください。

## 3. 実際に探究し、日々の考えを残す

実施ごとに、元メモ、方法、日付、結果、本人の役割、考えたこと、予想との違い、次の行動を残します。写真・データ・作品は所在も記録します。計画と実績を分け、うまくいかなかった試みや未解決の問いも残します。

探究は、問いを決め、情報を集め、整理・分析し、まとめて伝える流れを行き来する学びです。文部科学省の説明を参考に、本教材では反応を受けた修正まで記録します。[探究のプロセス](https://www.mext.go.jp/content/1421972_2.pdf)

> 今日実際にしたことは［メモ］です。計画と実施、結果と考察、私の担当と他の人の担当を分けて残してください。うまくいかなかった点も残し、前の記録とつないでください。

## 4. 振り返り、根拠のある材料集を作る

学期末などに、本人が使ってよいとした記録から[根拠付き要約](../templates/evidence-summary.md)を作ります。何に疑問を持ち、何を試し、どう考えが変わり、大学で何を学びたいかを整理します。各主張には原記録を付け、本人の今の考えを確認します。

出願先が決まる前の材料集は、本人の振り返り用です。出願に使うときには、次のAI利用条件の確認を改めて行います。過去にAIで作った文章だから自動的に提出できる、とは扱いません。

## 5. 総合型選抜・推薦入試用に出力する

### 先に、AIが手伝える範囲を確認する

[提出条件確認](../templates/submission-check.md)に、その年度・学部・方式の公式条件を記録します。**「AIについて記載を見つけられない」は「利用可」ではありません。** 不明なら学校や大学の案内窓口に本人が確認し、それまでは条件の確認にとどめます。提出用の材料整理、本文・構成案、添削・翻訳、質問生成、模擬面接は[提出条件確認](../templates/submission-check.md)の作業別表で判断し、一律に例外扱いしません。

実例として、摂南大学の2027年度総合型選抜要項は、志望理由書・学修計画書・プレゼンテーション資料等の作成に生成AIを使うことを禁止しています。禁止されている場合は、AIによる作成・添削や、AI文案を本人が書き直して提出する手順へ進みません。本人が条件に沿って作成します。[同要項の生成AIに関する記載](https://www.setsunan.ac.jp/admission/faculty/requirements/files/comprehensive/2027sougou_youkou.pdf)

### 許可された範囲で、設問ごとに出力する

[出願用出力シート](../templates/admissions-output.md)を使い、次の順で進めます。

1. 提出先・設問・字数・形式と、許可されたAI作業を確認する。
2. 本人が選んだ原記録を、設問と対応させる。根拠がない箇所は質問として残す。
3. 条件に応じて、活動報告の材料、志望理由の構成案、探究発表の構成、面接練習の質問などを作る。許可の範囲外の出力は作らない。
4. 本人が自分の言葉・事実・役割・今の志望を確認し、必要なら先生にも確認してもらう。
5. 募集要項指定の様式へ転記し、文字数、添付、引用・AI利用の表示条件、表示崩れを確認する。提出は本人が別に行う。

**根拠表・確認メモと、外へ出す本文は分けて保存**します。標準の出力はMarkdownです。PDF・Word・Web入力などが指定されたら、その様式に合わせて別途整えます。Private内のリンク、性格メモ、見せない記録、AIへの指示を提出用本文へ混ぜません。外部提出のためにリポジトリを公開する必要はありません。

> 総合型選抜・推薦入試用に出力する準備をしてください。対象は［入学年度・大学・学部・学科・方式］、設問は［設問］、公式資料は［URLまたは資料］です。まずtemplates/submission-check.mdでAI利用条件と提出条件を確認してください。条件が未確認・禁止なら本文は作らないでください。許可された範囲で、［選んだ記録］からtemplates/admissions-output.mdの案を作り、設問と原記録の対応、不足情報、私への確認事項を示してください。根拠表と提出用本文は分けてください。

確認後の保存依頼:

> 確認した範囲を、derived/YYMMDD-admissions-evidence.mdと、必要ならderived/YYMMDD-application-draft.mdへ分けて保存してください。同名は上書きせず、保存先と確認結果を教えてください。提出はしないでください。

## 大学・学部選びへ戻る

探究して関心が変わったら、[自己理解](self-understanding.md)と[進路探索用紙](../templates/career-exploration.md)で候補を見直します。自己理解は本人が納得できる選択の材料です。性格の点数や記録量で合格可能性を判定しません。

公式資料の確認日: 2026-09-26。高校生活の時期別の進め方と出力手順は、本教材の提案です。実際の出願・大学への問い合わせ・提出は行っていません。[架空の出力例](../examples/admissions-output.md)／[README](../README.md)

探究の記録を文章へつなぐときは[レポートのまとめ方](inquiry-report-guide.md)と[用紙](../templates/inquiry-report.md)を使えます。指定様式とAI利用条件を優先し、本人の分析と論述を残します。
