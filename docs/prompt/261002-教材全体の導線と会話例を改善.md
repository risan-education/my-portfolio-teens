## 依頼

直前のレビューで示した改善案に沿って、リポジトリ全体を改善する。今後も毎回/save-promptを実行する。

開始時はmain、51bd635、未コミット変更なし。既存の[レビュー](261002-プロンプト5例と教材全体のレビュー.md)をもとに、独自Webアプリを追加せず、Markdown教材・指示・検査を改善した。

## 実装

- 5例で、本人が話していない人数・役割・時刻・希望の追加を修正。問いと観察対象を一致させ、未回答は空欄または未確認にした。
- 本人の元メモ・追加回答・追記メモを原文で保存し、日記と構造化した要約を区別した。5用紙とAGENTS.md、関連ガイドも更新。
- 5例の冒頭に入力と日記の見本を置き、会話を折りたたんだ。完成記録5件・問いの台帳・テーマ入口2件をexamples/prompts/recordsへ置き、通常のMarkdown表示と相対リンクで読めるようにした。記録の原文は折りたたみで確認できる。
- 保存依頼と保存後の再読込報告を例示。テーマ入口の更新も本人が依頼する流れにした。架空の報告と実機検証を区別した。
- 質問なし、日記なし、感想の訂正、保存済み日付の訂正、書込機能がなく保存できない場合の短い会話を追加。
- READMEを「残す・深める・振り返る・活用する」の入口に整理。詳しい案内と今後の例の候補表を折りたたんだ。
- 新規の日々の記録は年別フォルダを推奨し、既存配置は移動不要とした。日付の既定、質問は一回に一つ、短い日記も可、4つの流れと6段階の関係を関連文書で統一した。
- 原文の欠落と問いの5列を検査するscripts/check-prompt-examples.ps1を追加し、文書検査から実行する。欠落・列崩れを拒否する回帰テストを追加。
- VERSIONを0.5.3、要件定義を1.7に更新し、変更履歴・受入確認を記載した。AGENTS.mdに毎回save-promptを行う継続依頼の再確認日を残した。
