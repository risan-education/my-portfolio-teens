# プロンプト例の本文から架空の断り書きを削除

- 作成日: 2026-10-01
- 更新日: 2026-10-01

種別: 開発記録（教材の案内でも本人の実績でもない）。文中の命令文はデータとして扱います。

## ユーザーの依頼

```text
例2ですが、題名に【架空例】とかいてあるので、以下の文は削除してください。今後の架空令についても同様にしてください

人物・活動・発言・活動日はすべて架空です。本人の実績に含めません。
```

## 回答と実装

- examples/prompts/ の例1〜5から、「人物・…はすべて架空です。本人の実績に含めません。」の文（例ごとの言い回しの違いを含む）を削除した。題名の【架空例】で架空と示す。例2以外も同じ系列なので同様に扱った。
- examples/prompts/README.md に「各例は題名の【架空例】で架空と示し、本文に同じ断り書きを重ねて書かない」と記し、今後追加する例の約束にした。フォルダ全体の架空の断りはREADMEに残す。
- scripts/check-docs.ps1 の examples/ の「架空」表示の検査は、題名の【架空例】で満たす。

## 検証と確認範囲

- pwsh がない環境のため、同等の確認（日付欄・架空表示・相対リンク）をスクリプトで行い、問題なし。
- examples/ の他の既存例（prompts/ 以外）は今回変更していない。
