- 更新日: 2026-10-01

```text
https://github.com/risan-education/my-portfolio-teens/tree/main/experiences が、まだ、自動的にREADME.md が表示されてしまいます。

記録が1件もないうちは README だけが表示される　で、お願いします
```

## 回答と実装

- GitHub の仕様（フォルダのページは一覧の下にそのフォルダの README.md を自動表示する）を説明し、「このままにする」案と「フォルダの README を別名にして自動表示を止める」案を示した。利用者は前者を選択。
- docs/where-records-go.md の「一覧の見方」に、記録が1件もないうちは一覧が README.md の1行だけなので README の本文だけが見えること、記録を保存すると一覧の行が README より上に並ぶことを追記した。
- フォルダの README.md の名前・リンク・検査スクリプトは変更していない。

## 検証と確認範囲

- pwsh がない環境のため、同等の確認（日付欄・相対リンク等）をスクリプトで行い、問題なし。
- GitHub の画面表示は一般的な仕様に基づく説明で、本人用Privateでの見え方は利用者が確認する。
