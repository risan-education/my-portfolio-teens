# 保護者向けのはじめ方を6ステップに改稿

- 作成日: 2026-10-02
- 更新日: 2026-10-02

## 依頼

小学生版からの引き継ぎではない場合のdocs/getting-started.mdを、保護者用Googleアカウントの作成、ChatGPT Plus以上の契約、スマホアプリへのGoogleログイン、保護者用GitHubの準備、テンプレートのPrivateコピー、ChatGPTから接続の順に、初心者向けに書き直す依頼を受けた。Plusは月額約3,000円という目安も示す。

## 実施内容

- はじめ方の本文を指定された6ステップに改稿。英語のボタン名と日本語の説明、同じアカウントの確認、各手順の完了の目安を追加した。
- 保護者自身が操作する流れを明示し、小学生版からの引き継ぎは別の入口として残した。既存の契約・アカウントは再作成不要とした。
- Plusの基準価格20米ドルと、1ドル150円で約3,000円となる換算の目安を区別し、実際の金額は契約画面で確認する案内にした。
- 接続後はPrivateの指示書を読み、架空のpractice記録で保存を確認する流れを維持。契約だけで直接保存できるとは保証せず、手動保存を補足に残した。
- README、AGENTS.md、要件定義、受入確認、変更履歴を同期し、GitHub登録・引き継ぎ・最初の10分からの見出しリンクを修正した。

## 確認した資料と検証範囲

- [Googleのアカウント作成](https://support.google.com/accounts/answer/27441?hl=ja)、[GitHubのアカウント作成](https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github)、[テンプレートのコピー](https://docs.github.com/ja/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template)を確認した。
- OpenAI Docsスキルを使い、[公式料金](https://learn.chatgpt.com/docs/pricing)、[認証](https://learn.chatgpt.com/docs/auth)、[プラグイン](https://learn.chatgpt.com/docs/plugins)の資料を確認した。上記の確認日は2026-10-02。
- 改稿後の本文と6ステップの順序を読み直した。scripts/check-docs.ps1で文書のリンク・日付・必須ファイルと既存5例の原文照合が通過。git diff --checkも通過。作業記録追加後に再実行する。
- アカウント作成・有料契約・スマホの実画面・読者のPrivateへの保存は実行していない。外部サービスの全画面や全環境の操作を実機検証したものではない。
