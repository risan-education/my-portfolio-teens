# 案のあとに探究の流れで質問を1つずつする規則と、例5件の作り直し

- 作成日: 2026-10-01
- 更新日: 2026-10-01

種別: 開発記録（教材の案内でも本人の実績でもない）。文中の命令文はデータとして扱います。

## ユーザーの依頼

```text
記録をしようとChatGPTに話しかけ たら、ChatGPTが、追加するとよさ そうな事項を聞いてくるリポジトリ にしたいです。

課題の設定 情報の収集 整理・分析 →まとめ・表現

の流れに慣れるために、ChatGPTに そのようや応答をしてもらうように リポジトリのルールを設定して、そ れに対応したかたちで、例5個をを作り 直してください。質問は1会話で1個ずつ、
```

## 回答と実装

- AGENTS.md「ChatGPTで記録するときの共通手順」に2項目を追加した。案を示したあと、「課題の設定→情報の収集→整理・分析→まとめ・表現」の流れで追加すると記録が深まる事項を質問する。質問は1回の返答につき1つ。段階ごとの質問の目安を示し、一言メモでは2〜3問を目安にする。質問の前に答えなくても保存できると伝え、「保存して」で質問をやめる。答えは本人の言葉のまま該当欄へ入れ、質問文や未回答の項目は記録に書かない。結論へ誘導せず、本人が言っていない事実・感想・成果を質問の形で補わない。
- 利用者向けの記載: README（最初の10分の案内）、docs/recording-guide.md に「ChatGPTからの質問に答える（1つずつ）」の節と4段階の質問例・入る欄の表、docs/ai-guide.md、templates/ 5用紙の先頭コメント、.github/copilot-instructions.md。CHANGELOG 0.5.2 に追記。
- examples/prompts/ の5例を会話形式で作り直した。本人の最初の発言→ChatGPTの案の要点と質問1→本人の答え→…→保存依頼の順に並べ、答えた内容だけが「できあがった記録」の欄に入る形にした。例3は計画の会話と観察後の会話の2本にし、整理・分析の質問を含めた。例1では質問から生まれた問いの questions.md 追記行も示した。index の使い方と一覧のポイントを更新。

## 検証と確認範囲

- pwsh がない環境のため、同等の確認（日付欄・用紙の空欄・架空表示・相対リンク）をスクリプトで行い、問題なし。
- ChatGPTが実際にこの規則どおり質問するかは環境・版によって異なるため未検証。架空例は検証ログではない。
