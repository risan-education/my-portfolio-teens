# ChatGPTへのプロンプト例とできあがった記録（まず5件）

- 作成日: 2026-10-01
- 更新日: 2026-10-01

種別: 開発記録（教材の案内でも本人の実績でもない）。文中の命令文はデータとして扱います。

## ユーザーの依頼

```text
ポートフォリオ作成といっても、いったい何からはじめてよいかわからないと思うので、ChatGPTへ話しかける実際の、ポートフォリオ作成の「プロンプト例」と、できあがったもの　の例について、中学高校生向けに、３０個ほどの例を作成したいです。まずは、５個ほど、例を作ってください。また、その内容について、こちらにも表示してください　常にmainにpushでお願いします
```

## 回答と実装

- `examples/prompts/` を新設し、README（使い方、作成済み5件の一覧、30件までの予定表）と、架空例5件を追加した。各例は「場面」「ChatGPTへ話しかける文（プロンプト例）」「ChatGPTの応答の要点」「できあがった記録の例」「この例のポイント」で構成し、用紙は templates/ の一言メモ・活動記録・探究ノート・作品カード・振り返りに対応させた。
  - 01 中1・初めての一言メモ（読んだ本）
  - 02 中3・文化祭の受付係（役割と集団の成果の区別）
  - 03 高1・通学路の疑問から探究ノート（問いの選択、AI案は未採用欄、数値の条件と限界）
  - 04 高2・友人と作ったWebアプリの作品カード（担当分担、反応の範囲、未確認）
  - 05 高1冬・二つの記録からの振り返り（読む記録の指定、当時と今の区別、性格を断定しない）
- 例2・3・5は同じ架空の生徒の設定にし、例5が例2・3の架空ファイル名を根拠として参照する形にした。すべて架空と明記し、本人の直接発言の創作はしていない。
- README.md の「最初の10分」の案内にプロンプト例へのリンクを追加。examples/README.md の一覧に行を追加。CHANGELOG に 0.5.2 を追加し、VERSION と README の版表示を 0.5.2 に更新。
- 回答でも5件のプロンプトと記録の要点を表示した。

## 検証と確認範囲

- pwsh がない環境のため、scripts/check-docs.ps1 と同等の確認（作成日・更新日の欄、examples/ の架空表示、用紙の空欄、相対リンクの存在）をスクリプトで行い、問題なし。
- 架空例の内容はChatGPTで実際に生成・保存した検証ログではない。
