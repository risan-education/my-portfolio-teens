# 中高生ポートフォリオ教材の整備と作業記録

- 作成日: 2026-09-27
- 更新日: 2026-09-27

## ユーザーの依頼

小学生版リポジトリと要件定義を参考に、ChatGPTを使う中高生版ポートフォリオを作成する。第一の目的は「日々の記録と考えを残し、大学入試の総合型選抜、推薦入試に備える」。登録・契約・アプリ導入・記録開始の説明、小学生版からの引き継ぎ、出願準備と出力、自己理解と学部選びを用意する。

ファイル名はYYMMDD-theme.md形式とし、移行は「新しいPrivateリポジトリへ、小学生用リポジトリの内容をコピーする」を最初のおすすめにする。高1頃に募集要項を確認し、一つの主テーマを6段階で探究する流れを重視する。

多分野の架空の探究例を10件以上掲載し、IBDPのExtended Essayも参考にする。テーマ選びは、志望学部から選ぶ方法と、好きなこと・日々の記録から選んで学部を探す方法を解説する。探究テーマ18例には、成果を文章にまとめた章をそれぞれ追加する。最後にsave-promptで会話と作業を記録し、全変更をコミットしてmainへpushする。

## 回答と実装

- ChatGPTでの準備・案の確認・保存の手順、15種類の用紙、目的別ガイド、共通AI編集指示を整備。通常のGitHub接続と書き込み対応環境を区別し、手動保存とClaude Code利用の補足も用意。
- 小学生版から原文・日付・相対リンクを保ってコピーする移行ガイドと架空例を作成。ファイル名の日付形式の変換は不要と明記。
- 募集要項の確認、探究の計画・実施、根拠付きの出願用出力を接続。得意・苦手・好き・嫌い、任意のBig Fiveの観点を本人確認付きで整理する説明を追加。
- 6段階ガイド、学部の関心別の探究計画18例、EEを参考にした研究計画15例、テーマ選びの二つの方法と架空の会話を追加。公式資料の出典と確認範囲は各ガイドに記載。
- 探究テーマ18例すべてに「探究学習成果の文面の例」を追加。教材として800〜1,200字程度を提案し、実際の本文は886〜939字。問い・方法・結果・見直し・限界・次の課題を段落で表現し、活動・数値・結果は架空と明記。一覧から各章へ直接リンクを設けた。
- 要件定義、変更履歴、受入確認を更新。教材の字数目安と大学の指定条件、教材の学習方針と実際の出願条件を区別した。

## コミットとpushの予定

対象は[my-portfolio-teens](https://github.com/risan-education/my-portfolio-teens)のmain。save-promptの指定に従い、この記録を含む現在のリポジトリ内の全変更を一つのコミットにまとめ、origin/mainへpushする。実行結果とコミット識別子は完了時の応答で報告する。
