# 各記録の冒頭に日記風の文を置く節を追加

- 作成日: 2026-10-01
- 更新日: 2026-10-01

種別: 開発記録（教材の案内でも本人の実績でもない）。文中の命令文はデータとして扱います。

## ユーザーの依頼

```text
ポートフォリオの成果物として、後でAIで出力するためのデータとしてmdファイルで良いのですが、人間がすぐに読みやすいように、最初か最後に、日記風の文章を作成してほしいです。どこに書いたらわかりやすいか提案して下さい
```

```text
提案通りでお願いします
```

## 回答と実装

- 提案: 各記録の冒頭（日付欄の直後）に「## 日記（本人が確認した文）」の節を置く。末尾案は長い探究ノートで読みにくく、別ファイル案は記録と日記が分かれるため採らない。利用者が提案どおりで了承。
- templates/ の5用紙（一言メモ・活動記録・探究ノート・作品カード・振り返り）に、日付欄の直後の節とAI向けコメントを追加。日付欄は空欄のまま。
- AGENTS.md「ChatGPTで記録するときの共通手順」に規則を追加: 質問を終えるとき（本人が止めたときも）に、元のメモと本人の答えだけから一人称の短い文（100〜200字）を案として示し、本人が直して保存で確定する。新しい事実・感想・成果を足さず、答えていない項目は書かない。追記する記録では日付付きの段落を足し、前の段落は書き換えない。要約・言い換えなので「本人の実際の言葉」には含めず、元のメモは別に保持。本人が不要と言えば空欄。
- README（最初の10分の案内）、docs/recording-guide.md（「冒頭の日記を確かめる」の節）、docs/ai-guide.md、examples/prompts/README.md（使い方の手順）に記載。
- examples/prompts/ の5例に、ChatGPTが質問の最後に日記の案を示す発言と、できあがった記録の冒頭の日記の節を追加。例3は会話1・会話2に対応する日付付きの2段落にした。
- CHANGELOG 0.5.2 に追記。

## 検証と確認範囲

- pwsh がない環境のため、同等の確認（日付欄・用紙の空欄・架空表示・相対リンク）をスクリプトで行い、問題なし。
- 例の日記の文は、各例の元のメモと本人の答えに含まれる内容だけで構成した。ChatGPTが実際に同じ振る舞いをするかは環境・版によって異なるため未検証。
