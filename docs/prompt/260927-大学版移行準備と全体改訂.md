# 大学版への移行準備とポートフォリオ全体の改訂

- 作成日: 2026-09-27
- 更新日: 2026-09-27

## 依頼と目的

利用者はgit pullを依頼し、公開予定の中高生向けポートフォリオについて詳細な調査と改善案を求めた。ChatGPTとの会話で日常の活動・考えを記録し、探究学習、総合型選抜・学校推薦型選抜の書類、面接に活用することが目的。大学版へ引き継いで就職活動のガクチカに使い、社会人以降もAIへ渡すコンテキストとして継続する構想がある。

大学版 my-portfolio-univ は仮の要件定義のみ作成済みとの説明を受け、中高生版の改訂を先に行い、その成果を後で大学版の要件定義へ反映する方針とした。利用者は改善案に沿ったリポジトリ全体の修正を依頼し、その後save-promptで作業記録の保存と全変更のコミット・pushを依頼した。

## 調査と実装

- git pullでmainをd92aa9eへ更新。教材構成、接続説明、原記録保持、入試・面接、卒業後の継続を点検した。
- 教材を0.5.0、要件定義を1.5へ改訂。大学版の実装・互換性は未確認と明記し、共通仕様、移行手順、確認表、架空例を整備した。
- 許可した記録を元の相対配置でコピーし、日付欄のない旧記録、入れ子のlegacy、当時の問いや役割を保つ方針を追加した。旧指示・設定は新しい保存先へ持ち込まない。
- 読取専用の移行検査を追加。許可一覧のSHA-256一致とコピー先の余分なファイルを確認する。文書検査ではlegacyの日付を強制せず、旧リンクの問題は要確認として報告する。
- 探究レポート用紙と、既存の架空原記録からレポート・面接へつながる例を追加。実施と計画、本人の役割、結果と限界を分けた。
- 提出用の材料整理・本文・添削・質問生成・模擬面接等について、作業ごとにAI利用条件を確認する説明へ揃えた。
- 接続の書込成功報告と、端末・プラン・接続名・保存経路を揃えた再現検証を区別した。mainへの直接保存と別ブランチ・PR、端末内保存を区別する。
- 任意の記録索引、判断の経緯、自己紹介の現在版・見直し日、利用停止の派生文書への反映を整備した。教材・架空例・練習・開発記録を本人の実績から除外する。
- README、AI向け指示、関連ガイド、変更履歴、受入確認を更新し、外部記事に使う紹介文案を用意した。外部記事と大学版リポジトリは変更していない。
