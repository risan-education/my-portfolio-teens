# 記録の保存先・呼び出し方・一覧の場所を案内に追加

- 作成日: 2026-10-01
- 更新日: 2026-10-01

種別: 開発記録（教材の案内でも本人の実績でもない）。文中の命令文はデータとして扱います。

## ユーザーの依頼

```text
それぞれの記録が、どのフォルダに保存されるのか、どのように呼び出せばよいか？どこにリストがあるか、記載してください
```

## 回答と実装

- 新規 `docs/where-records-go.md` に、記録の種類（一言メモ・活動記録・探究ノート・作品カード・主テーマの6段階・振り返り・年間振り返り・問い・今の自分・要約等・資料所在・練習・索引）ごとの用紙、保存先とファイル名の例、一覧の場所をまとめた表と、「一覧の見方」（フォルダがそのまま一覧、questions.md、projects/<テーマ>/README.md、増えたら索引）、ChatGPTへの呼び出し方の例文（ファイル名で指定、フォルダ・期間・テーマで探す、問いから探す、読む記録を指定する）、自分でGitHubを開く方法を記載した。
- README の「記録を置く場所」の表の下と「次からは、このように頼めます」、ガイド一覧からリンク。docs/recording-guide.md の「名前・日付・探し方」からもリンク。
- examples/prompts/README.md に、5例それぞれの保存先・呼び出す言い方・一覧の場所の表を追加。各例ファイルにも「保存先・呼び出し方・一覧」の節を追加した。
- CHANGELOG 0.5.2 に追記。

## 検証と確認範囲

- pwsh がない環境のため、同等の確認（日付欄・用紙の空欄・架空表示・相対リンク）をスクリプトで行い、問題なし。
- フォルダ構成や用紙は変更していない。索引・questions.md の仕組みは既存のまま。
