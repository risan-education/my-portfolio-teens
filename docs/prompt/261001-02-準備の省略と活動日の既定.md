# 準備の依頼を省略可能にし、活動日の既定を話しかけた日にする

- 作成日: 2026-10-01
- 更新日: 2026-10-01

種別: 開発記録（教材の案内でも本人の実績でもない）。文中の命令文はデータとして扱います。

## ユーザーの依頼

```text
AGENTS.mdを読んで、記録を始める準備をしてください。準備ができたら、次の一言を一言メモの用紙で記録する案を見せてください。

昨日、図書室で借りた深海の本を読み終わった。光らない魚がいるのが意外だった。活動日は2026-05-11です。

これが、長すぎます。最初の1文は省略できるようにリポジトリのルールを修正して下さい。

活動日は今日です。みたいな入力、または、なにも指定がなければ、ChatGPTに話しかけた当日のこととして記録する設定にして、そのこともわかりやすい場所に記載してください
```

## 回答と実装

- AGENTS.md「ChatGPTで記録するときの共通手順」に、準備の依頼を省略できる規則を追加した。本人がメモだけを送ったときは、接続済みならAGENTS.mdとREADMEを読んだうえで一言メモの用紙で案を作り、「準備をしてください」「一言メモの用紙で」の一文を求めない。活動記録の方が合いそうなときは提案にとどめ、本人が選ぶまで一言メモで進める。
- AGENTS.md「保存と日付」に活動日の既定を追加した。指定がなければChatGPTに話しかけた当日（Asia/Tokyo）の出来事として記録し、活動日欄に「（指定なし。話しかけた日）」と添える。「今日」「昨日」「先週の土曜」は会話当日から換算して案に示し本人が確認する。本当に分からないときだけ未確認。この既定は活動日だけに適用し、発言・成果・数値を補う理由にしない。
- 同じ内容を利用者が見る場所に記載: README.md（最初の10分の案内に太字で追加）、docs/recording-guide.md（新しい会話・一言だけ残す）、docs/ai-guide.md、docs/getting-started.md（手順5）、docs/first-10-minutes.md、templates/quick-note.md（活動日欄のコメント）、examples/chatgpt-session.md（準備の見出し）、examples/prompts/README.md。
- examples/prompts/01 のプロンプトをメモ1行だけに短縮し、「昨日」を話しかけた日（2026-05-12）から2026-05-11に換算して確認する流れに変更。02 には「活動日を書いたのは話しかけた日と違うため」の注記を追加。CHANGELOG 0.5.2 に追記。
- 同日の作業記録が既にあったため、規則に従い `261001-ChatGPTプロンプト例5件.md` を `261001-01-ChatGPTプロンプト例5件.md` へ改名した（他ファイルからのリンクなし）。

## 検証と確認範囲

- pwsh がない環境のため、scripts/check-docs.ps1 と同等の確認（作成日・更新日の欄、用紙の空欄、examples/ の架空表示、相対リンク）をスクリプトで行い、問題なし。
- ChatGPTが実際にこの既定どおりに振る舞うかは、接続環境・版によって異なるため未検証。利用者が最初の練習で確かめる前提は変えていない。
