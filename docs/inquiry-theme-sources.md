# 探究の例を公式資料から探す — 文部科学省・JST・大学の資料

- 作成日: 2026-09-26
- 更新日: 2026-09-26
- 以下の公式ページ・明記した本文箇所の確認日: 2026-09-26

**文部科学省やJSTには、高校の探究・課題研究の実践事例が掲載されています。** 大学の公式入試ページには、探究の成果や過程を扱う選抜の説明もあります。この二つを組み合わせ、学習の方法と、出願先が確認する事項を分けて読みます。

本リポジトリの[架空の探究テーマ18例](../examples/inquiry-themes/README.md)は、以下の資料から探究の過程・比較・改善・協働の観点を参照し、独自に作成した計画です。実践事例の転載、実在の生徒の合格事例、文部科学省によるテーマの認定ではありません。仮説・人数や期間の目安・学部との接点は本教材の提案です。

## 何を参考にしたか

<a id="s1"></a>

### S1 文部科学省 — 探究全体の進め方と資料の入口

- [総合的な学習（探究）の時間の資料](https://www.mext.go.jp/a_menu/shotou/sougou/main14_a2.htm)：高等学校向け手引き、学習指導要領解説、探究に関するコンテスト一覧へのリンクがあります。高等学校編の手引きは令和5年3月版として掲載されています。
- [探究の過程等を説明する資料（PDF）](https://www.mext.go.jp/content/1421972_2.pdf)：課題の設定、情報の収集、整理・分析、まとめ・表現の過程を確認しました。

**本教材への反映:** 大きな社会課題を掲げるだけでなく、確かめられる問いと方法を置き、結果から問いを見直す構成にしました。18例共通の考え方で、歴史、食品ロス、スポーツなどの例にも使っています。本教材の6段階は、[既存の探究ガイド](inquiry-project-guide.md)が採用した独自の構成です。

手引き全体のPDFは今回の閲覧環境で容量制限により通読できていません。掲載ページと上記の探究過程のPDFを確認した範囲で紹介しています。手引き内の個別事例を確認済みとして引用してはいません。

<a id="s2"></a>

### S2 文部科学省 — 修学旅行を教科横断で探究する実践

[長野県中野西高等学校「情報社会と問題解決・総合的な探究の時間との連携」（PDF）](https://www.mext.go.jp/content/20240507-mxt_jogai01-000021508_007.pdf)の1〜3ページを確認しました。候補地の情報を整理・地図化し、観光協会や旅行会社の話も踏まえて生徒が旅行計画を考える実践です。文化・歴史・産業などの教科学習ともつなげています。

**本教材への反映:** 情報を集めた後、同じ基準で比較し、条件のある計画へ変える観点を参考にしました。共有教室のルール、在庫計画、地域案内、交通のモデルの例は、今回独自に作った別のテーマです。公式事例でそれらの効果が実証されたという意味ではありません。

<a id="s3"></a>

### S3 文部科学省 — 地域観光のピクトグラムを検証・改善する実践

[栃木県立足利南高等学校「地域観光ピクトグラム」（PDF）](https://www.mext.go.jp/content/20250325-mxt_jogai01-000021508_004.pdf)の1〜3ページを確認しました。地域の課題を整理してピクトグラムを制作し、生徒同士の評価を基に改良し、発表する実践が紹介されています。

**本教材への反映:** 制作して終わらず、受け手の反応で改良する過程を参考にしました。お知らせの探索、図書館案内、情報システム、健康情報の案内、作品展示の例へ応用しています。各例の具体的な比較条件や対象者は本教材の提案です。

さらに読むなら、[文部科学省・高等学校情報科の実践事例一覧](https://www.mext.go.jp/a_menu/shotou/zyouhou/detail/mext_01833.html)から、情報デザイン、データ活用、モデル化などの題材を探せます。一覧にある全PDFの本文を確認したわけではありません。

<a id="s4"></a>

### S4 JST — SSHの継続研究・連携の実践

[SSH「事例と成果」](https://www.jst.go.jp/cpse/ssh/result/)には研究開発実施報告書・成果物などへの入口があります。[「特徴的な取組」](https://www.jst.go.jp/cpse/ssh/result/case/result.html)では、ページ内検索で学校名や分野を探せます。

今回確認した掲載本文の例:

- **神奈川県立横須賀高等学校（令和6年度掲載）**：3年間の課題研究「Principia」で研究を深め、論文にまとめ、下級生への助言にもつなげる実践。
- **三重県立松阪高等学校（令和6年度掲載）**：大学と連携し、高校生が小学校で理数の授業を実践する取り組み。

**本教材への反映:** 教育、工学、建築、生物、農学の例で、最初の小さな検証から複数年で問いを育て、協力者と方法を改善する見通しを置きました。掲載校の設備・専門家との連携をそのまま必須にはしていません。高校生個人でも可能な紙の試作や学校内の観察へ規模を調整しています。

SSHの実践報告は学習方法を探す資料で、ここに載った活動が一律に入試の加点対象になるという資料ではありません。

<a id="s5"></a>

### S5 大学の公式入試ページ — 探究をどう扱うか

**関西学院大学：[探究評価型入学試験](https://www.kwansei.ac.jp/admissions/guideline/exploratory.html)**（2027年度要項への案内があるページ）の「入試のポイント」「探究活動タイプ」を確認しました。成果と過程を扱い、活動の整理にはデータ収集、交流・協働、学術的考察という異なるタイプが示されています。高校入学後の活動という対象期間もあります。

**本教材への反映:** 実験だけを探究とせず、文学の読解・史料比較も、自分の問いと根拠を持って深める例として作りました。特定の例が同大学の出願条件を満たすとは判定していません。

**帝塚山大学：[総合型選抜 探究型](https://www.tezukayama-u.ac.jp/admission/admissions/admissions_office_exploration/)**（2027年度案内）の「プレゼンテーションテーマ」「評価のポイント」を確認しました。研究内容、協働での本人の役割、説明、志望学科の学びとの関連が示されています。

**本教材への反映:** 各例に、方法を選んだ理由、考えの変更、本人の担当、大学でさらに学びたいことを残す欄を設けました。

ここで確認したのは各大学の上記ページです。リンク先の共通要項・学部別条件・訂正情報まで含む出願資格審査や、全提出物のAI利用可否の確認を完了したものではありません。実際に受験する場合は、[出願準備ガイド](admissions-guide.md)で当該年度の要項一式を読み直します。

## 自分で実例を探し、読む手順

IBDPのExtended Essayも研究課題と方法を考える参考になります。[IB公式資料に基づくガイド](extended-essay-guide.md)に、2027年初回評価からの変更、公開題名例、正式なEEとの違いを記しました。[独自の架空例15件](../examples/extended-essay/README.md)と[テーマの選び方](choosing-inquiry-theme.md)へつながります。

1. 文部科学省の資料ページやJSTの事例ページで、気になる分野・地域・方法を探す。検索語は「植物 比較」「史料 地域」「情報デザイン 改善」など、テーマと方法を組み合わせる。
2. 気になった学校の公式サイトに活動報告・研究要旨があれば、元の本文を読む。検索結果の題名だけで、方法や結論を読んだことにしない。
3. 「問い」「比較したもの」「集めた資料・データ」「結果と限界」「見直し」「協力と本人の担当」を短く整理する。本人の記録とは別に、文献メモとして出典・ページ・確認日を残す。
4. 自分の環境に置き換えた問いを作る。入試に使えるかは、その研究の受賞歴ではなく、候補大学の年度・学部・方式の公式条件で確認する。

| 読むときの問い | メモする内容 |
| --- | --- |
| 何を、なぜ知りたかったのか | 自分の経験との共通点・違い |
| どう確かめたのか | 対象、比較条件、必要な資料や道具 |
| 何が言えて、何が言えないか | 反例、規模、因果関係を断定していないか |
| 自分の環境ならどう始めるか | 一週間でできる行動、協力がなくても可能な範囲 |
| どこに書いてあったか | 発行元、資料名、年度、URL、ページ、確認日 |

他の人の仮説・図・データを自分の発見として扱わず、引用する場合は出典と利用条件を確認します。先行例と同じ問いでも、対象や方法の違いを明らかにし、自分が実際に確かめた範囲を記録します。
