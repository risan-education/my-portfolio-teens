# はじめ方 — 保護者と一緒にChatGPTで記録を始める

- 作成日: 2026-09-26
- 更新日: 2026-10-02

日々の経験や考えをChatGPTに伝え、できた文章を確かめて保存するための準備をします。残した記録は、探究学習や大学入試の総合型選抜・推薦入試の準備にも使えます。プログラミングの知識は不要です。

**小学生版から引き継ぐ方は、[小学生版からの引き継ぎ](migration.md)へ進んでください。** すでに使っているアカウントを活用できます。新しい保存先が必要なときは、このページの手順5を参照します。

ここからは、**小学生版を使っておらず、新しく始める家庭向け**の手順です。保護者が自分のアカウントで操作し、本人が残したい内容を一緒に確認する使い方を案内します。保護者のスマホと、支払い方法を用意してください。パソコンがあると、コピーや接続の設定を大きな画面で進められます。

## 準備はこの6ステップ

1. **保護者用のGoogleアカウントを作成する。**
2. **ChatGPTの有料プラン（Plusプラン以上）を契約する。**
3. **スマホにChatGPTアプリをインストールして、Googleでログインする。**
4. **保護者用のGitHubアカウントを用意する。**
5. **本テンプレートを保護者用のGitHubにコピーし、Privateに設定する。**
6. **コピーしたリポジトリにChatGPTから接続する。**

ChatGPTは「一緒に文章を整理する相手」、GitHubは「できた記録をしまう場所」です。Googleアカウントは、ChatGPTへログインするときに使います。すでに用意できているものは、そのアカウントや契約を確認して次へ進んで構いません。

## 1. 保護者用のGoogleアカウントを作成する

まず、これから使うログイン先を一つ決めます。学校のアカウントではなく、保護者が管理できる個人用のアカウントを用意します。

1. スマホのSafariやChromeで、[Googleアカウントの作成ページ](https://accounts.google.com/signup)を開きます。
2. 利用目的を聞かれたら、保護者自身の個人用として作成します。
3. 画面に従って名前・生年月日などを入力し、メールアドレスとパスワードを設定します。
4. 確認を求められた場合は、電話番号や確認コードなどを画面に入力します。
5. 作成したメールアドレスを控えます。パスワードやアカウントの回復に必要な情報は、保護者が安全な場所で管理します。

すでに保護者用のGoogleアカウントがあれば、それを使えます。複数ある場合は、今回使うメールアドレスを決めておきましょう。詳しくは[Google公式の作成手順](https://support.google.com/accounts/answer/27441?hl=ja)を参照してください（確認日: 2026-10-02）。

**ここまでできればOK:** 保護者が、今回使うGoogleアカウントにログインできる。

## 2. ChatGPTの有料プラン（Plusプラン以上）を契約する

この手順では、保護者のChatGPTアカウントで**Plusプラン以上**を利用します。初めて契約する場合はPlusを選ぶ流れを説明します。すでに対象のプランを契約していれば、重ねて契約する必要はありません。

**Plusの予算の目安は月額約3,000円です。** 公式の基準価格は月額20米ドルで、約3,000円は1ドル150円として換算した目安です。日本円の実際の請求額は、地域別価格・税・支払い経路などによって変わります。上位プランは料金も異なるため、必ず契約画面の金額を確認してください。[OpenAI公式の料金案内](https://learn.chatgpt.com/docs/pricing)（確認日: 2026-10-02）

1. SafariやChromeで[ChatGPT](https://chatgpt.com/)を開きます。この段階ではアプリを入れなくて大丈夫です。
2. 初めてなら登録を選び、**Googleで続行（Continue with Google）**から手順1のアカウントを選びます。すでに登録済みなら、そのアカウントでログインします。
3. プロフィールや設定にある、プランの変更・アップグレードの項目を開き、**Plus**を選びます。表示名や位置は画面によって異なります。
4. 月額料金、次回の更新、支払い方法を保護者が確認し、契約を完了します。
5. 設定のアカウント・プランの表示で、契約したプランになっていることを確認します。

**ここまでできればOK:** 今回使うGoogleアカウントでChatGPTへログインし、Plus以上の契約を確認できる。

## 3. スマホにChatGPTアプリをインストールしてGoogleログインする

次に、いつものスマホから話しかけられるようにします。アプリには、手順2で契約したのと**同じアカウント**で入ります。

1. 保護者のスマホで[ChatGPTの公式ダウンロードページ](https://chatgpt.com/download/)を開き、iPhoneならApp Store、AndroidならGoogle Playの案内へ進みます。
2. アプリ名が**ChatGPT**、提供元が**OpenAI**であることを確認してインストールします。
3. アプリを開き、ログインを選びます。
4. **Googleで続行（Continue with Google）**を選び、手順2で契約したGoogleアカウントを選びます。
5. 設定でメールアドレスと契約プランを確認します。試しに「こんにちは」と送ってみましょう。

アプリで無料プランと表示されたら、まずメールアドレスが手順2と同じかを確認します。別のGoogleアカウントで入っていた場合はログアウトして入り直します。すぐにもう一度契約する必要はありません。

**ここまでできればOK:** スマホのChatGPTアプリで、契約したアカウントからメッセージを送れる。

## 4. 保護者用のGitHubアカウントを用意する

GitHub（ギットハブ）は、文章をファイルとして保存し、書き直した履歴も残せるサービスです。今回は保護者の個人アカウントを使います。**GitHubは無料のプランで始められます。**

1. SafariやChromeで[GitHubの登録ページ](https://github.com/signup)を開きます。すでに保護者のアカウントがあれば[ログイン](https://github.com/login)します。
2. **Continue with Google**が表示されていれば、手順1のGoogleアカウントを使えます。メールアドレスで登録する場合も、保護者が受信できるアドレスを使います。
3. ユーザー名など必要な項目を入力します。ユーザー名は保存先のURLにも使われます。本名や学校名を入れる必要はありません。
4. メールの確認など、画面に出る手続きを終えます。
5. 自分のプロフィールを開き、保護者のユーザー名を確認します。

[GitHub公式の登録手順](https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github)（確認日: 2026-10-02）。用語に迷ったら[GitHubの登録・ログインと保存先](github-basics.md)を参照してください。

**ここまでできればOK:** 保護者のGitHubにログインでき、ユーザー名が分かる。

## 5. 本テンプレートを保護者用のGitHubにコピーしてPrivateに設定する

GitHubでは、ファイルをまとめる保存場所を**リポジトリ**と呼びます。この教材をコピーすると、自分たちの記録用の保存場所ができます。**Private（プライベート）は「非公開」**の設定です。

1. 保護者のGitHubにログインした状態で、[本テンプレートのトップページ](https://github.com/risan-education/my-portfolio-teens)を開きます。
2. **Use this template（このテンプレートを使う）→ Create a new repository（新しいリポジトリを作る）**を選びます。
3. **Owner（所有者）**が手順4の保護者のユーザー名になっていることを確認します。
4. **Repository name（リポジトリ名）**に、例えば `my-learning-notes` と入力します。本名や学校名は不要です。
5. 公開範囲で**Private**を選びます。**Include all branches**は選ばずに進めます。
6. **Create repository from template**を押して、コピーを作ります。
7. コピー先のページで、所有者が保護者のユーザー名、公開範囲が**Private**になっていることを確かめます。
8. コピー先をお気に入りに登録し、そのページのURLを控えます。次の手順で使います。

URLは `https://github.com/保護者のユーザー名/my-learning-notes` のような形になります。**先頭が `risan-education` のページは配布元です。今後の記録には、保護者のユーザー名で始まるコピー先を使います。**

[GitHub公式のコピー手順](https://docs.github.com/ja/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template)（確認日: 2026-10-02）。ボタンが見つからなければ、ログイン済みか、ファイルの個別ページではなくトップページを開いているかを確認します。それでも見つからないときは[ZIPからコピーする補足](manual-editing.md)へ進めます。

**ここまでできればOK:** 保護者のGitHubにPrivateのコピーができ、そのURLを開ける。

## 6. コピーしたリポジトリにChatGPTから接続する

最後に、ChatGPTからコピー先を読めるようにします。GitHubにログインしただけでは、ChatGPTとの接続は完了していません。

### GitHubへの接続を設定する

1. 手順3のChatGPTアプリを開き、**プラグイン（Plugins）**や、設定内の**アプリ・接続**の項目を探します。名称や表示位置は版によって変わります。
2. **GitHub**を検索し、提供元と機能の説明を読んで、追加・接続を進めます。
3. GitHubのログイン画面が開いたら、手順4の保護者のアカウントでログインします。
4. 接続を許可する画面で、要求される権限を確認します。対象のリポジトリを選べる場合は、手順5で作ったコピー先だけを選びます。
5. 接続を完了し、ChatGPTに戻ります。

スマホに設定項目が見つからない場合は、SafariやChromeの[Web版ChatGPT](https://chatgpt.com/)に同じGoogleアカウントでログインし、プラグインの一覧から設定します。パソコンのWeb版でも構いません。設定後は、使いたいスマホの会話でも読み取りを確認してください。[OpenAI公式のプラグイン案内](https://learn.chatgpt.com/docs/plugins)（確認日: 2026-10-02）

### コピー先のURLを伝える

新しい会話を開き、次の文を送ります。最初のURLは、**手順5で控えたコピー先の実際のURL**に置き換えてください。

> 保存先は https://github.com/保護者のユーザー名/my-learning-notes です。GitHubの接続を使って、この保存先のAGENTS.mdとREADME.mdを読み、記録を始める準備をしてください。Privateであることと、対象ブランチを確認してください。読み取り・新規作成・追記・mainへの保存のどこまでできるか教えてください。準備だけでファイルは変更しないでください。

`AGENTS.md`はAIへの記録ルール、`README.md`は教材の案内です。`main`は、普段使う最新版の保存先の名前です。内容や用語をすべて覚える必要はありません。

ChatGPTが読めないと答えたら、GitHubへの接続先が保護者のアカウントか、コピーしたPrivateが対象に入っているかを確認します。読めないからといってPublic（公開）へ変更する必要はありません。

**ここまでできればOK:** コピー先の指示書を読めたことと、利用できる保存機能を確認できる。

接続の機能は環境や権限によって異なります。**Plus以上の契約や「接続済み」の表示だけでは、GitHubへ直接保存できると決まるわけではありません。** 書込対応の接続では作成・追記・コミットを頼めます。次の練習で実際に確かめ、保存機能がなければ[文章を自分で貼り付けて保存する方法](manual-editing.md)を使います。[確認済み・未確認の範囲](connection-environments.md)

## 準備のあと: 架空の記録を一件保存してみる

[接続確認の練習](connection-check.md)に沿って、コピー先の `practice/` に一件作ります。架空と明記した練習で、次の順に確かめます。

1. ChatGPTに「案を作って」と頼む。
2. 案を読んでから「この内容で保存してください」と頼む。
3. 保存先のリンクをGitHubで開き、**mainの本文と日付**を確認する。
4. 「追記の案を見せて」と頼み、内容の確認・保存・再表示も試す。

チャットに文章が出ただけでは、GitHubにはまだ保存されていません。別のブランチやPR（変更を確認して取り込むための提案）が必要な環境では、mainに反映する方法を先に説明してもらいます。

## 普段の使い方: メモを伝える → 案を確認する → 保存する

接続が確認できたら、本人が残したいメモを普段の言葉で伝えます。用紙・保存先・ファイル名・日付はChatGPTが案内します。活動日を書かなければ、話しかけた日の出来事として案に示します。別の日のことなら、その日付も伝えてください。

以下は**架空のメモ**です。実際に使うときは本人の経験に置き換えます。練習のまま保存する場合は `practice/` を使います。

> 昨日の部活で、先にゆっくり合わせたら入りやすかった。速いところはまだずれる。次も冒頭から試したい。

案を読んで、元のメモが残っていること、言っていない感想や成果が足されていないこと、保存先を確かめます。本人が直したいところを伝え、内容が決まったら保存します。

> この内容で保存してください。

保存後はGitHubのリンクを開いて確認します。新しい会話では、コピー先のURLと手順6の準備の文を送り直すと、保存先を確認できます。続きは[日常の記録](recording-guide.md)と[5つの会話例](../examples/prompts/README.md)へ。ときどき[バックアップ](backup-and-restore.md)も取っておきましょう。

## 補足: アカウントの使い方と別の始め方

### 本人が操作する場合の年齢条件

このページの手順は、保護者自身が操作するためのものです。本人が直接サービスを使う場合は、本人用アカウントと年齢・同意の条件を確認します。保護者のパスワードを本人と共有する方法にはしません。パスワードや認証コードは、ChatGPTへのメッセージに書かず、サービスの認証画面へ入力します。

ChatGPTは13歳未満向けではなく、18歳未満の利用には保護者の同意が必要と案内されています。最新の[公式の年齢条件](https://help.openai.com/en/articles/8313401-is-chatgpt-safe-for-all-ages)を確認してください。GitHubの条件は[登録ガイド](github-basics.md)を参照します。

### 契約の管理と、まず試したい場合

継続料金や解約方法は、契約したアカウントの設定で確認できます。アプリを削除するだけでは解約されません。Web契約とアプリストア契約では管理する場所が異なります。[解約の公式案内](https://help.openai.com/en/articles/7232927-canceling-your-chatgpt-subscription)

このページでは有料プランとスマホアプリを使う順序を案内しました。契約前に文章づくりだけ試したい場合は[最初の10分](first-10-minutes.md)、無料プランでの下書きと手動保存は[手動の補足](manual-editing.md)を使えます。端末のフォルダで編集したい場合は[デスクトップの補足](chatgpt-desktop.md)へ進みます。別のツールを使う人に、ChatGPTの契約を求めるものではありません。
