# はじめ方 — ChatGPTでポートフォリオを作る

- 作成日: 2026-09-26
- 更新日: 2026-09-26

このポートフォリオの第一の目的は、日々の記録と考えを残し、大学入試の総合型選抜、推薦入試に備えることです。探究学習の方法に慣れ、得意・苦手・好き・嫌いと性格の傾向を整理して、大学・学部選びにも役立てます。[はじめに](../README.md#はじめに)

[出願準備と出力の手順](admissions-guide.md)／[自己理解と大学・学部選び](self-understanding.md)も使えます。まずは以下の手順で、自分用の保存先と記録の方法を用意します。

入試対策の中心は[6段階の探究ガイド](inquiry-project-guide.md)です。高1頃に募集要項を確認したら、一つの大きな主テーマを選び、6段階全体の計画と最初の行動予定を作って始めます。日々のメモをその主テーマの調査・検証につなげます。

**ChatGPTに体験や考えを伝え、できた案を自分で確かめて、自分用のGitHubへ保存する**使い方を案内します。用紙の選択・文章の整理・ファイル名・日付の記入はChatGPTに頼めます。プログラミングやMarkdownの知識は不要です。

## 最初にすること

小学生版で記録していた人は、まず[小学生版からの引き継ぎ](migration.md)を開いてください。おすすめは、手順5で中高生版の新しいPrivateを作り、小学生用リポジトリの内容をコピーする方法です。既存のアカウント・契約は引き続き使い、未設定の項目だけを確認します。同じ保存先で続けたい場合の方法も、引き継ぎガイドで案内しています。

1. 年齢条件を確認し、ChatGPTのアカウントを用意する。
2. ChatGPT Plusの料金と利用条件を確認し、契約する場合は手続きする。
3. 公式ChatGPTアプリをインストールし、同じアカウントでログインする。
4. GitHubのアカウントを用意する。
5. ChatGPTと相談しながら、自分用のPrivateリポジトリを作り、接続する。
6. 指示書を読んでもらい、架空の記録で保存と追記を確認する。
7. 自分の記録を「案を作る → 確認する → 保存する」で続ける。

小学生版と同じ会話の流れを基本にしています。中高生版では本人が記録と利用範囲を決め、希望に応じて保護者が支援します。

## 1. ChatGPTのアカウントを用意する

[ChatGPT](https://chatgpt.com/)を開き、初めてなら登録、すでに使っていれば普段の方法でログインします。登録画面で利用できるメールアドレスやGoogle等のログイン方法を選びます。契約後も同じ方法・同じアカウントを使います。

本人が使う場合は年齢条件と保護者の同意を確認します。公式ヘルプでは13歳未満向けではなく、13〜18歳は保護者の同意を得るよう案内しています。13歳未満の場合、操作は成人が担当し、本人の希望する範囲のメモを扱います。[公式の年齢条件](https://help.openai.com/en/articles/8313401-is-chatgpt-safe-for-all-ages)（確認日: 2026-09-26）

学校のメールアドレスは必須ではありません。卒業後も利用できる連絡先を考え、パスワード・認証コードをChatGPTへのメッセージに書かないでください。

## 2. ChatGPT Plusの契約を確認する

小学生版に合わせ、継続利用のプラン例として **ChatGPT Plus** を案内します。公式の基準価格は **月額20米ドル・月払い** です。日本円の金額、税、支払い方法、更新日は契約画面で確認してください。固定の円換算額は案内しません。[Plusの公式説明](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)（確認日: 2026-09-26）

契約前に[接続と保存の違い](connection-check.md)も確認してください。**Plusの契約だけでGitHubへ直接書き込めるようになるわけではありません。** Freeで相談や下書きを試し、必要な機能と利用上限を確認してから選ぶこともできます。

### Webから契約する手順

1. [ChatGPT](https://chatgpt.com/)で、これから使うアカウントにログインする。
2. プロフィールメニューから **Upgrade Plan（プランをアップグレード）** を開き、**Get Plus** を選ぶ。
3. プラン名、料金、請求周期、支払い条件を確認する。未成年の契約・支払いは保護者と確認して進める。
4. 契約後、設定画面でアカウントとプランを確認する。すでに契約している人は、別アカウントで契約し直さない。

この使い方でAPIキーやAPIの従量課金契約は必要ありません。APIはPlusとは別のサービスです。

### 契約をやめる場合

契約した場所で解約します。Web契約はChatGPTの **Settings → Billing → Cancel plan**、アプリストア契約はAppleまたはGoogle Playのサブスクリプション管理で手続きします。アプリを削除するだけでは解約されません。[公式の解約手順](https://help.openai.com/en/articles/7232927-canceling-your-chatgpt-subscription)（確認日: 2026-09-26）

## 3. 公式ChatGPTアプリをインストールする

[OpenAIの公式ダウンロードページ](https://chatgpt.com/download/)を開き、端末に合うアプリを選びます。提供元がOpenAIであることを確認し、契約した同じChatGPTアカウントでログインします。アプリのインストールとPlus契約は別の操作です。

| 端末 | インストールと起動 |
| --- | --- |
| Windows | 公式ページのWindows用ダウンロードを選ぶ。案内されたインストーラーまたはMicrosoft Storeでインストールし、スタートメニューからChatGPTを開く |
| Mac | 公式ページのmacOS用ダウンロードを選ぶ。取得したファイルを開き、画面の指示に従ってインストールする。Applications（アプリケーション）からChatGPTを開く |
| iPhone・iPad | 公式ページのiOSリンクからApp Storeへ進み、OpenAIのChatGPTを入手して開く |
| Android | 公式ページのAndroidリンクからGoogle Playへ進み、OpenAIのChatGPTをインストールして開く |

端末の対応条件はダウンロード先で確認します。学校・共有端末でインストールできない場合は、[Web版ChatGPT](https://chatgpt.com/)から相談と下書きを始められます。スマホ・Web・パソコンでは使える接続や編集機能が異なることがあります。

公式資料: [アプリの開始手順](https://learn.chatgpt.com/docs/quickstart)／[Windows版](https://learn.chatgpt.com/docs/windows/windows-app)（確認日: 2026-09-26）。端末ごとの通し操作は本教材では未検証です。

## 4. GitHubのアカウントを用意する

GitHubは、ノートの文章をファイルとして保存し、変更履歴を残す場所です。保存場所のまとまりを「リポジトリ」と呼びます。

[GitHubの登録・ログインのしかた](github-basics.md)に沿って用意します。本人の利用は原則13歳以上で、居住国の条件も確認します。本人が条件を満たさない場合は保護者自身が操作します。保護者のログイン情報を本人と共有する方法にはしません。

## 5. ChatGPTと相談して、自分用の保存先を作る

ChatGPTで新しい会話を開き、次を送ります。この時点では配布元のURLを使います。

> このテンプレートを使って、自分のポートフォリオをChatGPTと作りたいです。GitHubの自分用Privateリポジトリへ複製し、読み取りと保存に必要な設定を順番に教えてください。今の環境で直接できることと、自分で操作することを分けてください。
>
> https://github.com/risan-education/my-portfolio-teens

使っている端末やGitHubのユーザー名を聞かれたら伝えます。パスワードや認証コードは、サービスの正規のログイン画面へ自分で入力します。

### 自分用のPrivateを作る

ChatGPTが複製機能を持つ環境では依頼できます。直接複製できない場合は、次のGitHub画面の操作をChatGPTに説明してもらいながら進めます。

1. GitHubにログインし、[配布元](https://github.com/risan-education/my-portfolio-teens)を開く。
2. **Use this template → Create a new repository** を選ぶ。
3. **Owner** を自分のアカウントにし、名前を付ける。例えば my-learning-notes。本名・学校名は不要。
4. **Private** を選び、**Include all branches** は選ばずに作成する。
5. 作成先の所有者と **Private** 表示を確認し、そのページをお気に入りに保存する。

[GitHubの公式手順](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template)（確認日: 2026-09-26）。ボタンがない場合はログイン状態と配布元のトップページを確認し、[手動の補足](manual-editing.md)へ進みます。

**ここから先の記録は、自分用のPrivateへ保存します。配布元のファイル・Issue・PRには書きません。** 配布元の組織に参加する必要はありません。

### GitHubをChatGPTへ接続する

1. ChatGPTの **Settings → Plugins** でGitHub、またはGitHubを含むプラグインを開く。必要ならプラグイン一覧で探してインストールする。
2. 案内されたGitHubの認可画面でログインする。提供元と要求されるアクセス範囲を読み、対象を選べる場合は自分用の保存先に限定する。
3. 作成したPrivateがアクセス対象に含まれていることを確認する。
4. ChatGPTの会話に、作成したページの実際のURLを貼る。

> 自分用の保存先は https://github.com/自分のユーザー名/自分のリポジトリ名 です。この保存先のAGENTS.mdとREADME.mdを読み、記録を始める準備をしてください。読み取り・新規作成・追記・mainへの保存のどこまでできるか確認してください。準備だけでファイルは変更しないでください。

URLの日本語部分は、自分が作成したページの実際の値に置き換えます。

公式資料: [プラグインの導入](https://learn.chatgpt.com/docs/plugins)／[GitHub接続](https://help.openai.com/en/articles/11145903-connecting-github-to-chatgpt)（確認日: 2026-09-26）

**公式に説明されている通常のGitHubアプリは読み取り専用です。** その場合、ChatGPTで下書きを作り、[手動保存](manual-editing.md)でGitHubへ反映します。編集・保存も会話で頼みたい場合は、[ChatGPTデスクトップの編集環境](chatgpt-desktop.md)を使う方法があります。別の書き込み対応ツールがある環境でも、機能名だけで判断せず次の練習で確認します。

## 6. 架空の記録で保存・追記を確かめる

[接続確認の練習](connection-check.md)に沿って、自分用Privateの examples/ に一件作ります。「案を作って」「この内容で保存してください」「追記の案を見せて」の順で、新規作成・追記・mainの再表示を確認します。読み取り専用の場合も、ChatGPTの案を自分で保存して同じ確認をします。

[AGENTS.md](../AGENTS.md)は共通のAI編集ルールです。置いてあるだけで毎回自動的に読み込まれるとは限りません。新しい会話では、自分用URLと「AGENTS.mdを読んで、記録を始める準備をしてください」を送り直します。読めない場合は指示書の本文を添付し、読取済みと扱える範囲を確認します。

## 7. 自分の経験を伝えて保存する

以下は書き方を示す**架空のメモ**です。自分の活動に置き換えて使います。練習のまま使う場合は examples/ へ保存します。

> 記録の案を作ってください。2026年9月26日、部活で先にゆっくり合わせたら入りやすかった。速いところはまだずれる。次も冒頭から試したいです。

ChatGPTが用紙と保存先を提案します。実記録なら例えば experiences/2026/260926-practice.md のような名前です。本文の日付は2026-09-26の形で残します。

元メモが残っていること、言っていない発言・成果が追加されていないこと、保存先を確認します。直したいところは普段の言葉で伝えてください。

> この内容で保存してください。

書き込みできる環境では、その範囲の保存を依頼します。GitHubでリンクを開き、**mainの本文・日付**を確認して完了です。GitHub接続ツールが直接コミットした場合は、追加でpushコマンドを実行する必要はありません。端末内だけの編集なら、GitHubへ反映する操作と確認が別に必要です。

保存できない環境では「GitHubへ貼り付けるファイル名と本文を出してください」と頼み、[手動保存](manual-editing.md)を使います。下書きが表示された段階では未保存です。

次からは[日常の記録](recording-guide.md)と[ChatGPTへの依頼例](ai-guide.md)を使えます。写真・動画は[所在メモ](../assets/README.md)にし、ときどき[バックアップ](backup-and-restore.md)を取ります。
