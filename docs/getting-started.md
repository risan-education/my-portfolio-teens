# はじめ方 — ChatGPTでポートフォリオを作る

- 作成日: 2026-09-26
- 更新日: 2026-09-27

このポートフォリオの第一の目的は、日々の記録と考えを残し、大学入試の総合型選抜、推薦入試に備えることです。探究学習の方法に慣れ、得意・苦手・好き・嫌いと性格の傾向を整理して、大学・学部選びにも役立てます。[はじめに](../README.md#はじめに)

**ChatGPTに体験や考えを伝え、できた案を自分で確かめて、自分用のGitHubへ保存する**使い方を案内します。用紙の選択・文章の整理・ファイル名・日付の記入・保存はChatGPTに頼めます。プログラミングやMarkdownの知識は不要です。

まだ何も試していない人は、先に[最初の10分](first-10-minutes.md)で、ChatGPTだけで一言メモを一件作ってみてください。

## 最初にすること

小学生版で記録していた人は、まず[小学生版からの引き継ぎ](migration.md)を開いてください。おすすめは、手順3で中高生版の新しいPrivateを作り、小学生用リポジトリの内容をコピーする方法です。既存のアカウントは引き続き使えます。

1. 年齢条件を確認し、ChatGPTのアカウントを用意する。
2. GitHubのアカウントを用意する。
3. 配布元から自分用のPrivateリポジトリを作る。
4. ChatGPTにGitHubを接続し、自分用Privateを対象にする。
5. 指示書を読んでもらい、架空の記録で保存と追記を確認する。
6. 自分の記録を「案を作る → 確認する → 保存する」で続ける。

有料プランとアプリのインストールは必須ではありません。必要になったときのために、最後の「任意」の節にまとめています。

## 1. ChatGPTのアカウントを用意する

[ChatGPT](https://chatgpt.com/)を開き、初めてなら登録、すでに使っていれば普段の方法でログインします。登録画面で利用できるメールアドレスやGoogle等のログイン方法を選びます。

本人が使う場合は年齢条件と保護者の同意を確認します。公式ヘルプでは13歳未満向けではなく、13〜18歳は保護者の同意を得るよう案内しています。13歳未満の場合、操作は成人が担当し、本人の希望する範囲のメモを扱います。[公式の年齢条件](https://help.openai.com/en/articles/8313401-is-chatgpt-safe-for-all-ages)（確認日: 2026-09-26）

学校のメールアドレスは必須ではありません。卒業後も利用できる連絡先を考え、パスワード・認証コードをChatGPTへのメッセージに書かないでください。

## 2. GitHubのアカウントを用意する

GitHubは、ノートの文章をファイルとして保存し、変更履歴を残す場所です。保存場所のまとまりを「リポジトリ」と呼びます。

[GitHubの登録・ログインのしかた](github-basics.md)に沿って用意します。本人の利用は原則13歳以上で、居住国の条件も確認します。本人が条件を満たさない場合は保護者自身が操作します。保護者のログイン情報を本人と共有する方法にはしません。ユーザー名に本名や学校名を入れる必要はありません。

## 3. 自分用のPrivateリポジトリを作る

1. GitHubにログインし、[配布元](https://github.com/risan-education/my-portfolio-teens)を開く。
2. **Use this template → Create a new repository** を選ぶ。
3. **Owner** を自分のアカウントにし、名前を付ける。例えば my-learning-notes。本名・学校名は不要。
4. **Private** を選び、**Include all branches** は選ばずに作成する。
5. 作成先の所有者と **Private** 表示を確認し、そのページをお気に入りに保存する。

[GitHubの公式手順](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template)（確認日: 2026-09-26）。ボタンがない場合はログイン状態と配布元のトップページを確認し、[手動の補足](manual-editing.md)のZIPから作る方法へ進みます。

分からないところは、ChatGPTに画面の説明をしてもらいながら進められます。

> このテンプレートから、GitHubに自分用のPrivateリポジトリを作りたいです。画面の操作を順番に教えてください。パスワードや認証コードは自分で入力します。
>
> https://github.com/risan-education/my-portfolio-teens

**ここから先の記録は、自分用のPrivateへ保存します。配布元のファイル・Issue・PRには書きません。** 配布元の組織に参加する必要はありません。

## 4. GitHubをChatGPTへ接続する

ChatGPTの書込対応のGitHub接続では、リポジトリの読み取りに加えて、ファイルの作成・追記・保存（コミット）を頼めます。[確認範囲と環境別の記録](connection-environments.md)を先に読み、mainへの直接保存、別ブランチ・PR、端末内保存のどれに対応するかを確認します。接続の設定場所や表示名はChatGPTの版によって変わるため、公式の説明で確かめてください。[GitHub接続の公式説明](https://help.openai.com/en/articles/11145903-connecting-github-to-chatgpt)

1. ChatGPTの設定（Settings）から、接続機能（コネクタ／アプリ等）を開き、GitHubを選ぶ。
2. 案内されたGitHubの認可画面でログインする。提供元と要求されるアクセス範囲を読み、対象を選べる場合は自分用の保存先だけに限定する。
3. 作成したPrivateがアクセス対象に含まれていることを確認する。
4. ChatGPTの会話に、作成したページの実際のURLを貼る。

> 自分用の保存先は https://github.com/自分のユーザー名/自分のリポジトリ名 です。この保存先のAGENTS.mdとREADME.mdを読み、記録を始める準備をしてください。読み取り・新規作成・追記・mainへの保存のどこまでできるか確認してください。準備だけでファイルは変更しないでください。

URLの日本語部分は、自分が作成したページの実際の値に置き換えます。

権限は環境やプランによって違うことがあります。ChatGPTの返事だけで判断せず、次の練習で実際に保存できることを確かめます。保存機能が使えない場合は、ChatGPTで下書きを作り、[自分で貼り付けて保存](manual-editing.md)します。端末のフォルダで編集したい場合は[ChatGPTデスクトップの補足](chatgpt-desktop.md)を使います。

## 5. 架空の記録で保存・追記を確かめる

[接続確認の練習](connection-check.md)に沿って、自分用Privateの practice/ に一件作ります。「案を作って」「この内容で保存してください」「追記の案を見せて」の順で、新規作成・追記・mainの再表示を確認します。

[AGENTS.md](../AGENTS.md)は共通のAI編集ルールです。置いてあるだけで毎回自動的に読み込まれるとは限りません。新しい会話では、自分用URLと「AGENTS.mdを読んで、記録を始める準備をしてください」を送り直します。読めない場合は指示書の本文を添付し、読取済みと扱える範囲を確認します。

## 6. 自分の経験を伝えて保存する

以下は書き方を示す**架空のメモ**です。自分の活動に置き換えて使います。練習のまま使う場合は practice/ へ保存します。

> 記録の案を作ってください。［活動した日］、部活で先にゆっくり合わせたら入りやすかった。速いところはまだずれる。次も冒頭から試したいです。

ChatGPTが用紙と保存先を提案します。実記録なら例えば experiences/2026/260926-practice.md のような名前です。本文の日付は2026-09-26の形で残します。

元メモが残っていること、言っていない発言・成果が追加されていないこと、保存先を確認します。直したいところは普段の言葉で伝えてください。

> この内容で保存してください。

自分の環境で確認した方法でChatGPTが保存し、保存先を報告します。標準は自分用Privateのmainです。別ブランチ・PRが必要なら事前に説明を受け、その範囲で進めます。main反映前は未反映です。GitHubでリンクを開き、**mainの本文・日付**を確認して完了です。GitHub接続ツールが直接コミットした場合は、追加でpushコマンドを実行する必要はありません。端末内だけの編集なら、GitHubへ反映する操作と確認が別に必要です。

保存できない環境では「GitHubへ貼り付けるファイル名と本文を出してください」と頼み、[手動保存](manual-editing.md)を使います。下書きが表示された段階では未保存です。

次からは[日常の記録](recording-guide.md)と[ChatGPTへの依頼例](ai-guide.md)を使えます。写真・動画は[所在メモ](../assets/README.md)にし、ときどき[バックアップ](backup-and-restore.md)を取ります。

## 任意: 有料プランとアプリ

この教材は無料プランでの下書きと手動保存でも使えます。無料プランでのGitHubへの直接保存を全環境で検証した意味ではありません。利用上限や機能が足りないと感じたら、有料プランを検討します。

- **ChatGPT Plus**: 公式の基準価格は **月額20米ドル・月払い** です。日本円の金額、税、支払い方法、更新日は契約画面で確認してください。[Plusの公式説明](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)（確認日: 2026-09-26）。未成年の契約・支払いは保護者と確認して進めます。解約はWeb契約なら **Settings → Billing → Cancel plan**、アプリストア契約はAppleまたはGoogle Playのサブスクリプション管理で行います。アプリを削除するだけでは解約されません。[公式の解約手順](https://help.openai.com/en/articles/7232927-canceling-your-chatgpt-subscription)（確認日: 2026-09-26）
- **公式アプリ**: [OpenAIの公式ダウンロードページ](https://chatgpt.com/download/)から、端末に合うアプリを入れられます。提供元がOpenAIであることを確認し、同じアカウントでログインします。スマホ・Web・パソコンで使える機能が異なることがあります。学校・共有端末では[Web版](https://chatgpt.com/)から始められます。[アプリの開始手順](https://learn.chatgpt.com/docs/quickstart)（確認日: 2026-09-26）
- この使い方でAPIキーやAPIの従量課金契約は必要ありません。APIはChatGPTのプランとは別のサービスです。
