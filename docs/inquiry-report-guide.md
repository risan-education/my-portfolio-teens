# 探究の記録をレポートにまとめる

- 作成日: 2026-09-27
- 更新日: 2026-09-27

個々の探究ノートから、問い・方法・結果・考察をつなぎます。[探究レポートの用紙](../templates/inquiry-report.md)を使い、derived/YYMMDD-inquiry-report.md に案を作れます。主テーマの入口はそのレポートへリンクします。本人の分析と論述をAIの代筆へ置き換えません。

## 用途と条件を先に決める

自分用の振り返りか、授業・コンテスト・出願等の提出用かを確認します。提出用は[提出条件確認](../templates/submission-check.md)で今回の作業の可否を確認します。禁止・未確認なら、その作業を進めません。私的な整理という名前に変えて提出用の作業を迂回しません。正式なEEには[専用ガイド](extended-essay-guide.md)と学校の指導を使います。

## 原記録からつなぐ

1. 本人が使う記録・資料と対象期間を選ぶ。
2. 問いに答える主張と、その根拠を[根拠付き要約](../templates/evidence-summary.md)へ並べる。未確認・反対例・限界も残す。
3. 問い、先行資料、方法、結果、考察、結論を本人の言葉でつなぐ。文献研究なら比較した箇所、数学なら前提・導出、制作なら変更の理由を示す。
4. 方法を選んだ理由、別の説明、言える範囲を確認する。人数や反応があっても因果関係や一般化が証明されたことにはしない。
5. 引用と要約を分け、読んだ資料の著者・題名・ページやURLを残す。存在・本文を確認していない参考文献は載せない。
6. 提出時は根拠表・Privateリンク・内部指示を除いた本文を別ファイルへ作り、指定形式と字数、引用・AI表示条件を確認する。

自分用のレポートをそのまま提出できるとは限りません。用途が変わった時点でAI利用条件を確認します。原記録の日付や当時の考えは変えず、今回の解釈はレポートへ記します。

## AIへの依頼例

> 今回は［用途］です。提出用途なら、先に今回の作業のAI利用条件を確認してください。許可された範囲で、［選んだ記録］から主張と根拠の対応を示し、私が分析・説明するための不足情報を質問してください。結果を補わず、実施と計画を分けてください。

[架空のレポート例](../examples/inquiry-report.md)から[面接の継続例](../examples/interview-session.md)へ進めます。両方とも教材であり、本人の実績や提出用の模範解答ではありません。
