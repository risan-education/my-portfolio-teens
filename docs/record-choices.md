# 記録の利用範囲・利用停止・削除

- 作成日: 2026-09-26
- 更新日: 2026-09-26

本人は、以前使ってよいとした記録でも希望を変えられます。理由を書く必要はありません。原記録を保持するルールより、本人の利用停止・削除の希望を優先します。

ChatGPTに「この記録の利用を止めたい。関連する要約やコピーへの影響を確認する案を見せて」と頼めます。最初は対象と影響の確認までとし、本人が指定した対応範囲を保存・削除の操作と区別します。

## 範囲を見直す

[見直し用紙](../templates/record-use-review.md)へ、対象と希望、本人の確認日を記入します。内容そのものを再掲する必要はありません。自分用、支援者用、AI用、外部提出用の範囲を別々に決めます。

利用停止の場合は、関連する要約・AI向け自己紹介・問いの一覧・発表材料も検索して再利用を止めます。AIへ渡さない情報は接続対象の外へ移し、必要に応じて接続を解除します。

## 削除の対象は一つではない

| 対象 | 確認すること |
| --- | --- |
| 現在のファイル | 本文の削除・リンクの整理 |
| Git履歴 | 現在のファイルを消しても過去の版が残りうる |
| コピー・バックアップ | 別端末や控え、共有先にもコピーがないか |
| 外部原本 | 写真・動画・PDFとその共有設定 |
| AI側・提出先 | 会話や添付、提出済み資料の扱いを各サービス・相手の手順で確認 |
| 派生文書 | 要約・自己紹介・活動報告での再利用停止と削除 |

対象と影響を本人と確認してから対応し、完了した範囲と残る範囲を記録します。「ファイルを削除した」ことを「すべて消えた」と案内しません。履歴書き換えや強制pushを自動で行いません。

バックアップから戻す場合も、利用停止・削除の希望を確認してから対象を選びます。停止中の原記録を要約で再登場させません。
