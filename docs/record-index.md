# 必要な記録を探し、AIへ渡す範囲を選ぶ

- 作成日: 2026-09-27
- 更新日: 2026-09-27

年・テーマのフォルダとquestions.mdだけで探せるうちは、索引は不要です。記録が増えたら[索引用紙](../templates/record-index.md)で profile/YYMMDD-record-index.md などに入口を作れます。本文の複製や活動実績にはしません。

## 読む範囲を決める

1. 今回の目的、本人が許可するフォルダ・期間・ファイルを先に決める。
2. 許可された原記録のタイトル・日付・テーマ・リンクを一覧にする。本文を読んでよい範囲も区別する。
3. 要約・コピーは原記録との対応を示し、重複して活動を数えない。
4. 今回使うものを本人が選ぶ。索引の作成・更新も保存対象に含めて依頼されたときだけ保存する。

templates/、examples/、practice/、docs/（docs/prompt/を含む）、案内文、旧指示書、移行確認メモ、索引自身は実績検索から除外します。legacy/ は移行確認メモと本文の種別で判断し、フォルダ名だけで実記録と決めません。

## AIへの依頼例

> ［許可した範囲］から、［相談目的］に使う記録を私が選べる索引の案を作ってください。原記録・要約・コピーを区別し、本人の実記録以外と利用停止中の記録は除外してください。読んだ範囲と読めなかった範囲を示し、まだ保存しないでください。

> この記録と、確認した索引の更新を一緒に保存してください。本文は索引へ重複転記せず、原記録へリンクしてください。

## 更新・利用停止

索引には確認日と本人が許可した利用範囲を残します。移行・訂正・利用停止があったら、関連する索引・要約・自己紹介を見直します。停止した本文を索引へ再掲しません。削除後の控えから戻す場合も、現在の利用範囲を確認します。

索引はアクセス制御ではありません。AIへ渡さないファイルは接続対象の外へ置きます。記録にアクセスできない場合は「記録なし」と断定せず、「今回確認できない」と伝えます。[AIへ持ち運ぶ](portability.md)
