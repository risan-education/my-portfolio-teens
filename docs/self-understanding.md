# 自己理解を出力し、大学・学部選びに使う

- 作成日: 2026-09-26
- 更新日: 2026-09-27

ChatGPTとの会話と[自己理解シート](../templates/self-understanding.md)を使い、**得意なこと・苦手なこと・好きなこと・嫌いなこと・性格の傾向**を、根拠と本人の確認付きで出力します。日々の記録→本人への質問→確認→自己理解メモ→大学・学部の比較、という仕組みです。

得意と好きは分けます。「できるが疲れる」「まだ苦手だが好き」も残します。苦手や嫌いは、本人がそう感じる場面・理由・改善したいかを確認します。過去の一回の失敗を、今後も変わらない能力や性格にしません。

## 1. 使う記録と範囲を決める

本人が選んだ日常・授業・部活・探究などの記録を使います。できれば異なる時期や場面も含めますが、最低件数は設けません。足りなければ「まだ判断できない」と残します。用紙・架空例・利用停止した記録は除外します。

小学生時代の記録は当時の情報です。保護者の観察と本人の言葉を分け、今もそうかを本人に確かめます。

## 2. 得意・苦手・好き・嫌いを整理する

各項目は、本人の言葉、行動の根拠、うまくいく条件、違う例、現在の確認に分けて書きます。AIが見つけた候補は「AIの仮説・本人未確認」と表示し、本人の発言に変えません。

例えば発表について、資料作りは好きでも、大勢の前で急に話すことは苦手かもしれません。練習できる少人数の授業ならどうか、と学ぶ環境を考える材料にします。「発表が苦手だからこの学部は無理」とはしません。

## 3. Big Fiveを補助の観点にする（任意）

Big Fiveは、性格の傾向を五つの側面で捉える枠組みです。BFI-2はその測定に使われる自己報告式の質問紙で、日本語版の研究もあります。本教材では、**五つの観点で本人と振り返る文章**を標準の出力にします。以下は本教材独自の会話の問いで、正式な検査項目ではありません。[開発者のBFI-2解説](https://www.ocf.berkeley.edu/~johnlab/bfi.html)／[日本語版の検証研究](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2022.924351/full)

| 観点 | 本人と確かめる例 |
| --- | --- |
| 開放性（新しい考えへの関心） | 新しいテーマを試すときと、慣れた方法を深めるとき、それぞれどう感じるか |
| 誠実性（段取り・継続） | 予定を立てると進めやすいか。どんな助けや区切りがあると続けやすいか |
| 外向性（人との関わり・活発さ） | 一人・少人数・大勢で、取り組みやすさや疲れ方にどんな違いがあるか |
| 協調性（協力・他者への配慮） | 意見が違う場面でどう相談するか。協力しやすかった条件は何か |
| 否定的情動性（心配・ストレスへの反応） | 不安や負担を感じやすい場面と、落ち着いて取り組める条件は何か。答えたくなければ省く |

記録から得点・偏差値・上位何％を作らず、「この場面ではこうだった」「本人はこう考えている」「別の場面は未確認」と出力します。高低に優劣を付けず、診断名や大学への適性判定に変換しません。五つすべてに答える必要はありません。

質問紙の結果を使いたい場合は、対象年齢・言語・利用条件・採点方法が確認できる尺度を別途選びます。本人が回答して得た結果だけを任意で追記し、尺度名・版・実施日・対象集団・解釈の限界を残します。BFI-2の質問文と採点法を、本教材のCC BY 4.0対象の素材として転載していません。開発者は利用条件を定めています。成人用の基準値を中高生へ無条件に当てはめません。[BFI-2の利用・採点に関する説明](https://www.ocf.berkeley.edu/~johnlab/bfi.html)

## 4. ChatGPTに出力を頼む

> AGENTS.mdとdocs/self-understanding.mdを読み、［本人が選んだ期間・記録］から自己理解シートの案を作ってください。得意・苦手・好き・嫌いを分け、各項目に原記録、場面、反対の例、確認したい質問を付けてください。私の直接の言葉とAIの仮説を区別してください。今も当てはまるか、一度に二問程度ずつ私に確認してください。
>
> Big Fiveの観点も［使う／今回は使わない］。使う場合は、五つの観点で具体的な経験を振り返る文章にし、点数や性格の診断を作らないでください。答えたくない項目は省いてください。確認後にtemplates/self-understanding.mdで出力してください。

会話の途中は本人未確認の案です。確認後は `derived/YYMMDD-self-understanding.md` へ保存を依頼できます。確認日と使ってよい範囲を記し、後から考えが変わったら別の日付のメモで見直します。[保存の手順](recording-guide.md)

## 5. 大学・学部を比較する

[探究テーマの選び方](choosing-inquiry-theme.md)では、確認した「好き」や日々の記録から問いを作り、問いに合う学部を探す方法を説明しています。[架空の会話例](../examples/theme-selection.md)では、記録の読取、AIの候補、本人の回答、予備調査と大学探しを順に示します。

本人が希望する学び方や問いを、大学の公式カリキュラム・授業方法・研究分野・支援環境と照合します。[進路探索用紙](../templates/career-exploration.md)で、**関心との接点／気になる負担／確かめたいこと／公式根拠**を並べます。出願資格・費用・場所なども別に確認します。

> 確認済みの自己理解メモを使って、［大学・学部の候補］を公式情報で比較してください。好きなテーマ、取り組みやすい学習環境、苦手な場面への支援、カリキュラム、出願条件を分け、資料のURL・確認日を付けてください。Big Fiveから学部の適性点や順位は作らず、接点と懸念、オープンキャンパスで確かめる質問を示してください。まだ候補がなければ、私の関心から調べる分野の案を出してください。

性格メモは進路を選ぶ本人のための資料です。出願用の本文へ自動で添付せず、使いたい経験だけを本人が選びます。自分が不得意と感じる内容も、先生などに共有する範囲を決められます。
