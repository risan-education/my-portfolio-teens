# 発表・進路・面接への活用

- 作成日: 2026-09-26
- 更新日: 2026-09-27

本人が選んだ経験を、必要になった用途に合わせてまとめます。記録を始めるときに志望校や職業を決める必要はありません。

本教材の第一の目的である総合型選抜・推薦入試対策は、[出願準備と出力の手順](admissions-guide.md)を使います。募集要項の確認→探究計画→実践→振り返り→条件に沿う出力まで案内しています。

ChatGPTに「私が選んだ記録だけで、［用途］の材料を根拠付きで整理して」と頼めます。原記録の範囲と用途を指定し、案を本人が確認してから保存します。[具体的な依頼例](ai-guide.md)

## 元記録から材料を選ぶ

1. 今回の目的と読む相手を決める。本人が利用を認めた原記録だけを選ぶ。
2. [根拠付き要約](../templates/evidence-summary.md)に、自分の役割、取り組んだ理由、予想と検証、工夫・変更、成果と限界、次の問いを根拠リンク付きで整理する。
3. 本人が現在の考えを確認する。小学生時代の興味を今の志望と決めつけず、経験した時期を変えない。
4. 元記録と別ファイルに保存する。

面接練習では「具体的に何をしたか」「なぜ変えたか」「その根拠はどこか」を元記録に戻って確かめます。集団の成果を自分一人の実績にせず、受賞や数値を補いません。手順と用紙は[面接・口頭試問の準備](interview-guide.md)と[面接準備シート](../templates/interview-prep.md)にあります。

## 進路が気になったら

[自己理解](self-understanding.md)で得意・苦手・好き・嫌いと性格の傾向を本人と確認し、[進路探索](../templates/career-exploration.md)で学びたいことや候補を比べます。Big Fiveの観点も任意で使えますが、過去の記録から性格の得点・能力・適性・合格可能性を判定しません。「未定」「今は決めない」も選べます。

## 提出物にする前に

[提出条件確認](../templates/submission-check.md)で提出先・年度・設問・対象期間・形式・AI利用条件の公式出典と確認日を残します。学校ごとの条件をこの教材に固定しません。条件が不明なら確認までとし、AIによる提出用本文の作成を進めません。

本人が内容と共有範囲を確認してから、必要な部分だけを用途に合わせて使います。この教材は送信・提出を自動で行いません。

AIへの自己紹介なら[AI向け用紙](../templates/ai-context.md)に今回の目的と本人が確認した現在の情報を先に書き、必要な要約・原記録だけを添えます。長く使う自己紹介は[現在版](../templates/ai-profile.md)にまとめます。

## 大学・就職活動・社会人になってから

同じ記録形式で続けられます。大学版の準備が整ったら[新しいPrivateへの移行](migration-to-univ.md)を選べます。同じ保存先の継続も可能です。大学生活の記録、就職活動のガクチカ、社会人になってからのAIへの説明は[高校卒業後も続ける](after-high-school.md)と[AIへ持ち運ぶ](portability.md)を使います。
