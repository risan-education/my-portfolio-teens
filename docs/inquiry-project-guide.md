# 6段階の探究ガイド — 高1から一つの主テーマを育てる

- 作成日: 2026-09-26
- 更新日: 2026-09-27

**本教材の総合型選抜・推薦入試対策では、6段階の探究を必須の取り組みとして位置付けます。高校1年生頃に大学・学部の募集要項を確認したら、一つの大きな主テーマを選び、このガイドに沿って継続的な探究を始めます。** 日々のメモを蓄積するだけでなく、問いを深め、検証し、他者へ伝え、協力して改善する経験をつなぎます。

これは本教材の学習方針です。実際の出願資格や選考方法は、受験する年度・学部・方式の募集要項で確認します。段階構成は[参考記事](https://risan.jpn.org/?p=14459)をもとにしています。文部科学省が示す課題の設定・情報の収集・整理分析・まとめ表現の過程も参考に、繰り返し深める形で使います。[文部科学省の探究の説明](https://www.mext.go.jp/content/1421972_2.pdf)（参照確認日: 2026-09-26）

## 募集要項を読んだら、探究を開始する

テーマ選びは[二つの方法](choosing-inquiry-theme.md)から始められます。大学・学部が未定なら、好きな問いや日々の記録から主テーマを選び、関連する学部と募集要項を並行して調べます。志望先の確定を待つ必要はありません。研究論文へ深めたいときは[EEを参考にするガイド](extended-essay-guide.md)と[架空例15件](../examples/extended-essay/README.md)も使えます。

1. [出願準備ガイド](admissions-guide.md)で、候補の大学・学部の募集要項、アドミッション・ポリシー、学べる内容を調べる。高1時点の要項は将来の受験年度と区別し、参考にした年度を残す。
2. [自己理解](self-understanding.md)と日々の記録から、自分が継続して考えたい主テーマを一つ選ぶ。大学で学びたい分野との接点を、本人の言葉で書く。
3. 主テーマの中から、今学期に確かめられる具体的な問いを一つ決める。6段階全体の見通しと、最初の調査・観察・制作の予定を立てる。
4. [6段階のプロジェクト用紙](../templates/inquiry-project.md)で projects/<theme>/README.md を作り、[出願準備計画](../templates/admissions-plan.md)と相互にリンクする。
5. 最初の小さな調査に着手し、結果と考えを残す。月ごとの確認日と学期末の振り返りを予定に入れる。

開始時に決めるのは、**主テーマ・本人が選んだ理由・最初の問い・6段階の見通し・最初の行動予定・見直す日**です。協力先など未定の事項には、確認する相手や時期を書きます。計画しただけでは「実施済み」にしません。

学校の「総合的な探究の時間」で進めるテーマを、そのまま主テーマにできます。すでに探究している場合は既存記録を整理して6段階の入口を作り、次の課題へ進みます。高2・高3から始める場合も、過去の活動日を作らず、残りの期間でできる範囲を計画します。

## 大きなテーマと、最初の問いを分ける

テーマが思い浮かばなければ、[架空の探究テーマ18例](../examples/inquiry-themes/README.md)を読んでみてください。文学・社会・理工・農・保健・芸術など、分野による方法の違いを比較できます。気になった三案を比べ、本人の疑問、使える資料、最初の一週間の行動を相談して一つ選びます。[公式の実践事例を探す方法](inquiry-theme-sources.md)も参考にできます。

大きなテーマは、複数の調査や試作をつなぐ軸です。一度に社会全体の問題を解決しようとせず、対象・場所・期間を絞って始めます。

| 大きな主テーマ（例） | 最初に確かめる問い（例） | 学部の学びとの接点として調べること |
| --- | --- | --- |
| 誰もが使いやすい情報の伝え方 | 図書コーナーの返却案内を、初めて使う人に分かりやすくするには | 情報デザイン、認知、教育などの授業・研究内容 |
| 身近な食品ロスを減らす | 家庭で食材が余る場面を記録すると、何が分かるか | 食・環境・経済などの授業・研究内容 |
| 地域の移動のしやすさ | 公開された交通情報と現地の案内には、どんな違いがあるか | 地理、都市計画、情報などの授業・研究内容 |

例はテーマ選びの案で、特定学部の合格条件や適性判定ではありません。本人の関心と公式の授業内容を確認して選びます。テーマを変える場合も、変更の理由と以前の記録を残します。

## 一つの主テーマを6段階で進める

| 段階 | 主テーマで行うこと | 残す根拠と次へのつながり |
| --- | --- | --- |
| 1. 興味を見つける | なぜ気になるか、自分の経験と大学で学びたい分野を結ぶ | 元メモ・本人の理由。主テーマを選ぶ |
| 2. 課題を決める | 対象や場面を絞り、確かめたい問いを一文にする | 現状を示す資料・観察、対象と範囲、問いを選んだ理由 |
| 3. 仮説を立てる | 先行資料を読み、自分の予想と確かめ方を考える | 出典・仮説・方法・比較条件・予想と異なる場合の見方 |
| 4. 現場で確かめる | 観察・聞き取り・調査・実験等を実施し、結果を分析する | 実施日・データ・本人の役割・結果と限界。必要なら2・3へ戻る |
| 5. 形にして発信する | 結果を作品・提案・発表等にし、相手の反応を受けて改善する | 初版と修正版、伝えた相手、実際の反応、変更理由 |
| 6. 人を巻き込む | 先生・友人・地域の人などと協力し、改善や次の検証へつなげる | 依頼と同意、役割分担、自分の貢献、協力で変わったことと根拠 |

六つすべてを主テーマの計画に入れ、発信と協働まで取り組むことを目指します。発信は授業内の発表、協働は先生や友人との改善でも構いません。ネット公開、大規模な団体設立、受賞を必要条件にはしません。

## 高1から出願までの見通し

次は本教材の計画例で、大学が指定した時期ではありません。学業・学校の探究計画と合わせて調整します。

| 時期の目安 | 主テーマで進めること | 確認するもの |
| --- | --- | --- |
| 高1・募集要項を調べた直後 | 主テーマを一つ選び、段階1〜3を計画。最初の調査を始める | プロジェクトの入口、最初の問い・行動予定、6段階の見通し |
| 高1の間 | 段階4で小さく確かめ、2・3へ戻って問いや方法を修正する | 元データ、予想との差、次に試す方法 |
| 高2 | 調査・検証を重ね、段階5の発信と段階6の協働を進める | 作品・発表、反応と改善、役割分担、変化の根拠 |
| 高3・出願準備 | 未解決の問いや限界も含めて整理し、大学で続けたい学びを考える | 当該年度の要項、設問と根拠の対応、本人の現在の考え |

日々の詳細は活動記録・探究ノート・作品カードで残し、入口からリンクします。探究ノートは主テーマの詳細記録として使います。日常のすべてのメモを主テーマに結び付けたり、毎回六つの欄を書き直したりする必要はありません。

## 月ごと・学期末に見直す

月ごとの確認では、今いる段階、実際に行ったこと、根拠、困っていること、次の一歩を更新します。学期末には六つの段階全体を見て、まだ着手できていない段階への予定を見直します。

状態は「これから・途中・ひと区切り・保留・お休み」。状態を変えた日と理由を履歴に残し、「ひと区切り」は実施記録を根拠に判断します。主テーマで未実施の段階は消さず、保留の理由と再検討する時期を記します。休む理由は「本人の希望」でも構いません。

主テーマは6段階で続けますが、実施できなかった活動を完了扱いにしません。課題・仮説の変更、順序の前後、繰り返し、休止があっても、そこまでの経験と次の計画を正確に残します。段階番号や完了数で能力・合格可能性を判定しません。

[6段階の架空の継続例](../examples/inquiry-project/README.md)は、一回の探究の流れを示しています。主テーマではその結果から次の問いへ進めます。[途中参加の例](../examples/entry-from-stage4.md)は短い補助活動の例で、入試対策の主テーマ全体の完了例ではありません。

## 人に聞く・伝える

相手・内容・方法・必要な同意を計画欄で確認します。訪問場所のルールや安全を確かめ、必要なら支援者と相談します。相手は役割だけでも記録でき、連絡先や氏名は不要です。

計画と実際の依頼・発信日を分け、協力を頼みたい相手を「協力者」として先に書きません。[共有のガイド](privacy.md)

## ChatGPTへの開始依頼

> 高校1年生です。総合型選抜・推薦入試の準備として、［大学・学部等］の募集要項と学びの内容を確認しました。資料は［URL・年度・確認メモ］です。私の関心は［関心や元記録］です。
>
> docs/inquiry-project-guide.mdに従って、一つの大きな主テーマで探究を始めたいです。まずテーマ候補を相談し、私が選んだ一つについて、templates/inquiry-project.mdで6段階全体の見通しを作ってください。最初の具体的な問い、最初の調査方法と予定、月ごとの確認日、学期末の振り返りを入れてください。出願準備計画と相互にリンクし、計画と実施は分けてください。

本人が案を確認したら保存を頼みます。書込機能がない場合は[手動保存](manual-editing.md)を使います。

## 続ける・まとめるときの依頼

> 主テーマの入口と今回の記録を読み、6段階の進み具合を更新する案を作ってください。未着手や保留の段階も残し、次にできることを二つ提案してください。私が選ぶまではAI案と記してください。

> 結果が予想と違いました。元の仮説を残して、段階2・3で見直す候補を示してください。

> 学期末の振り返りをしてください。一つの主テーマで何を深めたか、私の役割、発信への反応、協働で変わったこと、限界と次の問いを原記録付きで整理してください。未実施は未実施のまま残してください。

出願に向けてまとめるときは[出願ガイド](admissions-guide.md)へ戻り、[提出条件確認](../templates/submission-check.md)で当該年度の条件とAI利用範囲を確認します。

## 分野による読み替え

6段階は共通ですが、課題は社会の困りごとだけでなく、まだ分からない問いも含みます。「現場で確かめる」には観察・実験・文献や原資料の分析・計算・証明の検討を含めます。発信は授業内の報告、協働は先生や友人の批評を受けた改善でも構いません。段階の番号を能力・合否に対応させません。未実施は保留・お休みとして理由と再検討時期を残します。

結果と考察を文章にするときは[レポートのまとめ方](inquiry-report-guide.md)を使います。
