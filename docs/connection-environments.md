# 接続・保存の確認記録

- 作成日: 2026-09-27
- 更新日: 2026-09-27

教材を無料で利用できることと、あるプラン・画面でGitHubへ直接保存できることは別です。ChatGPTの書込対応の接続では作成・追記・コミットを頼めますが、接続済みの表示だけでmainへ直接保存できるとは判断しません。

## 現在分かっていること

| 根拠 | 確認内容 | 未確認の範囲 |
| --- | --- | --- |
| 配布元の2026-09-27の実利用報告 | ChatGPTからGitHubを編集可能との報告を受け、書込対応の案内に改訂した | 端末・画面・接続名・プラン・版の詳細、再現手順と保存結果を揃えた実機検証記録 |
| 教材の検査 | ローカルの保存・再読込、文書検査、架空の移行・復元 | 読者のPrivateへの実際の保存、スマホや無料プランでの直接保存 |
| OpenAI公式資料 | プラン・提供環境等による機能差、ローカルとクラウド、Codex cloudの変更確認・PR作成の流れ | 全環境で同じ接続名・同じmain保存方法が提供されるという保証 |

配布元の報告を否定したり、読み取り専用と一律に扱ったりはしません。一方で、詳細不明の実利用報告を、全利用者が同じ手順で保存できる検証結果へ拡張しません。

公式資料（2026-09-27確認）: [ChatGPTの機能と環境の違い](https://learn.chatgpt.com/docs/use-chatgpt)、[Codex cloudの手順](https://learn.chatgpt.com/docs/cloud)。製品・画面・権限が異なるので、クラウドでのPR作成を通常の会話からの直接コミットと同一視しません。

## 再現確認を残す項目

新しく確認するときは[接続練習](connection-check.md)を本人用Privateの架空データだけで行います。結果は自分用Privateまたは非公開の端末に残します。公開用の報告には認証情報・Private URL・実記録を含めません。

| 項目 | 記入すること |
| --- | --- |
| 環境 | 確認日、端末・OS、Web／アプリ／ローカル／クラウド、版、プラン、接続名・提供元 |
| 準備 | 自分用Private・ブランチ・指示書の読取、使える書込操作 |
| 新規作成 | 案だけでは作成しないこと、保存依頼後のファイル名・保存結果 |
| 追記 | 追記前の再読込、元メモと作成日の保持、追記の結果 |
| 反映方法 | mainへ直接／別ブランチ・PR／端末内のみ／手動。コミットがあれば識別子 |
| 再読込 | GitHubでmainを開いた結果、新しい会話での読取結果 |
| 例外 | 書込機能なし、権限・保護で拒否、未確認の端末・プラン |

一つの環境で成功しても別の環境を確認済みにはしません。結果が不足する欄は未確認とし、契約や権限拡張を解決策として自動で勧めません。
