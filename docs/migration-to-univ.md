# 中高生版から大学版へ引き継ぐ

- 作成日: 2026-09-27
- 更新日: 2026-09-27

大学版 `my-portfolio-univ` は仮の要件定義段階です。ここでは、中高生版側で準備できることと、大学版の配布準備が整った後の移行手順を分けます。実際の大学版への移行は未検証です。

## 今できる準備

今のPrivateで記録を続け、本人が残したい記録・継続する問い・AIへ渡す範囲を見直します。[共通仕様](portfolio-format.md)を大学版の要件定義へ引き継ぎます。大学版の用紙に合わせて過去の記録を書き直す必要はありません。

学校のメール、写真の保存先、保護者の共有権限も卒業前に確認します。[バックアップ](backup-and-restore.md)は本文と外部原本を別々に開いて確認します。

## 大学版の配布準備が整ったら

1. 大学版のREADME・指示書・共通仕様への対応を読み、本人用の新しいPrivateを作る。公開テンプレートと本人用Privateを区別し、実際のURL・所有者・ブランチ・Privateを確認する。
2. [引き継ぎ確認メモ](migration-checklist.md)で、許可した原記録、派生文書、参照用教材、移さないものを選ぶ。リンク先でも未許可の本文は読まない。
3. 未使用の legacy/teens-01/ に、元のリポジトリからの相対配置を保ってコピーする。同名があればまとまり全体を teens-02 等にする。
4. 元と先の本文・日付・名前を比較する。使える環境では[移行検査](migration-verification.md)で許可したファイルだけの内容一致を確かめる。コピー日を原記録の更新日にしない。
5. 相対リンク、旧URL、ルート基準のリンク、外部原本の権限を確認する。未解決の参照は確認メモへ残し、原文の修正や対象外の読取で解消しない。
6. 新しいREADME・questions.mdから、継続したい旧記録へリンクする。現在の関心と大学で始めたいことを本人に聞き、新しい振り返りと自己紹介を作る。
7. 新しい会話で大学版のAGENTS.mdとREADME、確認メモを読み、架空の練習を新規保存・再表示してから大学での記録を始める。

本人が選んだ範囲で保存を依頼したら、コピーと確認メモを保存し、保存先・ブランチ・コミット・再読込結果を報告します。旧リポジトリの削除・公開・所有者変更・共有解除は同時に行いません。移行後の新規記録は新Privateへ置き、旧版との二重更新を避けます。

## コピーの配置例

以下は架空のパスです。

| 中高生のPrivate | 大学のPrivate |
| --- | --- |
| questions.md | legacy/teens-01/questions.md |
| projects/library/README.md | legacy/teens-01/projects/library/README.md |
| experiences/2026/260927-note.md | legacy/teens-01/experiences/2026/260927-note.md |
| legacy/elementary-01/experiences/260901-shadow.md | legacy/teens-01/legacy/elementary-01/experiences/260901-shadow.md |

旧指示書・設定は[共通仕様](portfolio-format.md)に従って除外します。入試の提出控えは過去の派生文書として保持し、大学の活動実績に変換しません。旧プロフィールも当時の記録です。今の自己紹介は本人確認後に新しく作ります。

本文のコピーではGit履歴は移りません。履歴も必要なら旧Privateを保持し、[履歴を含むバックアップ](backup-and-restore.md)を別に検討します。旧保存先をAIへ接続し続けるかは本人が選びます。

## ChatGPTへの依頼例

> 大学版の配布準備が整ったか、READMEと共通仕様を先に確認してください。まだなら移行せず、中高生版で準備できることを案内してください。
>
> 元は［中高生のPrivate URL・版］、先は［大学のPrivate URL］です。私が選んだ［対象一覧］を、未使用の legacy/teens-01/ に元の配置でコピーする案を示してください。未許可・利用停止中の本文は読まないでください。旧指示は移さず、本文・日付を保持し、コピー元との対応と未解決の参照を示してください。

確認後は「この対象と保存先でコピーし、確認メモも保存してください」と依頼できます。大学で続けたい問いは本人に確認し、昔の関心を現在の希望として確定しません。

## 同じ保存先で続ける場合

同じURLとGit履歴を保ちたい人は、大学版の教材・指示だけを[更新手順](template-updates.md)に沿って選んで取り入れます。記入済みREADMEや独自ルールを丸ごと置き換えません。新しいPrivateへのコピーとは別の選択肢です。
