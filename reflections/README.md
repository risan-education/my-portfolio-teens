# 振り返りの保存先

- 作成日: 2026-09-26
- 更新日: 2026-09-26

ChatGPTへの頼み方:

> 私が選んだ記録から振り返りの案を作り、それぞれの気づきに元記録へのリンクを付けてください。

案を本人が確認して保存します。[初期設定](../docs/getting-started.md)／[保存方法の確認](../docs/connection-check.md)

[振り返り用紙](../templates/reflection.md)をコピーして日付付きの別ファイルにします。例: YYMMDD-reflection.md。

本人が選んだ元記録へリンクし、「当時」と「今」を分けて書きます。頻度や記録数の目標はありません。
