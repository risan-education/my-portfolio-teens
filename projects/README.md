# 探究と作品

- 作成日: 2026-09-26
- 更新日: 2026-09-26

ChatGPTへの頼み方:

> この問いを続けたいです。元記録を残して、探究ノートかプロジェクトの入口を作る案を見せてください。

案を本人が確認して保存します。[初期設定](../docs/getting-started.md)／[保存方法の確認](../docs/connection-check.md)

テーマごとにフォルダを作り、[探究ノート](../templates/inquiry.md)・[作品カード](../templates/work.md)を保存します。

入試対策では、一つの大きな主テーマを選び、[6段階の用紙](../templates/inquiry-project.md)を projects/<theme>/README.md にコピーして継続します。募集要項の確認後に6段階全体の見通しと最初の行動予定を作り、出願準備計画と相互にリンクします。同名のテーマがある場合は内容を確認し、別の探究なら別名にします。入口から日々の詳細記録へのリンクを付けます。

[進め方](../docs/inquiry-project-guide.md)／[継続例](../examples/inquiry-project/README.md)
