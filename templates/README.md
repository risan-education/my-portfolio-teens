# 用紙を選ぶ

- 作成日: 2026-09-26
- 更新日: 2026-09-26

このフォルダはChatGPTが記録を作るための空欄の用紙です。「このメモに合う用紙で案を作って」と頼めば選んでもらえます。ChatGPTは原本へ記入せず、自分用の保存先へ新しいファイルを作ります。内容確認後の保存は[接続方法](../docs/connection-check.md)に応じて行います。

手入力する場合も原本をコピーし、コピー後はリンクを保存先からの相対パスに直します。

| 目的 | 用紙 | 保存先の例 |
| --- | --- | --- |
| 残す | [一言](quick-note.md)・[活動](experience.md) | experiences/年/ |
| 残す・深める | [作品](work.md)・[探究](inquiry.md) | projects/テーマ/ |
| 入試対策の主テーマを進める | [6段階の入口・継続計画](inquiry-project.md) | projects/テーマ/README.md |
| 振り返る | [振り返り](reflection.md)・[年間](annual-review.md) | reflections/・annual-review/ |
| 活用する | [要約](evidence-summary.md)・[AI向け](ai-context.md)・[進路](career-exploration.md)・[提出条件](submission-check.md) | derived/ |
| 出願に備える | [準備計画](admissions-plan.md)・[出願用出力](admissions-output.md) | derived/YYMMDD-admissions-plan.md等 |
| 自分を知る | [自己理解](self-understanding.md) | derived/YYMMDD-self-understanding.md |
| 利用範囲を決める | [見直し](record-use-review.md) | profile/（本文の複製はしない） |

名前が重なるときは末尾に -02 などを付けます。全項目の記入は不要です。[記録のガイド](../docs/recording-guide.md)
